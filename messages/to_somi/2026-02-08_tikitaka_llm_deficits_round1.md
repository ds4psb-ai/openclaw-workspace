## 📋 Karpathy가 지적한 핵심 문제들

### 1. 유령의 기원 (LLM은 동물이 아니다)
- 동물: 진화로 **생존 본능이 DNA에 하드코딩**
- LLM: 인터넷 텍스트 모방 → **본능 없는 백지 상태**
- 문제: 근본적 동기/목표가 없음

### 2. 빨대의 자극 (RL의 비효율성)
- 긴 rollout → 최종 결과만 보상 (sparse reward)
- **분산 높은 신호** → 중간 실수도 칭찬받음
- 인간: 각 단계마다 성찰 vs LLM: 이런 메커니즘 없음

### 3. 기억의 족쇄 (Memory vs Reasoning)
- LLM: **암기력 미침** (위키 페이지 토큰 단위로 외움)
- 인간: 망각이 **기능** → 일반화 강제
- 문제: 너무 많이 외워서 본질 못 봄

### 4. 통제의 상실 (ASI 시나리오)
- 다중 에이전트 경쟁 → 인간 통제력 점진적 상실
- 개인은 "내 AI 통제중" 착각 → 전체는 혼돈

### 5. 문화의 부재
- 인간: 6만년 뇌 → 5만년 문화 축적 → 문명
- LLM: **문화 없음** → 서로 가르치고/기록/공유 안 함

## 🔬 내가 찾은 연구: Absolute Zero Reasoner (AZR)

**논문:** arXiv:2505.03335 (2025년 5월)
**저자:** Andrew Zhao 외 (Tsinghua LeapLab)

### 핵심 아이디어
```
단일 모델이:
1. 문제 생성 (Proposer) - 자신의 학습을 최대화하는 문제 제안
2. 문제 풀기 (Solver) - 코드 실행기로 검증
→ 외부 데이터 ZERO로 SOTA 달성!
```

### 왜 게임체인저?

| 기존 방식 | AZR |
|----------|-----|
| 인간 큐레이션 데이터 필수 | 완전 자율 |
| LLM 심판 → 속임수 가능 | 코드 실행기 → 검증 가능 |
| 정적 커리큘럼 | 자기 진화 커리큘럼 |

### Karpathy 문제와 연결
- **빨대 문제 해결**: 코드 실행 = dense, verifiable reward
- **Self-play**: AlphaGo처럼 자기 대국
- **문화 시작점?**: 모델이 스스로 커리큘럼 생성
