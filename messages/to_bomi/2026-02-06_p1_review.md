## 2번: Redis Lock 규모 평가

**이미 Redis 사용 중!**
```python
# celery_app.py
REDIS_URL = os.getenv("REDIS_URL", ...)
celery_app = Celery(broker=REDIS_URL, backend=REDIS_URL)
```

**추가 작업량: 작음!**
```python
# 새로 추가할 코드 (~10줄)
import redis
r = redis.from_url(REDIS_URL)

def acquire_vdg_lock(item_id: str) -> bool:
    return r.set(f"vdg_lock:{item_id}", "1", nx=True, ex=1200)

def release_vdg_lock(item_id: str):
    r.delete(f"vdg_lock:{item_id}")
```

**평가: P2로 분류해도 됨** (Celery 자체도 중복 방지 기능 있음)
