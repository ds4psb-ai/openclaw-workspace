## 📋 빌더 관련

### Q: 빌더 1과 빌더 2의 차이가 뭔가요?

**빌더 1 (분석):**
- 원본 영상 → 씬 분석
- 캐릭터 프로필 추출
- IMAGE 프롬프트 생성

**빌더 2 (확장):**
- 재현성 검증
- MOTION 프롬프트 생성
- 오마쥬/변주 버전 생성

### Q: 빌더 결과물이 이상하게 나와요

**체크리스트:**
1. 영상 파일 형식 확인 (MP4 권장)
2. 영상 길이 확인 (30초 이하 권장)
3. 영상 품질 확인 (720p 이상)
4. 빌더 프롬프트 버전 확인

### Q: 변주 옵션을 직접 만들 수 있나요?

네! 빌더 2에서 A/B/C 옵션 외에 "변주" 입력하면 맞춤형 옵션을 요청할 수 있습니다.

예: "조선시대 버전으로 해줘" 또는 "사이버펑크 버전"

## 🖼️ 이미지 생성 관련

### Q: 앵커 이미지가 뭔가요?

캐릭터의 "기준 이미지"입니다. 다른 씬에서 이 이미지를 참조하여 같은 캐릭터를 유지합니다.

**비유:** 배우 캐스팅 사진 → 이 사진을 보고 다른 장면도 촬영

### Q: --cref URL은 어디서 구하나요?

1. Midjourney에서 이미지 생성
2. 이미지 우클릭 → "이미지 주소 복사"
3. 또는 업스케일 후 "Open in Browser" → URL 복사

### Q: --cw 값은 어떻게 정하나요?

| 값 | 효과 |
|----|------|
| 100 | 얼굴+의상+헤어 최대 유지 |
| 80 | 얼굴 강하게, 의상 약간 변경 가능 |
| 50 | 얼굴 위주, 의상 자유 |
| 0 | 얼굴만 참조 |

**팁:** 클로즈업 → 높게 (80-100), 와이드샷 → 낮게 (30-50)

### Q: 여러 캐릭터를 같이 참조하려면?

URL을 띄어쓰기로 구분:
```
--cref https://url1.jpg https://url2.jpg
```

### Q: Midjourney 말고 다른 툴 써도 되나요?

- **NanoBanana Pro:** 한국어 프롬프트 제공됨, 추천!
- **DALL-E 3:** --cref 파라미터 미지원, 캐릭터 일관성 어려움
- **Stable Diffusion:** 가능하나 설정 복잡

### Q: 이미지가 프롬프트와 너무 달라요

**해결책:**
1. `--stylize` 값 낮추기 (250 → 100)
2. `--no` 파라미터로 원하지 않는 요소 제거
3. 프롬프트 더 구체적으로 수정
4. 여러 번 생성 후 선택

## 🎬 모션 생성 관련

### Q: Kling vs Veo 뭐가 좋아요?

| 항목 | Kling 3.0 | Veo 3.1 |
|------|-----------|---------|
| 카메라 움직임 | ⭐⭐⭐ | ⭐⭐ |
| 표정/감정 | ⭐⭐ | ⭐⭐⭐ |
| 속도 | 빠름 | 보통 |
| 가격 | 저렴 | 비쌈 |

**추천:**
- 움직임 많은 씬 → Kling
- 감정 클로즈업 → Veo

### Q: 모션이 너무 과하게 움직여요

프롬프트에 추가:
- `static camera`
- `subtle movement`
- `minimal motion`

### Q: 모션이 부자연스러워요

**체크리스트:**
1. 원본 이미지 해상도 확인 (1024px 이상)
2. 프롬프트가 이미지와 일치하는지
3. Duration이 너무 긴지 (2-3초 권장)

### Q: 이미지를 모션에 어떻게 연결하나요?

1. Kling/Veo에서 "Image to Video" 선택
2. 완성된 이미지 업로드
3. MOTION 프롬프트 입력
4. 생성!

## 🔧 기술적 문제

### Q: Google AI Studio 접속이 안 돼요

**해결:**
1. 브라우저 캐시 삭제
2. 다른 브라우저 시도
3. VPN 확인 (일부 지역 제한)

### Q: Midjourney가 느려요

**해결:**
1. Fast Mode 사용 (크레딧 더 소모)
2. 피크 시간대 피하기 (미국 낮 시간)
3. Turbo Mode 고려

### Q: 파일이 너무 커서 업로드가 안 돼요

**영상 압축:**
- HandBrake (무료) 사용
- 720p, 30fps로 변환
- 30초 이하로 자르기

### Q: 크레딧이 부족해요

**Midjourney:**
- Basic Plan 재구독
- 또는 Mega Plan으로 업그레이드

**Kling/Veo:**
- 무료 크레딧 확인
- 유료 플랜 구매
