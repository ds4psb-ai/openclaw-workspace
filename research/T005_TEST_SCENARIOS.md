## 🧪 테스트 케이스

### TC-01: 빌더 2 출력 형식 검증

**목적:** 개선된 출력 형식이 올바르게 나오는지 확인

**단계:**
1. 빌더 1 실행 → 결과물 받기
2. 빌더 2에 전달
3. 출력물 확인

**예상 결과:**
- [ ] 4개 MD 파일 생성됨
  - 오마쥬_IMAGE.md
  - 오마쥬_MOTION.md
  - 변주_IMAGE.md
  - 변주_MOTION.md
- [ ] 또는 통합 워크플로우 형식 (개선 후)
  - 오마쥬_WORKFLOW.md
  - 변주_WORKFLOW.md

**확인 포인트:**
- [ ] STEP 0: 앵커 단계 있음
- [ ] 씬별 IMAGE + MOTION 묶음 (개선 후)
- [ ] --cref 플레이스홀더 포함 (개선 후)
- [ ] 체크리스트 포함 (개선 후)

### TC-02: 앵커 이미지 워크플로우 검증

**목적:** 앵커 먼저 생성 → 나머지 씬 캐릭터 일관성 확인

**단계:**
1. Scene 02 프롬프트로 앵커 이미지 생성
2. URL 복사
3. Scene 01 프롬프트에 --cref [URL] 추가
4. Scene 01 이미지 생성
5. 두 이미지 캐릭터 비교

**예상 결과:**
- [ ] Scene 01과 Scene 02의 남자 캐릭터가 동일하게 보임
- [ ] 얼굴 특징 유지됨
- [ ] 의상/헤어 유사함 (--cw 값에 따라)

**실패 케이스:**
- [ ] 캐릭터가 완전히 다름 → --cw 값 확인
- [ ] URL 오류 → URL 형식 확인

### TC-03: 웹 헬퍼 파싱 검증

**목적:** MD 파일이 올바르게 파싱되는지 확인

**단계:**
1. T005_WEB_HELPER_FINAL.html 열기
2. 오마쥬_IMAGE.md 내용 붙여넣기
3. "분석하기" 클릭
4. 결과 확인

**예상 결과:**
- [ ] 씬 카드 올바르게 표시됨
- [ ] 씬 번호 순서대로
- [ ] 앵커 씬에 ⭐ 표시
- [ ] NanoBanana/Midjourney 탭 작동
- [ ] 복사 버튼 작동

**테스트할 MD 형식:**
```markdown
### 🎬 Scene 01: 제목 (00:00.00~00:01.67)

[📋 COPY] NanoBanana Pro:
```
프롬프트 내용
```

[📋 COPY] Midjourney V7:
```
프롬프트 내용 --ar 9:16
```
```
