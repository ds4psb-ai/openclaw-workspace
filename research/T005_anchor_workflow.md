# 앵커 이미지 워크플로우 가이드

## 🎯 목적
캐릭터 일관성(Character Consistency)을 유지하면서 여러 씬의 이미지를 생성하기 위한 워크플로우

---

## 📚 Midjourney Character Reference 기본 개념

### --cref (Character Reference)
- 캐릭터의 외모를 참조하는 파라미터
- 사용법: `[프롬프트] --cref [이미지 URL]`
- Midjourney로 생성된 이미지에서 가장 잘 작동
- 실제 사람 사진보다 AI 생성 이미지 권장

### --cw (Character Weight)
- 캐릭터 참조 강도 조절 (0-100)
- **--cw 100** (기본값): 얼굴, 머리, 의상 모두 최대한 유사하게
- **--cw 50**: 얼굴 위주, 의상 일부 변경 허용
- **--cw 0**: 얼굴만 유지, 의상/헤어 자유롭게 변경

### 복수 참조
- 여러 이미지 참조 가능: `--cref [URL1] [URL2]`
- 캐릭터 특성을 더 강하게 고정할 때 유용

## 🔄 권장 워크플로우

### Phase 1: 앵커 이미지 생성

**Step 1.1: 남자 앵커 (Scene 02)**
```
씬 테이블에서 ⭐ ANCHOR (Man) 표시된 씬
→ 이 씬의 Midjourney 프롬프트로 먼저 이미지 생성
→ 가장 마음에 드는 이미지 선택
→ URL 복사 (우클릭 → 이미지 주소 복사)
```

**Step 1.2: 여자 앵커 (Scene 05)**
```
씬 테이블에서 ⭐ ANCHOR (Woman) 표시된 씬
→ 이 씬의 Midjourney 프롬프트로 먼저 이미지 생성
→ 가장 마음에 드는 이미지 선택
→ URL 복사
```

### Phase 2: 나머지 씬 이미지 생성

**각 씬 프롬프트에 --cref 추가:**

원본 프롬프트:
```
1990s vintage film aesthetic, sunny afternoon... --iw 2.0 --ar 9:16 --v 7 --style raw --cw 50 --stylize 250
```

앵커 참조 추가:
```
1990s vintage film aesthetic, sunny afternoon... --iw 2.0 --ar 9:16 --v 7 --style raw --cref [MALE_ANCHOR_URL] --cw 50 --stylize 250
```

**씬별 --cref 적용 가이드:**

| Scene | 등장 캐릭터 | --cref 사용 |
|-------|------------|-------------|
| 01 | 남자 (멀리서) | --cref [MALE_URL] --cw 30 |
| 02 | 남자 (클로즈업) | ⭐ 앵커 씬 - 여기서 생성 |
| 03 | 남자 + 여자 | --cref [MALE_URL] [FEMALE_URL] --cw 50 |
| 04 | 남자 | --cref [MALE_URL] --cw 80 |
| 05 | 여자 (클로즈업) | ⭐ 앵커 씬 - 여기서 생성 |
| 06 | 남자 + 여자 | --cref [MALE_URL] [FEMALE_URL] --cw 50 |
| 07 | 차량 (인물 작음) | --cref 생략 가능 |
| 08 | 인물 없음 | --cref 생략 |

### Phase 3: 모션 영상 생성

이미지 생성 완료 후:
1. 각 씬의 최종 이미지를 Kling/Veo에 업로드
2. MOTION 프롬프트 적용
3. 영상 생성

---

## ⚠️ 주의사항

### 빌더 1/2의 현재 한계
1. **앵커 이미지 URL 부재**: 빌더는 프롬프트만 생성, 실제 이미지는 사용자가 생성해야 함
2. **--cref 자동 삽입 없음**: 사용자가 수동으로 앵커 URL을 프롬프트에 추가해야 함
3. **순서 가이드 부족**: 앵커 먼저 생성해야 한다는 안내 없음

### 권장 개선사항
1. 빌더 2 출력에 "앵커 먼저 생성" 단계 명시
2. 각 씬 프롬프트에 `[MALE_ANCHOR_URL]` 플레이스홀더 포함
3. 작업 순서 체크리스트 제공

## 📋 수강생용 간단 가이드 (복사해서 제공)

```
🎯 AI 영상 제작 - 캐릭터 일관성 가이드

1️⃣ 앵커 이미지 먼저!
   - Scene 02 (남자 앵커) 이미지 생성 → URL 복사
   - Scene 05 (여자 앵커) 이미지 생성 → URL 복사

2️⃣ 나머지 씬 생성
   - 각 프롬프트 끝에 추가: --cref [복사한 URL]
   - 클로즈업 씬: --cw 80~100
   - 멀리서 보이는 씬: --cw 30~50
   - 두 캐릭터 함께: --cref [남자URL] [여자URL]

3️⃣ 모션 영상
   - 완성된 이미지를 Kling/Veo에 업로드
   - MOTION 프롬프트 입력
   - 생성!

💡 팁: 앵커 이미지가 마음에 안 들면 다시 생성!
   나머지 씬의 일관성은 앵커 품질에 달려있습니다.
```
