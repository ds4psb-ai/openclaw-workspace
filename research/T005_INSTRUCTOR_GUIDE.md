## 🚨 수강생 주요 병목 포인트

### 1. 앵커 이미지 개념 미이해 (가장 흔함!)

**증상:**
- Scene 01부터 순서대로 생성 시작
- 캐릭터가 씬마다 다르게 나옴
- "왜 같은 사람이 안 나와요?"

**해결:**
- 수업 시작 전 앵커 개념 강조 (5분)
- 화이트보드에 워크플로우 다이어그램 그리기
- "앵커 먼저!"를 구호처럼 반복

### 2. --cref 파라미터 사용법 혼란

**증상:**
- "--cref 뭐예요?"
- URL 복사하는 법을 모름
- 파라미터 위치/형식 오류

**해결:**
- 라이브 데모로 직접 보여주기
- 단계별 스크린샷 준비
- 템플릿 프롬프트 제공

### 3. MD 파일 복붙 피로

**증상:**
- "파일이 4개나 되네요..."
- 어떤 프롬프트가 어떤 씬인지 헷갈림
- 복붙 실수 (잘못된 씬 프롬프트 사용)

**해결:**
- **웹 헬퍼 도구** 사용 권장
- 또는 MD 뷰어 프로그램 추천 (Obsidian, Typora)
- 씬 번호 큰 소리로 말하며 확인

### 4. Midjourney/Kling 사용법

**증상:**
- 툴 자체가 처음인 수강생
- 계정 생성/결제 문제
- UI 찾기 어려움

**해결:**
- 사전 준비물 체크리스트 공유 (수업 1주 전)
- 첫 수업 전반부에 기본 사용법 튜토리얼
- 백업 계정 준비 (강사용)

## 🛠️ 트러블슈팅 가이드

### "이미지가 안 나와요"

**원인 1:** Midjourney 크레딧 소진
- 해결: 크레딧 확인, 추가 결제 안내

**원인 2:** 프롬프트 오류
- 해결: 파라미터 형식 확인 (-- 앞 공백 등)

**원인 3:** 금지 콘텐츠 필터링
- 해결: 프롬프트에서 민감한 단어 제거

### "캐릭터가 다 달라요"

**원인 1:** --cref 미사용
- 해결: 앵커 URL 붙여넣기 확인

**원인 2:** --cw 값이 너무 낮음
- 해결: --cw 80 이상으로 조정

**원인 3:** 앵커 이미지 품질 낮음
- 해결: 앵커 재생성

### "모션이 이상해요"

**원인 1:** 이미지 해상도 낮음
- 해결: 고해상도 이미지 사용

**원인 2:** 프롬프트가 이미지와 불일치
- 해결: 이미지에 맞게 프롬프트 수정

**원인 3:** 카메라 무브먼트 과다
- 해결: "static" 또는 "subtle movement" 추가
