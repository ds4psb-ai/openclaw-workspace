## 🎯 문제 정의

### 현재 상황
- 빌더 1: 원본 영상 분석 → 씬 테이블 + 이미지 프롬프트 (1개 MD)
- 빌더 2: 검증 + Motion 프롬프트 + 오마쥬/변주 → 4개 MD 출력
  1. 오마쥬 IMAGE.md
  2. 오마쥬 MOTION.md
  3. 변주 IMAGE.md
  4. 변주 MOTION.md

### 수강생 병목현상
1. 4개의 긴 MD 파일을 보면서 복붙 작업 어려움
2. **순서 가이드 부족**: 어떤 앵커 이미지부터 만들어야 하는지?
3. **이미지↔모션 매칭**: 씬별로 IMAGE와 MOTION 프롬프트가 흩어져 있음
4. **복붙 피로도**: 각 씬마다 NanoBanana/Midjourney/Kling/Veo 프롬프트 찾아서 복붙

### 사용 도구 (추정)
- 이미지: Midjourney V7, NanoBanana Pro
- 모션: Kling 3.0, Veo 3.1
- 앵커 참조: `--cref`, `--cw` 파라미터

**개념:** MD 4개 대신 작업 순서 중심 구조로 출력

**현재:**
```
오마쥬_IMAGE.md (씬 1-8 이미지 프롬프트)
오마쥬_MOTION.md (씬 1-8 모션 프롬프트)
변주_IMAGE.md (씬 1-8 이미지 프롬프트)
변주_MOTION.md (씬 1-8 모션 프롬프트)
```

**개선안:**
```
STEP_1_ANCHORS.md
  - 앵커 이미지 먼저 생성 (MALE_ANCHOR, FEMALE_ANCHOR)
  - Midjourney 프롬프트 + 가이드

STEP_2_오마쥬_씬별.md
  - 씬 1: IMAGE + MOTION 함께
  - 씬 2: IMAGE + MOTION 함께
  - ...

STEP_3_변주_씬별.md
  - 씬 1: IMAGE + MOTION 함께
  - 씬 2: IMAGE + MOTION 함께
  - ...
```

**장점:**
- 작업 순서대로 정렬
- 씬별로 IMAGE+MOTION 묶임
- 추가 도구 불필요

**단점:**
- 빌더 2 프롬프트 수정 필요
