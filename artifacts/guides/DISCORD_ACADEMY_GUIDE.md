# 🎮 디스코드 오프라인 강의 가이드

## 테드 (강사) 준비 + 수강생 공지용

---

## Part 1: 테드 — 강사 세팅 가이드

### 1단계: 서버 만들기 (이미 있으면 스킵)

1. Discord 데스크탑 앱 열기 (웹보다 앱 필수!)
2. 왼쪽 사이드바 하단 **"+" 버튼** 클릭
3. **"직접 만들기"** → **"나와 친구들을 위해"** 선택
4. 서버 이름: `Prompty Academy` (또는 원하는 이름)
5. **서버 만들기** 클릭

### 2단계: 채널 구성 (추천)

```
📋 텍스트 채널
├── #공지사항        ← 강의 안내, 링크 공유
├── #질문답변        ← 실습 중 Q&A
├── #과제제출        ← 수강생 결과물 업로드
└── #자유게시판      ← 잡담

🔊 음성 채널
├── 🎓 강의실        ← 화면 공유용 (메인)
└── 🗣️ 토론방       ← 소그룹 토론용 (선택)
```

**채널 만드는 법:**
- 카테고리 옆 **"+"** → 채널 이름 입력 → 유형 선택 (텍스트/음성)

### 3단계: 초대 링크 생성

1. 서버 이름 클릭 → **"사람 초대하기"**
2. **"초대 링크 편집"** 클릭
3. **만료 기간: "안 함"** 으로 설정
4. **최대 사용 횟수:** 수강생 수에 맞게
5. 링크 복사 → 단톡방에 공유

### 4단계: 강의 당일 — 화면 공유

1. **🎓 강의실** 음성 채널 입장
2. 화면 왼쪽 하단 **모니터 아이콘 (🖥️)** 클릭
3. 공유 방식 선택:
   - **"화면"** → 모니터 전체 (추천: 듀얼 모니터 시)
   - **"앱"** → 브라우저 창만 (Kling AI 탭)
4. 설정:
   - **해상도:** 1080p (Nitro) 또는 720p (무료)
   - **프레임:** 30fps (무료) / 60fps (Nitro)
   - ✅ **"사운드도 함께 공유"** 반드시 체크!
5. **"라이브 시작"** 클릭

### ⚠️ 오프라인 교실 주의사항

| 문제 | 해결 |
|------|------|
| 하울링 (삐~ 소리) | 수강생 디스코드 **스피커 OFF**, 강사 목소리는 현장에서 직접 듣기 |
| 인터넷 느림 | 강사 PC **유선 랜선** 연결, 수강생 Wi-Fi |
| 화면 지연 (1-3초) | "지금 화면 보이시죠?" 확인 후 진행 |
| 수강생 소리 겹침 | 수강생 전원 **마이크 뮤트** (강사만 발언) |

### 💡 프로 팁

- **듀얼 모니터** 추천: 1번에 Kling AI 작업, 2번에 디스코드 채팅 관리
- 강의 전 5분 일찍 접속해서 화면 공유 테스트
- 수강생에게 **"화면이 잘 보이면 👍 리액션"** 요청 → 확인용
- 중요한 링크는 #공지사항 채널에 텍스트로도 공유

## Part 2: 수강생 공지 메시지

아래 내용을 단톡방에 바로 보낼 수 있게 작성했어:

---

### 📢 공지 — 버전 A (카카오톡/문자용, 간결)

```
📢 [Prompty Academy] 내일 강의 준비사항

안녕하세요! 내일 강의에서는 디스코드(Discord)를 통해 
강사 화면을 여러분 노트북에서 실시간으로 보며 진행합니다.

✅ 사전 준비 (필수!)

1️⃣ Discord 앱 설치
   - PC: https://discord.com/download
   - (웹 버전 말고 반드시 앱으로!)

2️⃣ Discord 계정 만들기
   - 앱 실행 → 회원가입 (이메일, 닉네임, 비밀번호)

3️⃣ 우리 서버 입장
   - 초대 링크: [여기에 링크 붙여넣기]
   - 링크 클릭 → "초대 수락"

4️⃣ Kling AI 계정 만들기
   - https://klingai.com 접속 → 구글 계정으로 가입
   - (무료 플랜으로 충분합니다!)

5️⃣ 이어폰/헤드폰 지참
   - 오프라인 교실에서 소리 겹침 방지용

📌 내일 강의 시작 전
   → Discord 앱 켜고 → 🎓 강의실 음성 채널 입장
   → 마이크는 뮤트(음소거) 해주세요!

궁금한 점은 여기로 질문주세요 🙏
```

### 📢 공지 — 버전 B (상세 버전, 처음 디스코드 쓰는 분들용)

```
📢 [Prompty Academy] 내일 강의 안내 📢

안녕하세요 수강생 여러분!

내일 강의에서는 "디스코드(Discord)"라는 앱을 통해 
제 화면을 여러분 노트북으로 실시간 공유하면서 진행합니다.
(각자 PC에서 제 작업 화면을 보면서 동시에 실습 가능!)

━━━━━━━━━━━━━━━━

🔧 사전 준비 체크리스트

□ 1. Discord 앱 다운로드 & 설치
   👉 https://discord.com/download
   ※ 크롬 웹 버전 말고 꼭 "앱"으로 설치해주세요!

□ 2. 회원가입
   - 앱 실행 → "가입하기"
   - 이메일, 닉네임(본명 권장), 비밀번호 입력
   - 이메일 인증 완료

□ 3. 우리 서버 참가
   - 아래 초대 링크 클릭:
   👉 [초대 링크]
   - "초대 수락" 누르면 끝!

□ 4. Kling AI 계정 가입
   - 👉 https://klingai.com
   - 구글 계정으로 간편 가입
   - 무료 플랜(매일 크레딧 제공)으로 OK

□ 5. 준비물
   - 노트북 (충전기 지참)
   - 이어폰 또는 헤드폰 🎧
   - (오프라인 교실이라 스피커 쓰면 소리가 겹려요!)

━━━━━━━━━━━━━━━━

📍 내일 강의 시작할 때

1. Discord 앱 실행
2. 왼쪽에서 우리 서버 클릭
3. 🎓 "강의실" 채널 클릭 → "음성 채널 참가"
4. 🔇 마이크 뮤트(음소거) 해주세요
5. 제가 화면 공유하면 → 클릭해서 시청!

※ 화면이 잘 보이면 👍 리액션 눌러주세요!

━━━━━━━━━━━━━━━━

❓ 설치가 안 되거나 어려우시면
   내일 강의 시작 전에 10분 일찍 오시면 도와드릴게요!

기대됩니다! 내일 뵙겠습니다 🙌
```
