## 1. 바이럴 패턴 공식 체계 (Viral Pattern Formulas)

### 1.1 바이럴의 핵심 원리: 3초의 법칙

TikTok/Reels/Shorts 알고리즘의 최우선 지표는 **시청 시간(Watch Time)**과 **재시청률(Rewatch Rate)**이다.

> **첫 3초 리텐션 65% 이상인 영상 → 노출량 4~7배 증가** (OpusClip 분석)

3초 안에 시청자를 잡지 못하면 아무리 좋은 콘텐츠도 묻힌다.

### 1.2 바이럴 후크 7대 공식

| # | 공식명 | 템플릿 예시 | 활용 장르 |
|---|--------|------------|-----------|
| 1 | **Bold Statement** (대담한 주장) | "대부분의 크리에이터가 조회수를 죽이고 있다" | 교육, 반론 |
| 2 | **Question Hook** (질문 후크) | "왜 어떤 영상은 200뷰에서 바이럴 되고 어떤 건 2만뷰에서 죽을까?" | 호기심 유발 |
| 3 | **Pattern Interrupt** (패턴 끊기) | 예상 못한 비주얼/사운드로 시작 | 엔터테인먼트, DIY |
| 4 | **Proof-First** (결과 먼저) | "이 계정을 90일 만에 0→5만 팔로워로 키웠다" | 케이스 스터디 |
| 5 | **Unexpected Confession** (예상 못한 고백) | "이거 공유하면 안 되는데..." | 스토리텔링, 라이프스타일 |
| 6 | **You've Been Doing It Wrong** (당신은 틀렸다) | "이거 당장 그만해. 대신 이렇게 해" | 피트니스, 생산성 |
| 7 | **This Cost Me ₩₩₩** (이것 때문에 돈 날렸다) | "이 실수 하나로 230만원 날렸다" | 재테크, 프리랜서 |

### 1.3 바이럴 영상의 구조 공식 (5-Beat Framework)

```
[0-3초]  HOOK      → 스크롤 멈추기 (3대 심리 트리거: 패턴 깨기, 호기심 갭, 사회적 증거)
[3-8초]  PROMISE   → 이 영상에서 뭘 얻는지 약속
[8-20초] DELIVERY  → 핵심 가치 전달 (한 번에 하나씩)
[20-25초] PAYOFF   → 기대한 결과/반전 도달
[마지막]  LOOP/CTA → 재시청 유도 또는 행동 유도
```

### 1.4 알고리즘이 보는 6대 시그널

| 시그널 | 설명 | 목표 |
|--------|------|------|
| **3초 리텐션** | 첫 3초 안에 이탈하지 않은 비율 | 65%+ |
| **평균 시청 시간** | 영상 전체 대비 시청 비율 | 70%+ |
| **루프율** | 반복 시청 횟수 | 높을수록 좋음 |
| **저장(Save)** | "나중에 보기" 저장 수 | 가치 있는 정보 지표 |
| **공유(Share)** | 외부 공유 횟수 | 바이럴 최강 시그널 |
| **댓글** | 댓글 수와 길이 | 참여도 지표 |

### 1.5 숏폼 최적 길이

- **15-30초**: 루프 효과 극대화 (짧아서 반복 시청)
- **30-60초**: 교육/설명형 콘텐츠 스윗스팟
- **TikTok 허용 10분이지만** 실제 바이럴 영상 대부분 15-60초

## 2. Kling AI 최신 기술 총정리 (2026.01 기준)

### 2.1 버전 히스토리

| 버전 | 시기 | 핵심 업데이트 |
|------|------|--------------|
| Kling 1.5 | 2024 | Motion Brush 도입 |
| Kling 1.6 | 2025 초 | 카메라 경로 제어, 립싱크, 3D Attention 엔진 |
| Kling 2.1 | 2025.05 | **키프레임** — 시작/끝 포지션 지정 가능 |
| Kling 2.5 Turbo | 2025.09 | 속도 60%↑, 비용 62%↓, 모션 퀄리티↑ |
| **Kling 2.6** | **2025.12** | **오디오+비주얼 동시 생성, Kling Video O1** |

### 2.2 Kling 2.6의 핵심 기능 (강의에서 시연 가능)

#### ⭐ 동시 오디오-비주얼 생성
- 보이스오버, 대사, 효과음, 배경음악을 영상과 함께 원패스 생성
- 프롬프트 예: "바리스타가 라떼 만드는 법을 설명, 커피숍 앰비언트 사운드, 배경 재즈"
- **한국어/중국어 음성 생성이 업계 최고 수준**

#### ⭐ Motion Brush (모션 브러시)
- 이미지 특정 부분만 선택적으로 움직임 부여
- 예: 인물은 정지 → 머리카락과 배경 나뭇잎만 바람에 흔들림
- **바이럴 패턴 공식화에 가장 직접적으로 활용 가능**

#### ⭐ 카메라 제어
- Pan, Tilt, Zoom, Orbit, Tracking Shot
- 경쟁사(Runway, Sora)에서 제한적이거나 추가 비용인 기능이 기본 포함
- Motion Brush와 조합하면 복잡한 시네마틱 씬 가능

#### ⭐ Image-to-Video
- 정지 이미지 → 동영상 변환 (강의에서 가장 실용적)
- 제품 사진, 일러스트, AI 이미지 → 다이나믹 영상화
- **Midjourney/DALL-E 이미지 → Kling 영상** 파이프라인

#### ⭐ 키프레임 (Kling 2.1+)
- 시작/끝 프레임 지정으로 정밀한 스토리 제어
- 숏폼의 "훅 → 페이오프" 구조에 최적

#### ⭐ Negative Prompt
- 원하지 않는 요소 명시적 제거: "no blur, no distortion, no extra limbs"
- 성공률 대폭 향상

### 2.3 Kling 프롬프트 엔지니어링 4대 원칙

Kling은 프롬프트를 **스토리보드처럼** 읽는다. 4가지 핵심 요소:

```
1. 씬 세팅 (Scene Setting)
   "해질녘 해안 도로, 절벽과 반짝이는 바다, 길게 드리운 그림자"

2. 피사체 묘사 (Subject Description)  
   "빨간 컨버터블 스포츠카, 크롬 휠, 가죽 인테리어"

3. 모션 지시 (Motion Directives)
   "카메라가 차와 나란히 트래킹, 점차 뒤로 빠지며 해안선 전체 노출"

4. 스타일 가이드 (Stylistic Guidance)
   "시네마틱 4K, 얕은 심도, 생동감 있는 색보정"
```

### 2.4 프로 팁: Reference-First Prompting

**텍스트만으로 프롬프팅하는 것은 초보 방식.** 프로는 **레퍼런스 이미지 먼저** 제공한다.

- **Aesthetic (미학)**: "깨끗한 자연광" / "시네마틱 콘트라스트" → 전체 톤 앵커
- **Structure (구조)**: "3비트 리빌" / "훅→제품→페이오프" → 리듬 지시
- **Motion Cues (모션)**: "슬로우 팬" / "마이크로 패럴랙스" → 움직임 스타일
- **Continuity (연속성)**: "형태 유지" / "색상 일관성" → AI 불안정 방지

## 3. "바이럴 패턴 공식화 → Kling AI 제작" 워크플로우

### 3.1 3단계 빌더 파이프라인 (추정 — 아카데미 빌더 3개에 맞춤)

수강생이 사용할 **3개의 빌더**가 있다고 했으니, 다음과 같은 파이프라인으로 추정:

```
[빌더 1] 바이럴 패턴 분석기
├── 입력: TikTok 영상 URL / 카테고리
├── 분석: 후크 패턴, 구조, 리텐션 포인트 추출
└── 출력: 패턴 공식 카드 (Hook → Promise → Delivery → Payoff)

[빌더 2] 프롬프트 생성기
├── 입력: 바이럴 패턴 공식 + 사용자 콘텐츠 주제
├── 변환: Kling AI 최적화 프롬프트 자동 생성
└── 출력: Scene Setting + Subject + Motion + Style 프롬프트

[빌더 3] 영상 제작 + 편집
├── 입력: Kling 생성 영상 + BGM + 자막
├── 편집: 숏폼 최적화 (9:16, 자막, 트랜지션)
└── 출력: 업로드 가능한 숏폼 영상
```

### 3.2 실전 워크플로우 예시

```
Step 1: 바이럴 영상 벤치마킹
- Komission/아웃라이어 스카우트로 SS티어 영상 발굴
- 후크 패턴 분류 (7대 공식 중 어디 해당?)
- 구조 분석 (몇 초에 뭐가 오는지)

Step 2: 공식 추출 및 변형
- "이 영상은 Pattern Interrupt + Proof-First 조합이다"
- 내 주제에 맞게 공식 변형
- Kling 프롬프트로 변환 (4대 원칙 적용)

Step 3: Kling AI 제작
- Image-to-Video: 미드저니/DALL-E로 키 비주얼 생성 → Kling 영상화
- Motion Brush로 핵심 움직임 지정
- 카메라 무브먼트로 시네마틱 효과

Step 4: 숏폼 최적화
- 자막 추가 (뮤트 시청 85% 대응)
- 후크 텍스트 오버레이
- BGM + SFX 싱크
- 9:16 비율 확인
```

## 4. 디스코드 오프라인 강의 화면 공유 세팅

### 4.1 추천 구조

```
[강사 PC (테드)]
    ↓ Discord "Go Live" / Screen Share
[디스코드 서버 - Voice Channel]
    ↓ 수강생 각자 PC에서 접속
[수강생 PC ×N]
    → 디스코드 앱에서 화면 시청
    → 동시에 자기 PC에서 Kling AI 실습
```

### 4.2 Discord 화면 공유 방법

1. **Voice Channel 입장** (강사 + 수강생 모두)
2. **강사: "Go Live" 클릭** (화면 왼쪽 하단 모니터 아이콘)
3. **공유 대상 선택**:
   - "Screen" → 전체 모니터 공유
   - "Application Window" → Kling AI 브라우저 창만 공유
4. **해상도/FPS 설정**:
   - Nitro 없으면: 720p / 30fps
   - Nitro 있으면: 1080p / 60fps (권장)
5. **수강생: 화면 클릭 → 시청**

### 4.3 최적 세팅 체크리스트

#### 강사 PC
- [ ] Discord 데스크탑 앱 최신 버전 (웹 버전 비추)
- [ ] Nitro 구독 (1080p 60fps 화면 공유용 — 없으면 720p)
- [ ] "Application Window" 공유 시 브라우저 사운드 공유 활성화
- [ ] 마이크 세팅 확인 (Push to Talk vs Voice Activity)
- [ ] 이중 모니터 추천 (1번: 공유 화면, 2번: 디스코드 채팅/관리)

#### 수강생 PC
- [ ] Discord 앱 설치 + 서버 가입 완료
- [ ] Voice Channel 접속 방법 사전 안내
- [ ] 헤드폰/이어폰 준비 (오프라인이면 스피커 하울링 방지!)
- [ ] Kling AI 계정 생성 + 로그인 완료

#### ⚠️ 오프라인 교실 특수 상황
오프라인 교실에서 디스코드를 통해 화면을 공유하므로:

- **네트워크**: 같은 Wi-Fi에 다수 접속 시 대역폭 이슈 가능
  - 강사 PC는 **유선 이더넷** 연결 강력 추천
  - 수강생용 Wi-Fi AP 별도 확보 또는 대역폭 테스트
- **오디오 하울링**: 수강생이 스피커로 재생하면 강사 마이크에 피드백
  - 수강생 전원 **이어폰/헤드폰 필수** 또는
  - 수강생 디스코드 **뮤트** 후 강사 목소리는 현장에서 직접 듣기
- **딜레이**: 디스코드 화면 공유 약 1-3초 지연 → 실습 시 "잠시 기다려주세요" 안내

### 4.4 대안: Stage Channel 활용

수강생 수가 많으면 **Stage Channel** 사용 가능:
- 강사만 발언 권한 (수강생은 청중)
- 질문은 "손들기" 기능 또는 텍스트 채팅으로
- 대규모 교육에 더 적합한 구조

## 6. Kling AI 프롬프트 치트시트 (강의 핸드아웃용)

### 기본 구조
```
[Scene] + [Subject] + [Motion] + [Style] + [Negative]
```

### 후크별 Kling 프롬프트 예시

#### Bold Statement 스타일
```
Extreme close-up of a person's face looking directly at camera,
dramatic studio lighting with dark background,
slow zoom in, text overlay appears: "[대담한 주장]",
cinematic 4K, high contrast, no blur
```

#### Pattern Interrupt 스타일
```
Unexpected object falling into frame from above,
camera quickly pans down to reveal the object,
vibrant colors against white background,
fast motion, sharp focus, no distortion
```

#### Proof-First 스타일
```
Split screen showing before/after comparison,
left side: [이전 상태], right side: [결과 상태],
smooth camera push in, professional lighting,
clean and modern aesthetic, no watermark
```

#### 제품 쇼케이스 (Image-to-Video)
```
[제품 이미지 업로드]
Product slowly rotates 360 degrees on minimal white pedestal,
soft studio lighting with subtle highlights on surface,
gentle floating motion, shallow depth of field,
premium product photography style
```

### Negative Prompt 필수 항목
```
no blur, no distortion, no extra limbs, no watermark,
no text artifacts, no flickering, no morphing
```

## 7. 핵심 인사이트

### 🎯 강의에서 강조할 3가지

1. **"바이럴은 운이 아니라 공식이다"**
   - 7대 후크 공식 + 5-Beat 구조 = 재현 가능한 바이럴
   - 데이터로 검증 (3초 리텐션 65%+ → 노출 4-7배)

2. **"Kling AI는 스토리보드를 읽는다"**
   - 단순 텍스트 ≠ 좋은 프롬프트
   - 4대 요소 (씬+피사체+모션+스타일) 구조화가 핵심
   - Reference-First Prompting으로 프로 수준 결과

3. **"숏폼의 85%는 무음 시청"**
   - 자막/텍스트 오버레이 필수
   - Kling 2.6 오디오 생성은 보너스, 자막이 기본
