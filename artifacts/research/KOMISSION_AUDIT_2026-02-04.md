## 💰 상용화 전략 (웹 리서치 기반)

### 시장 분석
- TikTok 분석 도구에 대한 B2B 수요 급증
- 네이티브 분석 기능이 기본적 → 심층 분석 갭 존재
- 브랜드/크리에이터 모두 "edge" 필요

### 가격 모델 옵션

#### 1. Tiered Subscription (추천)
| 플랜 | 가격 | 기능 |
|------|------|------|
| Free | $0 | 기본 아웃라이어 5개/일, 제한된 분석 |
| Pro | $29-49/월 | 무제한 아웃라이어, VDG 분석 10개/월 |
| Business | $99-199/월 | 무제한 VDG, API 접근, 팀 기능 |
| Enterprise | 커스텀 | 화이트라벨, 전용 인프라 |

#### 2. Usage-Based (대안)
- VDG 분석당: $0.50-2.00
- API 호출당: $0.01-0.05
- **장점:** 38% 더 빠른 성장률 (OpenView 연구)

#### 3. Freemium + Feature-Gating
- 기본 기능 무료
- 고급 분석/내보내기/API → 유료

### 경쟁사 벤치마크 (심층)
| 경쟁사 | 가격대 | 핵심 기능 | 약점 |
|--------|--------|----------|------|
| **Shortimize** | $99-249/월 | 무제한 계정, 비디오 추적, 크리에이터 결제 자동화 | VDG급 심층분석 없음 |
| **Sprout Social** | $199/seat/월 | 올인원 SMM, 크로스플랫폼 | TikTok 특화 아님 |
| **Pentos** | 불명 | TikTok 전용, 트렌딩 오디오 | 소규모 |
| **Exolyt** | 불명 | 해시태그 분석, 센티먼트 | API 없음 |
| **네이티브 TikTok** | 무료 | 기본 분석 | 60일 제한, 심층분석 없음 |
| **Hootsuite** | $99+/월 | 올인원 SMM | TikTok 특화 아님 |

**시장 Gap 발견:**
- 대부분 "분석/트래킹" 도구 → 패시브
- **VDG 같은 "왜 바이럴인지" 설명하는 도구 없음** ← Shorti.ai USP!
- 패턴 라이브러리/레시피 제공하는 도구 부재

### Shorti.ai 차별점 (USP) - 핵심 경쟁력
1. **VDG 분석** - Gemini 2.5 Pro 기반 심층 바이럴 분석
   - "왜 이 영상이 바이럴인가?" 질문에 답변
   - 훅/트랜지션/CTA 패턴 자동 추출
   - 경쟁사 대비 **유일한 기능**

2. **패턴 라이브러리** - 검증된 바이럴 레시피 DB
   - 카테고리별 성공 패턴 축적
   - "따라하면 되는" 액셔너블 인사이트
   
3. **아웃라이어 탐지** - 실시간 급상승 영상 감지
   - SS/S/A/B/C 티어 자동 분류
   - 빠른 트렌드 캐치

4. **한국 시장 특화** - 로컬 트렌드 이해
   - K-콘텐츠 바이럴 패턴 특화
   - 한국어 지원
