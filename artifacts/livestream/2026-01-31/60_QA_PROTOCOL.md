# Q&A 프로토콜(시간관리/품질)

## (복붙/멘트) Q&A 시작 전 10초 공지
- “질문은 `Q:`로 시작해서 **직무/상황/원하는 결과**만 1줄로 주세요. 긴 질문은 후반 Q&A에서 묶어서 답할게요.”

## 질문 포맷(고정)
- 직무 / 지금 상황 / 원하는 결과
- 운영 팁: 채팅에 질문을 받을 때는 **`Q:`로 시작**하게 요청하면(예: `Q: 직무/상황/원하는 결과`) 스팸/잡담과 분리가 쉬움

## (복붙/멘트) 60–90초 답변 템플릿(3문장)
- **결론(1줄):** "저라면 X부터 하겠습니다."
- **이유(1줄):** "지금 병목이 Y라서요."
- **다음 액션(1줄):** "오늘은 Z 3가지만 체크해보세요."

> 길어질 것 같으면: 결론 1줄만 주고 **후반 Q&A/댓글/커뮤니티로 이어서**로 컷.

## 선별 규칙
- ‘오늘 3파트’ 중 어디에 붙는 질문인지 먼저 분류 후 답
- 케이스가 길면: “끝나고 댓글/커뮤니티로 이어서”로 컷
- 홍보/링크 스팸은 **답하지 말고** 바로 타임아웃/차단(대응에 시간 쓰지 않기)

## (운영) 질문 수집을 깔끔하게 만드는 2줄
- (고정 멘트 1회) “질문은 `Q:`로 시작해서 **직무/상황/원하는 결과**만 1줄로 주세요. 긴 질문은 제가 후반 Q&A에서 묶어서 답할게요.”
- (모더레이터 있으면) 모더는 좋은 질문을 **`Q:` 그대로 복붙**해서 메모에 쌓기 → Q&A 타임에 위에서부터 처리

## (포맷 미준수 대응) 흐름 안 끊고 다시 받는 1줄
- “질문 감사합니다 — 채팅이 너무 빨라서요. **`Q:`로 시작해서 `직무/상황/원하는 결과`만 1줄로** 다시 한 번만 적어주시면 바로 잡아서 답할게요.”

## (복붙) 질문 큐 메모 포맷(모더/운영자용)
- `Q: (직무) / (상황) / (원하는 결과) — (작성자 닉네임)`
- 예: `Q: PM / 유저 인터뷰 시간이 없음 / PRD를 빠르게 검증하고 싶음 — @someone`

## (시간 박스) Q&A가 길어질 때의 기본 룰
- 질문 1개당 **60–90초**를 기본으로 잡기
- 길어질 것 같으면 이렇게 컷(복붙/멘트):
  - “좋은 질문인데 케이스가 길어서, **지금은 결론만 한 줄로** 드리고 방송 끝나고 댓글/커뮤니티로 이어서 정리해드릴게요.”
  - “이건 Part 2/3에서 같이 엮어야 정확해요. **큐에 넣어둘게요.**”

## (근거 3줄) YouTube 라이브 채팅 운영 기능(공식)
- **구독자 전용 채팅**(구독 기간 조건 포함)으로 채팅 참여자를 제한할 수 있음.
- **슬로우 모드(Slow mode)**로 1인당 채팅 간격(몇 초/몇 분)을 걸어 도배를 줄일 수 있음.
- **금칙어 차단/부적절 메시지 보류(기본 검열, Basic moderation)** 같은 기본 보호장치를 켤 수 있음(최종 노출 여부는 운영자가 결정).

> 참고: UI/명칭은 계정/권한/지역에 따라 약간 다를 수 있습니다. 핵심은 “라이브 채팅 설정에서 **참여 제한 + 속도 제한 + 기본 검열**” 3가지를 켜는 것.

### 방송 시작 전 체크리스트(측정 가능)
- [ ] 구독자 전용 채팅 ON(예: 구독 10분 이상)
- [ ] Slow mode ON(예: 10초)
- [ ] 금칙어 10개 등록(욕설/홍보/링크 스팸)
- [ ] 모더레이터 1명 지정(질문 선별/정리 담당)
- [ ] (권장) 고정댓글/채팅 공지로 **질문 포맷 1줄** 안내: `Q: 직무 / 상황 / 원하는 결과`

## 시간관리 멘트
- “좋은 질문인데요, 케이스가 길어져서 방송 끝나고 정리해서 답 드릴게요. 지금은 핵심만 한 줄로 처방하고 넘어갈게요.”
- “이건 Part3(결제/운영)에서 같이 엮어야 답이 정확합니다. 잠깐 킵해둘게요.”

## 채팅이 조용할 때(활성화 질문)
- “지금 하시는 게 ‘영상 제작’ 쪽인가요, ‘서비스/자동화’ 쪽인가요? 둘 중 하나만 적어주세요.”
- “제일 싫어하는 반복 업무가 뭐예요? 회의/메일/리서치/정리 중 하나만.”
