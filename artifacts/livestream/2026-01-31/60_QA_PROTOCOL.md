# Q&A 프로토콜 (시간 관리/품질)

## TL;DR (흐름 유지 3줄)
- 질문은 채팅에서 **`Q:`로 시작**하게 유도: `Q: 직무 / 상황 / 원하는 결과` *(1줄, 한 메시지당 질문 1개. 소문자 `q:`도 채팅 원문은 유지하고 기록할 때만 `Q:`로 통일)*
- (질문이 길어지면) **1줄로 다시 요청하고 진행**: “감사합니다 — 채팅이 빨라서요. `Q:`로 시작해서 `직무 / 상황 / 원하는 결과`만 1줄로 다시 부탁드릴게요.”
- (운영) 위 포맷 리마인드는 **라이브 전체 3회 이내**로 유지: **고정댓글 1회(시작 시) + 채팅 공지 최대 2회(필요 시)** *(즉, `1+2=최대 3회`. Q&A 파트가 여러 번이어도 채팅 공지는 라이브 전체 합산 2회 이내로 제한하고, 같은 문구를 질문마다 반복 공지하지 않기)*
  - (권장 타이밍) **Q&A 시작 시 1회 공지**하고, 흐름이 흐트러질 때만 추가 1회 공지
  - (간격) 같은 리마인드 문구는 **최소 20분 간격**으로만 재공지(질문마다 반복 금지, 채팅 피로도 방지)
  - (리듬) 공지는 **붙여넣기용 2줄만** 쓰고, 같은 문구를 질문마다 반복하지 않기(진행 흐름 우선)
  - (형식) 공지/고정댓글은 **평문(코드블록/불릿/번호 없이)** + **줄 맨 앞 공백 없이** 붙여넣기(모바일 가독성/복붙 사고 방지)
  - 예시(평문 2줄):
    - `Q: 직무 / 상황 / 원하는 결과 (1줄)`
    - `답변은 60–90초 컷(결론→이유→다음 액션)`
  - (주의) 고정댓글/설명란/채팅 공지는 **코드블록(백틱)으로 감싸지 말기**(모바일 가독성/클릭성 저하 방지)
- 답변은 **원칙 60초(필요 시 최대 90초)**: **결론 1줄 → 이유 1줄 → 다음 액션 1줄**
  - (타이머 기준) 질문을 읽고 난 뒤, **답변 첫 문장부터** 60–90초를 잰다(질문 소개/호명 시간은 제외)
  - (짧게 가야 하면) 60초 모드: **결론 1줄 → 다음 액션 1줄**만 말하고 컷
  - (질문 폭주 시) 큐를 1회 정리: **“Q 3개만 받고 바로 답할게요.”** *(필요할 때 1회만 사용, 정상화되면 즉시 해제)*
- (정상화 복귀) 질문 속도가 줄면 **“Q 3개 제한” 문구는 즉시 해제**하고 일반 Q&A 흐름으로 복귀
  - (복귀 멘트 1줄) “채팅 안정돼서 제한은 풀고, `Q:` 포맷만 유지해서 계속 받을게요.”

## 90초 답변 템플릿(말로 그대로)
- **결론(1줄):** “저라면 **X부터** 하겠습니다.”
- **이유(1줄):** “지금 병목이 **Y**라서요.”
- **다음 액션(1줄):** “오늘은 **Z 3가지만** 체크해보세요.”
- **마무리(1줄):** “핵심은 여기까지고, 다음 질문으로 넘어갈게요.”

> 운영 팁: Q&A 시작 전에 **휴대폰 타이머(90초) 1개만** 켜두면 답변이 길어지는 사고가 거의 사라짐.

## (실수 방지) 고정댓글 운영 10초 체크
- 고정댓글을 수정/업데이트했다면 **댓글 목록 상단에서 ‘고정됨 / Pinned by …’ 배지가 남아있는지** 10초 확인
- 타임스탬프/링크/공지 문구는 가능하면 **평문(코드블록 금지)**으로 유지(모바일 클릭/가독성)
- (챕터 사고 방지) 공지 문구가 타임스탬프(00:00… 라인들)와 같이 있을 땐 **반드시 빈 줄로 분리**(챕터 인식/클릭 안정)

## (복붙) 고정댓글/채팅 공지 ‘평문’ 예시(2줄)
아래 2줄은 **그대로 평문으로** 붙여넣기(앞에 `-`/`•` 같은 불릿 없이).
문서 가독성 때문에 `백틱`을 쓰는 구간이 있어도, **실제 복붙은 백틱 없이 평문으로**.

Q: 직무 / 상황 / 원하는 결과 (1줄)
답변은 60–90초 컷(결론→이유→다음 액션)

(형식) 위 2줄은 **불릿/번호/들여쓰기 없이** 줄 맨 앞부터 시작(앞 공백 금지)

> 운영 팁: 이 공지는 **라이브 중 1회(고정댓글)**만 박아두고, 채팅은 필요할 때만(최대 2회) 리마인드.

## (채팅 폭주/스팸) 10초 대응(운영이 멈추지 않게)
- 도배/링크 스팸이 늘면 **즉시 슬로우 모드(Slow mode)**(추천 5–10초, *처음엔 10초로 시작* / 필요하면 15초까지) + **구독자 전용 채팅**(필요 시 기본 검토 ON)을 켜서 속도를 낮추기
  - (추천 기본값, 10초용)
    1) **Slow mode ON(10초)**
    2) (필요 시) **기본 검토(Basic moderation) ON** *(스팸 메시지가 자동으로 보류되게)*
    3) 그래도 터지면 **구독자 전용 ON(구독 10분 이상)** *(참여 제한)*
  - (권장) 설정을 켠 직후 채팅에 **1줄만** 안내하고 끝내기(과다 공지 방지):
    - “채팅이 너무 빨라서 잠깐 **슬로우 모드** 걸고 갈게요.”
  - (실전 팁) **슬로우 모드만 켜도** 체감이 큼. ‘구독자 전용’은 채팅이 계속 터질 때만 추가로 올리기(불필요한 참여 장벽 최소화).
  - (운영 팁) 구독자 전용은 보통 **‘구독 10분 이상’ 조건**으로 시작하면 무난함(너무 빡세게 잡지 말기)
  - (UI 길안내, 10초용) 보통 경로: **YouTube Studio → 라이브 컨트롤룸 → 채팅(라이브 채팅 설정)** → `Slow mode` / `구독자 전용` / `기본 검토(보류)`
    - 계정/지역에 따라 메뉴명이 약간 달라도, 핵심은 **(1) 속도 제한 (2) 참여 제한 (3) 기본 검토(보류)** 3가지를 켜는 것.
- 스팸/홍보는 **답하지 말고** 타임아웃/차단(대응에 시간 쓰지 않기)
  - (모더레이터 없을 때) 호스트가 즉시 타임아웃 1회 후 재발 시 차단
- (정상화 복귀) 채팅이 안정되면 **슬로우 모드/구독자 전용을 한 단계씩만 완화**하고 1–2분 관찰(설정을 한꺼번에 풀면 재폭주 위험)

## (운영) 질문 포맷 리마인드(채팅 노이즈 방지)
- Q&A 파트 시작할 때 **채팅에 1회**, 그리고 채팅이 흐트러지면(잡담/도배가 늘면) **중간에 1회만 추가 공지**
  - 핵심: 질문마다 반복 공지하지 말고, **라이브 전체 합산 최대 2회**로 제한(운영 멈춤 방지)
  - 공지 예시 1줄: `Q: PM / 인터뷰 시간이 부족 / PRD를 빠르게 검증하고 싶음`

## (운영) 90초 타이머 1개만(실전)
- 휴대폰/시계로 **90초 타이머**를 켜고 시작
- 타이머가 울리면 **결론 1줄만 더 말하고 바로 컷**(“다음 질문 갈게요”) — 길어질수록 전체 흐름이 무너짐
- (운영) 같은 질문을 2분 이상 붙잡지 않기: 필요한 경우 “상세는 댓글/커뮤니티로” 한 줄 남기고 다음 질문으로 이동
- (복붙/멘트) 타이머 울렸을 때 쓰는 1줄:
  - “좋은 질문인데요, **지금은 결론만 한 줄로** 정리하고 다음 질문 갈게요.”
- (운영 팁) 스스로 길어질 것 같으면 **60초 지점에 1회 더 컷 판단**: “결론 → 다음 액션”만 남기고 종료

## (채팅 정리 2줄) 도배 줄이는 룰
- 같은 질문/공감은 **새 질문 대신 `👍`(좋아요)로 눌러달라**고 1회 공지(채팅 속도/노이즈 감소)
- 질문은 가능하면 **1개씩**(여러 개면 “가장 중요한 1개만” 다시 요청하고, 나머지는 후반 큐로 이동)

## (복붙/멘트) Q&A 시작 전 10초 공지
- “질문은 `Q:`로 시작해서 **직무 / 상황 / 원하는 결과**만 1줄로 주세요. 긴 질문은 후반 Q&A에서 묶어서 답할게요.”
- “답변은 흐름을 위해 **질문당 60–90초 컷**으로 갈게요. 길어지는 건 방송 끝나고 댓글/커뮤니티로 이어서 정리할게요.”

## (운영) 채팅 공지/고정댓글로 박아두기 좋은 1줄
- `Q: 직무 / 상황 / 원하는 결과 (1줄)`

### (옵션) 고정댓글에 같이 붙이면 좋은 1줄(시간 관리)
- `답변은 60–90초 컷(결론→이유→다음 액션)`

## 질문 포맷(고정)
- 직무 / 상황 / 원하는 결과
- 운영 팁: 채팅에 질문을 받을 때는 **`Q:`로 시작**하게 요청하면(예: `Q: 직무 / 상황 / 원하는 결과`) 스팸/잡담과 분리가 쉬움

## (마무리 멘트) 다음 질문으로 넘어가는 1줄
- “핵심은 여기까지고요 — **다음 질문 갈게요.**”

## 선별 규칙
- ‘오늘 3파트’ 중 어디에 붙는 질문인지 먼저 분류 후 답
- 케이스가 길면: “끝나고 댓글/커뮤니티로 이어서”로 컷
- 홍보/링크 스팸은 **답하지 말고** 바로 타임아웃/차단(대응에 시간 쓰지 않기, 운영자 원칙 동일 적용)

## (운영) 질문 수집을 깔끔하게 만드는 2줄
- (고정 멘트 1회) “질문은 `Q:`로 시작해서 **직무 / 상황 / 원하는 결과**만 1줄로 주세요. 긴 질문은 제가 후반 Q&A에서 묶어서 답할게요.”
- (모더레이터가 있으면) 모더레이터는 좋은 질문을 **`Q:` 그대로 복붙**해서 메모에 쌓기 → Q&A 타임에 위에서부터 처리

## (질문 폭주 대응) 30초로 ‘큐 정리’하는 방법
- “지금부터 **Q 3개만 받고** 바로 답하고 넘어갈게요. 나머지는 후반 Q&A/댓글로 받겠습니다.” *(질문량이 폭주할 때만 1회 사용)*
- 모더레이터가 있으면: “좋은 질문은 `Q:` 그대로 복붙해서 큐에 넣어주세요.”

## (포맷 미준수 대응) 흐름 안 끊고 다시 받는 1줄
- “질문 감사합니다 — 채팅이 너무 빨라서요. **`Q:`로 시작해서 `직무 / 상황 / 원하는 결과`만 1줄로** 다시 적어주시면 바로 잡아서 답할게요.”

## (복붙) 질문 큐 메모 포맷(모더레이터/운영자용)
- `Q: (직무) / (상황) / (원하는 결과) — (작성자 닉네임)`
- 예: `Q: PM / 유저 인터뷰 시간이 없음 / PRD를 빠르게 검증하고 싶음 — @someone`

## (시간 박스) Q&A가 길어질 때의 기본 룰
- 질문 1개당 **60–90초**를 기본으로 잡기
- 길어질 것 같으면 이렇게 컷(복붙/멘트):
  - “좋은 질문인데 케이스가 길어서, **지금은 결론만 한 줄로** 드리고 방송 끝나고 댓글/커뮤니티로 이어서 정리해드릴게요.”
  - “이건 Part 2/3에서 같이 엮어야 정확해요. **큐에 넣어둘게요.**”

## (강제 컷) 시간을 뺏길 때 쓰는 하드 스탑 1줄
- “이건 케이스가 커서 여기서 다 하면 방송이 멈춰요. **결론만 한 줄** 드리고, 상세는 **댓글/커뮤니티로 이어서** 정리하겠습니다.”

## (운영) Q&A 파트 타임스탬프 메모(챕터/리플레이용)
- Q&A 시작할 때: `__:__ Q&A 시작`
- Q&A 중간에 주제 전환 있으면: `__:__ Q&A(결제)` / `__:__ Q&A(운영)` 같은 식으로 1줄만 추가
- Q&A 종료/엔딩 전환: `__:__ 엔딩`

## (채팅이 조용할 때) 활성화 질문 3개
- (운영 팁) 20–30초 무응답이면 진행 멘트 1줄 후 바로 첫 질문으로 전환: “좋아요, 제가 먼저 많이 나오는 질문 1개부터 짧게 답해볼게요.”
- “지금 하시는 게 ‘영상 제작’ 쪽인가요, ‘서비스/자동화’ 쪽인가요? 둘 중 하나만 적어주세요.”
- “제일 싫어하는 반복 업무가 뭐예요? 회의/메일/리서치/정리 중 하나만.”
- “지금 당장 가장 급한 건 ‘성과(조회/전환)’인가요, ‘시간(업무 자동화)’인가요? 둘 중 하나만.”

## (근거 3줄) YouTube 라이브 채팅 운영 기능(공식)
- **구독자 전용 채팅**(구독 기간 조건 포함)으로 채팅 참여자를 제한할 수 있음.
- **슬로우 모드(Slow mode)**로 1인당 채팅 간격(몇 초/몇 분)을 설정해 도배를 줄일 수 있음.
- **금칙어 차단/부적절 메시지 보류(기본 검토, Basic moderation)** 같은 기본 보호장치를 켤 수 있음(최종 노출 여부는 운영자가 결정).

> 참고: UI/명칭은 계정/권한/지역에 따라 약간 달라도, 핵심은 “라이브 채팅 설정에서 **참여 제한 + 속도 제한 + 기본 검토(보류)**” 3가지를 켜는 것.

### 방송 시작 전 체크리스트(측정 가능)
*(YouTube Studio의 라이브 컨트롤룸/채팅 설정에서 확인)*
- [ ] 구독자 전용 채팅 ON(예: 구독 10분 이상)
- [ ] Slow mode ON(추천: 5–10초, 채팅이 폭주하면 15초까지)
