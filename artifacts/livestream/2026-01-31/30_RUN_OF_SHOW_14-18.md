# Run of Show (14:00–18:00)

- ‘만들기’가 아니라 **업그레이드 + 재현성 + 결제**까지 붙여 운영 가능한 상태로 완주.

## 14:00–14:10 오프닝(10m)
- 훅: “오늘은 만드는 데서 끝내지 않고, 운영/수익화까지 붙여서 ‘서비스’로 만듭니다.”
- 룰: 코드 0줄, 채팅만 / 질문 포맷 강제(직무/상황/원하는 결과)

## 14:10–14:30 지난 2강 복기(20m)
- ‘씬별 프롬프트 일관성 유지 앱’이 해결한 문제 3개
- 오늘 확장: 데이터 기반 프롬프트 추론 + 스토리보드 대응

## 14:30–15:25 Part 1 — 앱/홈페이지 성능·디자인 업그레이드(55m)
- 체감 성능: 로딩/프로그레스/상태/에러/재시도/저장
- UI 정리: 컴포넌트/타이포/여백/색/버튼 상태
- Before/After를 계속 보여주기

## 15:25–15:40 Q&A 1차(15m)
- 질문 포맷 통일 + 긴 질문은 후반부로 킵

## 15:40–16:45 Part 2 — 데이터 기반 프롬프트 추론으로 고도화(65m)
- 데이터 스키마(씬/캐릭터/톤/금칙/예시/스타일)

## 16:45–17:00 Q&A 2차(15m)
