> 목적: 라이브 데모가 막힐 때 **2분 안에** “말”보다 “화면”으로 즉시 전환해 흐름을 지킨다.

- [ ] 라이브 시작 직전, **A1 → A2 → A3를 실제 방송 화면에서 30초 안에 열기** 1회 점검
- [ ] B1 영상 첫 프레임 재생 확인 후 일시정지(필요 시 즉시 재생할 수 있는 상태로 대기)

- 폴더(추천): `plan-b-assets/` *(예시; 위치는 자유지만 라이브 중 두 번 클릭 이내로 열 수 있어야 함 — 예: `/Users/ted/Desktop/livestream/plan-b-assets/`)*
- 파일명(예시): *(이름순 정렬 시 상단부터 보이도록, **A1/A2/A3/B1/B2 접두어** 사용)*
- [ ] (권장) A1/A2/A3 이미지는 Quick Look(스페이스바)로 1회 열어 **파일명-내용 매칭** 확인(급한 전환 중 오픈 실수 방지)
  - `A1_performance_before-after.png`

매핑(헷갈림 방지):
- A1 ↔ Part 1(성능·디자인)
- A2 ↔ Part 2(스토리보드/일관성)
- A3 ↔ Part 3(결제/운영)

전환 시 화면 전개 순서(추천):
- 폴더 열기 → **A1 → A2 → A3** (3장으로 전체 구조를 먼저 보여주고, 필요하면 B1/B2로 보강)
- (현장 팁) 전환 첫 10초는 **A1부터 바로 열기**로 고정하고, 설명은 화면이 뜬 뒤에 시작(침묵/머뭇거림 방지).

## 1) 필수 자산(없으면 전환 지연 리스크 큼)
- [ ] 사전 녹화 데모(각 2–5분) 2개 이상 *(A/B 흐름 각각 최소 1개, 총 2개 이상 권장)*
  - [ ] 라이브 시작 전 각 파일 10초 **로컬 재생(무음/권한 오류/검은 화면 없음)** 확인
  - [ ] 성능/디자인 개선 결과
  - [ ] Polar 결제 연결 결과 (**샌드박스: 실결제 금지, 테스트 결제만**)
  - [ ] (중요) 녹화본/캡처 모두 **민감 정보 마스킹/크롭** 확인(토큰/메일/실결제 카드 정보/주소 등)
- [ ] 정상 플로우 캡처 3장(핵심 전환 지점만): 업로드/결과/다음 액션
  - [ ] (추천) 캡처도 A1/A2/A3 규칙으로 파일명 맞춰두기(라이브 중 ‘생각 없이’ 순서대로 열리게)
- [ ] 정적 스크린샷 세트: Before/After, 설정 화면(민감 정보 **확실히** 마스킹), 결제 플로우(테스트 결제)
- [ ] 스토리보드 테이블 예시 1장(timecode/shot_goal/continuity_checks)
- [ ] 결제 성공 화면/대시보드 캡처 1–2장
- [ ] 대체 링크(미러) 1개: Notion/Google Docs(공유 권한 미리 테스트, 로그인 없이 열람 가능 여부 확인)
- [ ] (권장) 미러 문서는 PDF로 1부 로컬 저장(네트워크 이슈 시 즉시 화면 공유 가능)

## 2) 운영 백업(전환 속도)
- [ ] 로컬 백업: 중요한 문서/프롬프트/템플릿 로컬 저장
- [ ] 플랜B 자산 폴더는 **스트리밍 장치의 로컬 디스크**에 두기(Wi-Fi/클라우드 없이도 즉시 열리는지 확인)
- [ ] (권장) B1/B2 영상은 플레이어에서 1회 열어 **첫 프레임 + 5초 재생 확인**(전환 직후 검은 화면/버퍼링 방지)
- [ ] (권장) 데모 영상 포맷은 가능하면 통일(`.mp4` + H.264, 1080p)해 코덱/플레이어 이슈를 줄이기
- [ ] (권장) A1/A2/A3를 실제 방송 화면에서 순서대로 열어 **10초 내 전환**이 되는지 1회 리허설 *(막히면 B1/B2로 바로 넘어가는 동선까지 포함, 클릭 순서까지 고정)*
- [ ] (권장) B1/B2 영상은 **중간 지점(예: 01:00) 탐색(Seek) 1회**도 확인(코덱/파일 손상으로 중간 재생 실패하는 사고 방지)
- [ ] (운영 팁) 영상 재생이 버벅이면 즉시 **A1/A2/A3 정적 캡처 3장**으로 전환하고, 영상은 Q&A 구간에 재시도
- [ ] 플랜B 전환 시각 `__:__`(영상 재생 시간 기준)을 한 줄로 메모 → 방송 후 `35_TIMESTAMP_TEMPLATE.md`의 “(옵션) 플랜B 전환”에 반영 *(라이브 중 템플릿 직접 수정 금지)*
- [ ] 플랜B 전환 직후 운영 로그 한 줄 남기기: `KST HH:MM Plan B 전환` *(사후 정리/타임라인 복원용)*
- [ ] 타임스탬프 템플릿 복사/붙여넣기 준비: `35_TIMESTAMP_TEMPLATE.md` *(고정댓글 업데이트 10–15분 컷, 라이브 중 템플릿 직접 수정 금지)*
- [ ] 대체 네트워크: 핫스팟/테더링 + 비밀번호 확인
- [ ] 대체 오디오: 유선 이어폰/보조 마이크
- [ ] 대체 화면 공유: 데모용 브라우저 프로필/시크릿 창(둘 중 하나는 로그인 상태 확인)
- [ ] (스트리밍 툴 사용 시) OBS/스트림 세팅 백업: 씬/소스/오디오 입력이 깨졌을 때 즉시 복구
- [ ] 로컬 화면 녹화(백그라운드) 켜두기(디스크 여유 확인): 라이브 화면이 깨져도 **리플레이/클립**은 살릴 수 있음
