# YouTube 제목/설명/고정댓글 (광고 티 최소)

## 제목 후보(택1)
1) 코드 0줄, 채팅만으로 앱/웹 업그레이드 + 결제(Polar)까지 (AI 에이전트 실전)
2) AI 에이전트로 ‘프로덕트’ 만들기: 성능·디자인 개선 + 결제 붙이기까지 (노코드/노프로그래밍)
3) 씬별 프롬프트 일관성 앱 고도화: 데이터 기반 추론 + 스토리보드 대비 + 결제 연결
4) 코드 0줄 채팅 라이브: 성능·디자인 업그레이드 → 씬별 일관성(데이터/스토리보드) → Polar 결제

## 설명란 상단 5~6줄(모바일 최적)
- 이 영상에서 **코드 0줄 + 자연어 채팅만**으로 “만들기→운영 가능”까지 한 번에 보여드립니다.
- Part 1: 성능·디자인 업그레이드 (Before/After)
- Part 2: 데이터 기반 프롬프트 추론으로 씬별 일관성 고도화(+스토리보드 timecode/shot_goal/continuity_checks)
- Part 3: Polar 카드결제 연결(샌드박스 포함) → 제공/운영 흐름까지
- 체크리스트/템플릿은 설명란/고정댓글로 공유(라이브 종료 직후 **10~15분 내 타임스탬프 업데이트**)
- (검색용) `OpenClaw` / `Moltbot` 같은 브랜드 키워드는 **과한 광고 문장 없이** ‘더보기 아래’ 어딘가에 1줄로만 넣어두면 충분합니다.

> 리플레이로 남길 때는 `14:00–18:00` 같은 **실시간 스케줄 표기는 삭제/수정**하는 게 깔끔합니다(시청자 혼동 방지).

### (근거 3줄) YouTube 설명 작성 팁(공식)
- 설명은 **‘더보기(Show more)’ 전/후 2층 구조**로 보이므로, **첫 몇 줄에 영상 핵심**을 넣는 것을 권장.
- 검색을 위해 **핵심 키워드 1~2개를 제목+설명에 반복 노출**하라고 안내.
- 긴 영상은 **챕터(Video chapters)**를 넣어 중요한 구간으로 바로 점프하게 만들 수 있음.

### 업로드 전 체크리스트(측정 가능)
- [ ] 설명 첫 3줄에 “누가/무엇을/얻는지” 한 문장 + Part 요약 3줄
- [ ] 제목/설명에 핵심 키워드 2개(예: ‘AI 에이전트’, ‘결제’)를 각각 2회 이상 포함
- [ ] 방송 종료 후 15분 내 타임스탬프(챕터) 6개 이상 추가 *(운영 목표: 10~15분)*
  - (필수) 첫 줄 `00:00` 포함 여부 확인(유튜브 챕터 자동 인식)
  - (권장) 저장 후 1~2분 뒤 **챕터 1개 클릭 테스트**(반영 지연/인식 실패 조기 발견)
- [ ] (중요) 고정댓글/설명란에 링크/타임스탬프가 **코드블록(백틱)**으로 감싸져 있지 않은지 10초 확인(모바일 클릭/챕터 인식 사고 방지)
- [ ] (중요) 플레이스홀더가 남아있지 않은지 확인 *(예: `YYYY-MM-DD`, `LINK_HERE`, `KST HH:MM`, `__:__`)*

## 고정댓글(복붙용)

### 0) 복붙 전에 읽기(운영자 메모 — 붙여넣지 말 것)
- 링크는 **`https://`로 시작하는 한 줄 단독**으로 유지(괄호/추가 문장/백틱/코드블록은 링크 깨짐/클릭성 저하 가능)
- (중요) 링크 줄은 `-` 같은 불릿 없이 **URL만 단독 줄**로 두는 게 가장 안전합니다(모바일 클릭/복사 안정)
- `https://LINK_HERE`만 실제 링크로 교체
- `업데이트(운영 로그): KST HH:MM`의 `KST HH:MM`는 실제 시각으로 교체(부담이면 업데이트 줄은 삭제해도 OK)
- 아래 타임스탬프 블록의 `__:__`는 **방송 후 실제 영상 재생 시간**으로 교체(placeholder 남기지 않기)
- (사고 방지) **타임스탬프/챕터 블록에는 `KST`를 절대 섞지 말기** (운영 로그는 `KST`, 챕터는 `00:00`부터 영상 재생 시간)

운영 팁(동선 최소):
- **라이브 중 1차 고정댓글은 “링크 1개만”** 붙여도 OK
- 종료 직후에 타임스탬프/운영 로그까지 합쳐서 **1회 업데이트**로 마무리(과다 수정 방지)

### 2) 운영/메모 룰(붙여넣지 말 것)
- 업데이트 시각은 **KST HH:MM(시계)** — 예: `KST 16:12` / 라이브 종료 직후 10~15분 내 반영 목표
- 위 타임스탬프는 **영상 재생 시간** 기준: `00:00`부터 시작 — 보통 `MM:SS`, 길면 `H:MM:SS`
- 챕터 자동 인식 최소 조건: `00:00` 포함 **3줄 이상**. 운영은 최소 6줄 목표.
- 고정댓글/설명란은 **코드블록(백틱)**으로 감싸지 말고 평문으로 붙여넣기(모바일 클릭/챕터 인식 안정성)
