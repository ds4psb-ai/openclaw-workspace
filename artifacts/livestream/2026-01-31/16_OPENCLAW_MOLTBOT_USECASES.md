# OpenClaw (구 Moltbot) 2026 사용 사례 (라이브에 넣을 한 문단 + 안전 가이드)

## 라이브에서 30초로 말할 요약 (복사/붙여넣기)
> 표기 팁: 라이브에서는 처음 1회만 **"OpenClaw (구 Moltbot)"**로 소개하고, 이후에는 OpenClaw로 통일하면 시청자 혼선을 줄일 수 있음.

- "OpenClaw (구 Moltbot)는 텔레그램 같은 메신저를 **AI 에이전트의 리모컨**으로 바꿔주는 게이트웨이입니다. 해외에서도 ‘폰에서 명령 → 서버에서 실행’ 패턴으로 개인 비서를 운영한 사례가 꾸준히 보고되고, 오늘 시연도 같은 철학입니다. **자동화는 데모를 넘어 운영(로그/스케줄/버전/권한)까지 붙어야** 실전에서 힘을 발휘합니다."

## 근거 링크
- MiniMax 튜토리얼(텔레그램에 OpenClaw 붙이기, 구 Moltbot 문서지만 개념 동일): https://platform.minimax.io/docs/solutions/moltbot
- OpenClaw 텔레그램 문서(Privacy/admin/requireMention 등): https://docs.openclaw.ai/channels/telegram

## 명칭 혼선 방지(짧게)
- 자료/블로그에 남아 있는 **Moltbot** 표기는 이전 명칭이며, 현재 명칭은 **OpenClaw**입니다.
- 라이브에선 첫 1회만 `OpenClaw (구 Moltbot)`로 소개하고, 이후엔 `OpenClaw`로 통일(슬라이드/자막/채팅 고정문구도 동일 규칙 적용).

## 안전 가이드(짧게)
- 프라이버시/권한:
  - 그룹에서 멘션 없이 동작하게 하려면 Telegram **/setprivacy disable** 또는 봇 관리자(admin) 권한 필요(그룹마다 재초대가 필요할 수 있음)
- 운영/보안(기본값은 “거절”, 필요한 것만 허용):
  - 토큰/키는 절대 노출 금지(레포/스크린 공유/OBS 소스/로그 캡처 시 특히)
  - 메신저 명령은 **allowlist + 승인(approval) + `requireMention`/prefix + `dry-run` 우선 적용 + 1회 실행 원칙(한 번에 하나만 실행)** 가드레일로 작게 시작(처음엔 읽기 전용 명령부터 권장)
  - 외부 공개 대시보드 금지(라이브 데모 포함, 로컬/사설망 권장) — 데모 계정이라도 접근 제어 없는 URL은 공유하지 않기
  - 라이브 시작 전 1분 점검: 화면 공유/OBS 소스의 토큰·환경변수·터미널 히스토리 노출 여부 확인
  - 송출 직전 개인 채팅에서 테스트 1회(의도한 채널/권한/프리픽스 확인) 후 본 방송 채팅에서 실행
