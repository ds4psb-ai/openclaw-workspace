# 방송 체크리스트

## (시간 없을 때) 최소 체크 5개
- [ ] **로컬 녹화 ON + 저장경로/용량 확인**(REC 카운터가 실제로 도는지 1초 확인)
- [ ] **알림/개인정보 노출될 탭·창 닫기**(메일·DM·결제·관리자)
- [ ] **마이크/데스크탑 오디오 10초 테스트**(입력 레벨/클리핑/싱크)
- [ ] **YouTube Studio 스트림 헬스 + 계정/스트림 대상 확인**(잘못된 계정/키 사고 방지)
- [ ] **KST(시계) vs 영상 재생 시간(`__:__`) 분리 기록 준비**(첫 메모 `00:00 오프닝`)

## 60분 전
- [ ] 전원/충전 상태 확인(노트북 사용 시 어댑터 연결)
- [ ] 로컬 녹화 저장 경로 + 디스크 여유 용량 확인(권장 **50GB+**)
- [ ] 네트워크 업로드 속도 확인(권장 **업로드 10Mbps+**, 가능하면 유선)
- [ ] 방해금지/알림 끄기(OS/메신저/브라우저 푸시) + 사운드 출력 장치 확인
- [ ] OBS/브라우저에서 알림/개인정보(메일·DM) 노출될 **탭/창 닫기** → *노출될 수 있는 것만 정리해도 사고 확률이 크게 떨어짐*
- [ ] (권장) **화면 공유 안전 체크**: 화면 공유(또는 창 공유) ON/OFF 상태를 한 번 확인하고, 개인 탭/앱 열기 전 1초만 “공유 중인지” 재확인(사고 방지)
- [ ] **오디오 사전 점검**: 마이크 입력 레벨/노이즈/클리핑 확인 + 10초 테스트 녹화 후 재생(소리/싱크)
- [ ] (권장) **OBS 로컬 녹화 포맷**: 가능하면 `mkv` 권장(방송 중 크래시/강제종료에도 파일 손상 확률 ↓, 종료 후 필요하면 mp4로 리먹스)
  - (OBS 리먹스 빠른 동선) OBS `File → Remux Recordings…`에서 `mkv → mp4` 변환 *(보통 재인코딩 없이 컨테이너만 변환)*
- [ ] (권장) **OBS 녹화 트랙(오디오) 확인**: 마이크/데스크탑 오디오가 녹화 파일에 *둘 다* 들어가는지 10초 테스트로 확인(방송은 정상인데 로컬 녹화가 무음/한쪽만 나오는 사고 방지)
- [ ] (권장) 시스템 팝업 방지: OS 업데이트/백업/클라우드 동기화(Drive/iCloud 등)로 인한 알림·대역폭 점유가 없게 정리
- [ ] (권장) **브라우저 프로필 분리**: 데모용(노출 OK) / 개인용(메일·DM·결제·관리자) 탭을 분리해서 사고 확률 줄이기
- [ ] (권장) **비밀번호 매니저/자동완성 팝업 방지**: 1Password/Bitwarden 등 자동완성 제안이 뜰 수 있는 로그인/결제 탭은 미리 닫거나, 데모 탭에서는 자동완성 비활성화(화면 공유 중 팝업 방지)
- [ ] (권장) **오디오/블루투스 변수 최소화**: 가능하면 유선 마이크/유선 이어폰 우선, 무선이면 배터리/자동 전환(멀티포인트)으로 인한 소리 끊김 가능성만 미리 점검
- [ ] (권장) YouTube Studio 로그인/채널 계정 확인(잘못된 계정으로 스트림 관리/고정댓글 수정하는 사고 방지)
- [ ] 유튜브 제목/설명/고정댓글 초안 준비(`20_YT_TITLE_DESC_PIN.md`)
- [ ] 고정댓글/설명란 링크 확인
- [ ] (보안) 화면 공유 전: 토큰/키/.env/대시보드 주소 노출될 탭 닫기
- [ ] (권장) YouTube Studio/채팅 창을 **팝아웃(별도 창)**으로 분리해두기(데모 탭 이동 중에도 헬스/채팅을 놓치지 않게)
- [ ] (권장) **OBS 캡처 소스 점검**: 팝아웃 채팅/Studio(및 개인 메신저/알림 창)가 방송 화면에 잡히지 않게, 캡처 대상(디스플레이/윈도우/앱) 1회 확인

- [ ] **유튜브 스트림 상태 확인**: 연결/지연/경고(YouTube Studio의 스트림 헬스)
- [ ] (권장) **스트림/예약 방송 대상 확인**: 오늘 라이브(예약된 스트림)를 제대로 선택했는지 1초 확인(잘못된 스트림/키로 방송하는 사고 방지)
- [ ] 유튜브 라이브 설정 확인: 채팅 가능/슬로우모드(필요 시)/모더레이터(가능하면 1명)
- [ ] (권장) **채팅 운영 안전장치**: 모더레이터 1명 지정 또는 차단 단어 3~5개만 추가(링크 스팸/도배 대비)
- [ ] (권장) **지연(레이턴시/latency) 모드** 확인(저지연/초저지연/일반 중 선택) + 채팅 반응 속도가 운영에 맞는지 10초만 확인

- [ ] **13:55 카톡방 전체 멘션** 준비: `10_KAKAO_ALL_MENTION.md` 열어두고, 시계/타이머 알림 맞추기
- [ ] 진행용 런오브쇼 문서 열어두기: `30_RUN_OF_SHOW_14-18.md`
- [ ] 플랜B 자산(캡처/녹화본/미러링크) 탭 열어두기 (`50_DEMO_PLAN_A_B.md` / `35_TIMESTAMP_TEMPLATE.md` / 자료 링크)
- [ ] 타임스탬프 메모용 문서/메모앱 열어두기(방송 중 **영상 재생 시간 `__:__`만** 빠르게 기록)
- [ ] (권장) **KST 시계**(Clock/메뉴바)도 한 곳에 고정해두기(운영 이벤트 `KST HH:MM` 기록용)
- [ ] (헷갈림 방지) **KST(시계)** vs **영상 재생 시간(00:00 기준)**을 분리해서 기록할 준비
- [ ] (운영 팁) 고정댓글은 **링크 1개 먼저** 붙이는 흐름으로 갈 준비(광고 티 ↓ / 나머지는 방송 후 타임스탬프로 정리)
