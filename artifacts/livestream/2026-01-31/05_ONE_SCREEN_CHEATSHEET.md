# One-screen ops cheat sheet (라이브 중 이 한 장만 켜두기)

## 시간 표기 규칙(헷갈림 방지)
- **챕터/타임스탬프 = `__:__` (영상 재생 시간, 00:00 기준)**
  - 보통 `MM:SS`, 길면 `H:MM:SS` (문서 안에서만 일관되면 OK)
  - (주의) 라이브 레이턴시 때문에 **실제 시계(KST)**와 **영상 재생 시간**은 항상 다를 수 있음 → 챕터는 무조건 **영상 재생 시간**만.
  - (유튜브 챕터 자동 인식) 첫 줄은 **반드시 `00:00`**
- **운영 이벤트 = `KST HH:MM` (시계, 접두어 `KST` 꼭 붙이기)**
  - 예: `KST 17:05 자료 링크 고정댓글 게시`

## (복붙용) 라이브 중 메모 템플릿
- 챕터 메모(영상 재생 시간): `__:__ 무엇을 했는지(짧게)` *(예: `00:00 오프닝` / `12:34 WOW 데모`)*
- 운영 로그(KST 시계): `KST HH:MM 무엇을 업데이트/확인했는지`
- 플랜B 전환(옵션): `플랜B 전환 __:__ (사유 1단어)`

> 규칙 1개만: **`KST`는 운영 로그에만**, 챕터/타임스탬프 블록에는 절대 섞지 않기.

## 라이브 중 최소 루프(운영 동선)
1) 진행: `30_RUN_OF_SHOW_14-18.md`
2) 메모: 영상 재생 시간 `__:__`만 계속 찍기 (첫 줄 `00:00 오프닝`)
   - (옵션) 플랜B 전환이 있었으면: `플랜B 전환 __:__ (사유 1단어)` 1줄만 추가
3) 장애/지연: 2분만 원인 확인 → 안 풀리면 `50_DEMO_PLAN_A_B.md`로 플랜B

## 고정댓글 운영(과다 수정 방지)
- 방송 중: **링크 1개만 먼저** 붙이기 (예: 자료/체크리스트)
- 종료 직후: `35_TIMESTAMP_TEMPLATE.md`로 챕터 정리 → 고정댓글/설명란에 **1회** 업데이트
- (주의) 링크/타임스탬프는 **코드블록(백틱)으로 감싸지 말기**(모바일 클릭/챕터 인식 저하 방지)

## 종료 직후 60초 루프
- 메모앱 `__:__` 목록 → `35_TIMESTAMP_TEMPLATE.md`에 한 번에 정리
- 챕터 블록 → 고정댓글 먼저, 그다음 설명란
  - (필수) 챕터/타임스탬프 첫 줄이 `00:00`인지 확인(유튜브 챕터 자동 인식)
  - (권장) 저장 후 1~2분 뒤 **챕터 1개 클릭 테스트**(반영 지연/인식 실패 조기 발견)
- 마지막으로 `KST HH:MM` 1줄 로그(예: `KST 18:12 고정댓글/설명란 업데이트 완료`)

## 저장/반영 확인(10초)
- 고정댓글/설명란 수정 후: **새로고침 1회**(정말 저장/고정됐는지 확인)
- 가능하면 **시크릿/로그아웃 창에서 링크 1개 + 챕터 클릭 1개만** 테스트(권한/챕터 인식 사고 방지)

## 플레이스홀더 최종 체크(사고 방지)
- YouTube 입력란에서 한 번만 검색:
  - (팁) **Mac: `⌘F` / Windows: `Ctrl+F`**로 아래 키워드만 1회씩 검색하고 끝내기(과다 수정 방지)
  - `LINK_HERE` / `https://LINK_HERE`
  - `YYYY-MM-DD`
  - `KST HH:MM`
  - `__:__` *(타임스탬프를 실제 값으로 채우고도 placeholder가 남았는지)*
