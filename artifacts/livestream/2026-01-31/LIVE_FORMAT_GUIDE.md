- **챕터/타임스탬프 = `__:__` (영상 재생 시간, 00:00 기준)**

## A/B 전환 멘트

### 플랜A → 플랜B 전환 시

**결제/로그인 플로우 실패:**
```
"지금 화면이 꼬였네요.
실시간이니까 이런 일도 있죠.
일단 미리 준비해둔 캡처/짧은 녹화본으로 ‘정상 플로우’를 먼저 설명드리고,
바로 다시 시도해볼게요."
```

**자동화/권한 반영이 안 될 때:**
```
"지금 원하는 결과가 바로 안 나오네요.
이럴 때 실제로 어떻게 확인하는지(상태/로그/재시도)를 보여드릴게요.
일단 흐름은 준비한 자료로 설명하고 이어갈게요."
```

**전체 실패(하드 스탑):**
```
"오늘 라이브에서 100% 완성은 못 했지만,
어디서 막히는지, 왜 막히는지 같이 봤잖아요.
이게 진짜 개발이에요.
고쳐서 후속 영상으로 완성본 보여드릴게요!"
```

## (중요) 챕터 붙여넣기 5초 규칙
- 첫 줄은 **반드시 `00:00`**
- `00:00 ...` 챕터 라인은 **불릿/들여쓰기 없이** 각 줄을 **단독 라인**으로
- 챕터 라인들 사이에 **빈 줄/설명 문장** 끼우지 않기(연속 라인 유지)
- 챕터 블록 안에 **`KST ...` 운영 로그 섞지 않기**(필요하면 빈 줄로 분리해서 아래쪽)
- 챕터 인식이 불안하면: **설명란에 먼저 붙이는 쪽이 보통 더 안정적**
