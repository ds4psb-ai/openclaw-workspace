# 방송 후속 작업 (권장: 종료 후 30분 이내 완료)

> 리플레이 정리만 하는 경우: **0–4번을 우선 완료**하고, 5–6번은 필요할 때만 실행하세요(시간이 없으면 0–4만으로 종료해도 운영상 충분합니다).

## 0) 종료·저장 확인 (실수 방지)
- [ ] **YouTube Studio에서 스트림을 종료하고 Ended 상태(종료됨)를 확인한 후** OBS 로컬 녹화를 OFF *(순서 고정: YouTube 종료 확인 → OBS 종료, 종료 누락·파일 손상 방지, 종료 버튼은 연타하지 않기. YouTube 종료 확인 전 OBS부터 끄지 않기. 종료 확인 전 브라우저/OBS 강제 종료 금지)*
- [ ] (권장) YouTube Studio에서 **스트림 Ended(종료됨)와 저장 상태가 정상인지** 10초 확인(상태 꼬임 방지)
- [ ] (권장) 리플레이 **공개 범위(비공개/일부공개/공개)가 의도한 값인지** 10초 확인(공개 범위 오설정 방지)
- [ ] (권장) 제목 앞의 `LIVE`/`라이브` 표기가 남아 있다면 리플레이 문맥에 맞게 1회 정리(검색/클릭 혼선 방지)
- [ ] 녹화 파일이 실제로 저장됐는지 **파일 존재 확인 + 5–10초 재생**으로 확인(영상·오디오가 모두 정상인지 함께 점검)
- [ ] (권장) OBS 사용 시 녹화 종료 직후 3–5초 대기 후 파일 확인(파일 쓰기 마무리 지연을 미저장으로 오해하는 사고 방지)
- [ ] (권장) 파일명에 날짜/회차 식별자(예: `2026-01-31_live`)가 있는지 1회 확인(아카이브 혼동 방지)
- [ ] (선택) 원본 파일을 다른 드라이브/클라우드에 1회 백업(복사해 두기, 업로드 중 사고 대비 · 가능하면 백업 경로도 한 줄 메모)
- [ ] (선택, OBS) 로컬 녹화를 `mkv`로 했다면: 필요할 때만 `mkv → mp4` **Remux(무손실 컨테이너 변환)** 진행(보통 재인코딩 없이 컨테이너만 변환). OBS 메뉴: `File → Remux Recordings…`

## 1) 타임스탬프/리캡 정리 (권장: 종료 후 10–15분 이내)
- [ ] 방송 중 찍어둔 `__:__`(영상 재생 시간) 메모를 `35_TIMESTAMP_TEMPLATE.md`에 먼저 정리 *(라이브 중에는 메모앱만 사용하고, 템플릿 편집은 종료 후 1회만)*
- [ ] **첫 줄은 `00:00`**로 시작(챕터 자동 인식/시청자 점프 유도, `KST` 시각과 혼용 금지)
- [ ] 정리 전 챕터 블록에 `__:__`/`KST HH:MM` 플레이스홀더·미완성 줄이 남아있지 않은지 1회 확인(오류 업로드 방지)
- [ ] (운영 메모) `__:__`는 **영상 재생 시간(00:00 기준)**, “업데이트:”는 **KST(시계)**로 분리
- [ ] (실수 방지) 메모앱에 `KST ...` 로그가 섞여 있어도, 유튜브 챕터로 붙일 때는 `00:00 ...` 라인만 따로 선택해 복붙

## 2) 고정댓글 업데이트 (종료 후 1회 편집 → 설명란 1회 동기화, 총 2회 반영, 동일 본문 유지)
- [ ] **원칙 요약:** 고정댓글 1회 수정 + 설명란 1회 동기화(총 2회)만 수행하고 즉시 종료(오탈자/링크 오류가 아니면 즉시 재수정 금지)
- [ ] (모드 공통) 라이브 당일/리플레이 정리 모드 모두 동일하게 **고정댓글 1회 + 설명란 1회(총 2회, 동일 본문 유지)**만 반영(한쪽만 반영하고 종료하지 않기, 2회 반영 완료 후 즉시 종료)
- [ ] (리플레이 정리 모드) 멘션 관련 로그(`KST HH:MM 멘션 완료`)는 새로 추가/수정하지 않기(멘션 재전송 금지 원칙과 동일)
- [ ] (순서 고정) **고정댓글 저장 확인 → 핀(고정) 상태 확인 → 설명란 저장 확인** 순서로 진행(중간 새로고침/탭 이동 금지, 순서 변경 금지)
- [ ] (예외 처리) 한쪽 저장이 실패했으면 반대쪽을 먼저 건드리지 말고, **실패한 쪽 저장만 1회 재시도 후** 다음 단계로 이동(재시도도 실패하면 해당 단계와 반대쪽 반영을 모두 중단하고 `KST HH:MM 저장 실패(고정댓글/설명란)` 로그 한 줄만 남기고 종료)
- [ ] (저장 원칙) 반영 확인 중에는 **저장 연타/연속 수정 금지** — 반영 지연(1–3분)은 정상일 수 있으니 확인과 수정을 분리하고, 필요 시 최소 5분 후 **고정댓글 1회 + 설명란 1회(총 2회, 동일 본문)**로만 재동기화
- [ ] (운영 원칙) 방송 중에는 고정댓글을 자주 수정하지 말고, **링크 1개만 게시 → 종료 직후 타임스탬프/리캡 1회 업데이트**로 마무리(과다 수정 방지, 라이브 종료 전 재게시/재정리 금지)
- [ ] (중복 방지) 고정댓글 업데이트는 **기존 고정댓글 본문 1회 편집**으로 처리하고, 기존 고정댓글이 없을 때만 새 댓글 1회 작성 후 즉시 고정(기존 고정댓글이 있으면 새 댓글 작성 금지, 같은 본문 재게시/재고정 반복 금지)
- [ ] (권장) 편집 전 현재 고정댓글 본문을 메모앱에 1회 복사해 백업(오편집/덮어쓰기 시 즉시 복구용)
- [ ] (결정식) 종료 직후 챕터 반영은 **고정댓글 1회 + 설명란 1회 = 총 2회(동일 본문)**로 고정(한쪽만 반영하고 끝내지 않기, 오탈자/링크 오류가 아니면 즉시 연속 재수정 금지)
- [ ] (예외 처리) 기존 고정댓글이 아예 없으면: **새 댓글 작성 → 즉시 Pin(고정) → 저장 확인** 순서로 1회만 처리
- [ ] 자료 링크 1줄(단독 줄) + (선택) `업데이트: KST HH:MM` 1줄 추가(예: `업데이트: KST 18:12`) — **KST 시계 기준** *(플레이스홀더가 아닌 실제 시각으로 교체, 이전 회차 시각 복붙 금지. 업데이트 시각을 넣지 않을 경우 해당 줄은 통째로 삭제하고 빈 줄도 남기지 않기)*
  - (실수 방지) 자료 링크가 아직 확정되지 않았다면 임시 플레이스홀더를 남기지 말고, **검증된 기존 링크 1개**만 유지
  - (형식) 업데이트 시각은 `KST 09:05`처럼 **24시간제 + 앞 0 유지**로 통일(`KST 9:5`/`KST 24:00` 표기 금지, 검색/로그 정렬/자동 파싱 안정). 같은 회차에서는 표기 형식을 끝까지 동일하게 유지
  - (중요) 링크는 **불릿 없이 URL 단독 한 줄**(예: `https://...`)로 두기(모바일 클릭/복사 안정)
  - (주의) 실제 고정댓글에는 **백틱 없이 평문**으로 쓰기(모바일 클릭/가독성 유지)
  - (링크 운영 팁) 링크는 가능하면 **`https://`로 시작하는 한 줄 단독 텍스트**로 두기(괄호/추가 문장/백틱/코드블록은 링크가 깨지거나 클릭 편의가 떨어질 수 있음)
- [ ] (다음 회차 준비) 질문 포맷 문구 저장: `Q: 직무 / 상황 / 원하는 결과 (한 줄)` (`60_QA_PROTOCOL.md`와 동일 포맷 유지)
- [ ] 위에서 정리한 타임스탬프/리캡을 그대로 복붙(챕터 블록 중간에 설명 문장/구분선 삽입 금지, `KST ...` 로그는 블록 밖으로 분리)
  - (중요) 타임스탬프(00:00… 라인들)는 **빈 줄/설명 문장 없이 연속 라인으로** 붙여넣기(챕터 인식 안정)
  - (형식) 챕터 라인은 **불릿(-/•)·들여쓰기 없이** 줄 맨 앞부터 `00:00` 형태로 유지
  - (형식) `업데이트: KST ...` 라인은 타임스탬프 블록 **위/아래 아무 곳에 두되**, 챕터 블록(00:00… 라인들) 내부에는 빈 줄을 넣지 않기
  - (주의) 타임스탬프 블록(00:00… 라인들)에는 `KST ...` 줄을 섞지 않기(챕터 인식 안정)
- [ ] (복붙 직전) 템플릿의 `https://LINK_HERE` / `https://LINK_HERE_2` / `https://example.com` / `KST HH:MM` / `YYYY-MM-DD` / `__:__` / `— ... —` 같은 플레이스홀더/예시가 **남아있지 않은지** 빠르게 1회 확인
- [ ] (복붙 직전) 챕터 라인 시작에 **앞 공백/불릿(-/•)** 이 끼지 않았는지 1초 확인(인식 실패 예방, 줄 끝 불필요 공백도 함께 제거)
- [ ] (복붙 직전) 챕터 라인이 **`00:00` 포함 최소 3줄(권장 6줄 이상)**인지 최종 1회 확인(자동 인식 안정)
- [ ] (복붙 직후) 붙여넣기/수정 후 **저장 버튼 비활성화(또는 저장 완료 토스트)**를 1초 확인하고, 확인 전 탭 이동/새로고침하지 않기(저장 누락 방지)
- [ ] (권장) 고정댓글에 올린 타임스탬프 블록은 이후 **설명란에도 동일하게 1회 반영**(총 2회 반영: 고정댓글 1회 + 설명란 1회. 권장 순서: **고정댓글 저장 확인 → 핀(고정) 상태 확인 → 설명란 저장 확인**. 기준 본문은 `35_TIMESTAMP_TEMPLATE.md` 정리본 1개만 사용)
- [ ] (실수 방지) 고정댓글 반영 직후, **같은 최종 본문을 다시 복사해** 설명란에 붙여넣기(중간 임의 수정 금지, 본문 드리프트 방지)
- [ ] (실수 방지) 설명란 반영 직후, 고정댓글/설명란에 공통으로 들어간 **챕터 라인(최소 1개, 권장 3개)**의 순서/표현이 같은지 10초 대조(한쪽만 수정되는 불일치 방지)
- [ ] (중복 방지) 반영 확인 중에는 같은 본문으로 저장을 반복하지 말고, **최소 1–3분 대기 후 새로고침 1회로만 재확인**(저장 버튼 연타 금지, 단 깨진 링크/명확한 오탈자만 즉시 1회 보정)
- [ ] (중복 수정 방지) 반영 직후 5분 안에는 저장/수정 버튼을 다시 누르지 않기(오탈자·깨진 링크 같은 명확한 오류만 예외)
- [ ] (원칙) 반영 확인 단계와 재수정 단계를 분리: 확인이 끝나기 전에는 본문을 다시 고치지 않기(착시로 인한 연속 수정 방지, 저장 연타 금지)
- [ ] (순서 고정) 위 결정식(고정댓글 1회 + 설명란 1회, 총 2회)을 유지하고, 반영 지연처럼 보여도 오탈자/링크 오류가 아니면 **최소 5분 대기 후 1회만** 재수정
- [ ] (실수 방지) 설명란 반영 전, 고정댓글에 붙인 **최종 챕터 블록 전체**를 다시 1회 복사해 그대로 붙여넣기(부분 복사 금지, 고정댓글/설명란 불일치 방지)
- [ ] (리플레이 팁) 고정댓글에 “오늘/지금/방금…” 같은 문구가 남아있으면 “이 영상/이번 세션…”으로 바꾸기
- [ ] (리플레이 혼동 방지) 제목/설명에 남은 실시간 표기(예: `14:00–18:00`, `오늘`)는 리플레이 문구로 1회 정리
- [ ] (실수 방지) 수정/저장 후 **고정댓글이 실제로 핀(고정) 상태인지** 10초 확인(댓글 최상단 `고정됨` / `Pinned by ...` 배지 기준, 수정하다가 고정이 풀리는 사고 방지)
- [ ] (확인 팁) 고정 상태 점검 전 댓글 정렬이 **인기순/Top comments**인지 먼저 확인(최신순에서는 위치가 달라 보여 놓치기 쉬움)
- [ ] (실수 방지) **저장 확인을 먼저 끝낸 뒤** 고정 상태 확인 단계에서만 새로고침 1회 진행(계정/권한 꼬임 방지, 저장 전 새로고침 금지)
- [ ] (권장) 저장 후 1–3분 뒤 **시크릿/로그아웃 창에서 챕터 1개만 클릭 테스트**(반영 지연/인식/클릭 동작을 10초 확인). 실패 시 즉시 재수정하지 말고, 설명란 새로고침 1회 후 1회만 재확인
- [ ] (권장) 챕터 제목은 **모바일 한 줄 기준(약 20자 내외)**으로 유지(길면 잘려서 탐색성이 떨어짐)
- [ ] (권장) **시크릿/로그아웃 창에서 링크 1개도 함께 확인**(권한/로그인 착시로 “나만 열리는 링크”를 놓치지 않기)
- [ ] (문제 시) 5분 이상 챕터 인식이 없으면 **고정댓글은 그대로 두고**, 설명란 챕터 블록만 **`00:00 ...` 연속 라인으로 저장**한 뒤 1분 후 1회만 재확인(연속 재수정·저장 연타 금지, 실패 시 라이브 종료 후 재점검으로 이월)
- [ ] (운영 로그) 고정댓글/설명란 수정이 끝나면: `KST HH:MM 고정댓글/설명란 업데이트 완료` 한 줄만 남기기(추적용, 중복 수정/중복 게시 방지, 로그는 **한 곳에만** 기록)
- [ ] (권장) **업데이트 완료 직후 스크린샷 1장 저장**(반영 증빙/기억용)

- 아래 3블록이면 운영상 충분(링크/시간만 바꾸면 됩니다)
- `https://LINK_HERE` 같은 플레이스홀더가 남지 않게 마지막에 1회 확인
- (선택) “업데이트: KST …” 라인은 추적용. 바쁘면 생략 가능.
- (중요) 실제 고정댓글에는 **코드블록(백틱)으로 감싸지 말고**, 아래 내용을 **평문으로 그대로** 붙여넣기
- (챕터 인식/가독성) **타임스탬프(00:00… 라인들)는 한 덩어리로 연속**해서 붙여넣기(중간에 빈 줄/설명 문장/기호를 끼우지 않기)

(평문 템플릿 — 값 교체 후 복붙)
