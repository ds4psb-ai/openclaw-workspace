# 방송 후 후속 작업(30분)

## 0) 종료/저장(실수 방지)
- [ ] 스트림 종료 → 로컬 녹화 STOP
- [ ] 녹화 파일이 실제로 저장됐는지 **파일 크기/재생**으로 10초만 확인
- [ ] (선택) 원본 파일을 다른 드라이브/클라우드로 복사 시작(업로드 중 사고 대비)
- [ ] (선택, OBS) 로컬 녹화를 `mkv`로 했다면: 필요할 때만 `mkv → mp4` 리먹스(OBS `File → Remux Recordings…`)

## 1) 타임스탬프/리캡 정리(10~15분 컷)
- [ ] 방송 중 찍어둔 `__:__`(영상 재생 시간) 메모를 `35_TIMESTAMP_TEMPLATE.md`에 먼저 정리
- [ ] **첫 줄은 `00:00`**로 시작(챕터 자동 인식/시청자 점프 유도)
- [ ] (운영 메모) `__:__`는 **영상 재생 시간(00:00 기준)**, “업데이트:”는 **KST(시계)**로 분리

## 2) 고정댓글 업데이트(정리본 복붙)
- [ ] 자료 링크 1줄 + (가능하면) “업데이트: `KST HH:MM`(예: `KST 18:12`)” 한 줄 포함 — **시계 기준**
  - (링크 운영 팁) 링크는 가능하면 **`https://`로 시작하는 한 줄 단독 텍스트**로 두기(괄호/추가 문장/백틱/코드블록은 링크가 깨지거나 클릭성이 떨어질 수 있음)
- [ ] 질문 포맷 재공지
- [ ] 위에서 정리한 타임스탬프/리캡을 그대로 복붙
- [ ] (권장) 고정댓글에 올린 타임스탬프는 이후 **설명란에도 동일하게 복사**(검색/공유/유입에 유리)
- [ ] (챕터 자동 인식) 최소 조건: `00:00` 포함 **3줄 이상**(운영은 6줄 이상 권장)
- [ ] (리플레이 팁) 고정댓글에 “오늘…” 같은 문구가 남아있으면 “이 영상…”으로 바꾸기
- [ ] (실수 방지) 고정 후 **새로고침 1회** 해서 *진짜로* 고정됐는지 확인(계정/권한 꼬임 방지)
- [ ] (운영 로그) 고정댓글/설명란 수정이 끝나면: `KST HH:MM 고정댓글/설명란 업데이트 완료` 1줄만 남기기(나중에 추적용)

**고정댓글 템플릿(최소)**
- 아래 3블록만 있으면 운영적으로 OK(링크/시간만 바꾸면 됨)
- `LINK_HERE` / `https://LINK_HERE` / `KST HH:MM` 같은 플레이스홀더가 남지 않게 마지막에 1회 확인
- (중요) 실제 고정댓글에는 **코드블록(백틱)으로 감싸지 말고**, 아래 내용을 **평문으로 그대로** 붙여넣기

(평문 템플릿 — 그대로 복붙)

자료 링크(1개)
https://LINK_HERE

업데이트: KST HH:MM

00:00 오프닝
12:34 Part 1 — ...
34:56 Part 2 — ...

## 3) 설명란/챕터(가능하면)
- [ ] **설명란 상단**에 자료 링크 1줄(고정댓글과 동일해도 OK)
- [ ] 타임스탬프(=챕터) Part 1/Part 2/Part 3
- [ ] 챕터 자동 인식을 위해 **첫 줄은 `00:00`**로 시작(예: `00:00 오프닝`)
- [ ] (형식 팁) `00:00`(오프닝) / `12:34`(세그먼트) / `01:02:10`(긴 라이브)처럼 **동일 문서 안에서만 일관**되게 쓰면 OK
- [ ] (리플레이 팁) 설명/고정댓글에 `14:00–18:00(KST)` 같은 **실시간 스케줄 표기**가 남아있으면 제거/수정(시청자 혼동 방지)
- [ ] (리플레이 팁) “오늘 라이브에서…” 같은 문구는 “이 영상에서…”로 바꾸면 깔끔(다음날/다음달에도 어색하지 않음)
- [ ] (운영 팁) 설명란 저장 후 **챕터가 자동 인식되는지**(00:00 포함) 10초만 확인
- [ ] (운영 팁) 챕터/설명란 반영은 몇 분 지연될 수 있음 → 저장 후 1~2분 뒤 새로고침해서 한 번 더 확인

## 4) 리플레이/공유 전 안전 스캔(2분)
- [ ] 관리자/대시보드/결제/개인정보 노출 구간이 없는지 1회 확인
- [ ] 문제가 있으면: 바로 비공개/편집(YouTube Studio) 플로우로 전환
- [ ] (추가 안전) 자료 링크(노션/구글독스/드라이브)가 **권한 문제 없이 열리는지** 10초만 테스트(시청자 이탈 방지)

## 5) 다음 라이브 예고 문구(짧게)
- [ ] 예시: “다음 라이브: (일시) 14–18시 — 성능/디자인 → 데이터 기반 추론 → 수익화.”
