## 1) 타임스탬프/리캡 정리 (권장 10–15분 컷)
- [ ] 방송 중 찍어둔 `__:__`(영상 재생 시간) 메모를 `35_TIMESTAMP_TEMPLATE.md`에 먼저 정리
- [ ] **첫 줄은 `00:00`**로 시작(챕터 자동 인식/시청자 점프 유도)
- [ ] 정리 전 `__:__` 플레이스홀더/미완성 줄이 남아있지 않은지 1회 확인(오류 업로드 방지)
- [ ] (운영 메모) `__:__`는 **영상 재생 시간(00:00 기준)**, “업데이트:”는 **KST(시계)**로 분리
- [ ] (실수 방지) 메모앱에 `KST ...` 로그가 섞여 있어도, 유튜브 챕터로 붙일 때는 `00:00 ...` 라인만 따로 선택해 복붙

## 2) 고정댓글 업데이트(정리본 붙여넣기)
- [ ] (운영 원칙) 방송 중에는 고정댓글을 자주 수정하지 말고: **링크 1개만 게시 → 종료 직후 타임스탬프/리캡 1회만 업데이트** 흐름으로 마무리(과다 수정 방지)
- [ ] 자료 링크 1줄(단독 줄) + (선택) `업데이트: KST HH:MM` 1줄 추가(예: `업데이트: KST 18:12`) — **KST 시계 기준**
  - (형식) 업데이트 시각은 `KST 09:05`처럼 **24시간제 + 앞 0 유지**로 통일(검색/로그 정렬 안정)
  - (중요) 링크는 **불릿 없이 URL 단독 한 줄**(예: `https://...`)로 두기(모바일 클릭/복사 안정)
  - (주의) 실제 고정댓글에는 **백틱 없이 평문**으로 쓰기(모바일 클릭/가독성 유지)
  - (링크 운영 팁) 링크는 가능하면 **`https://`로 시작하는 한 줄 단독 텍스트**로 두기(괄호/추가 문장/백틱/코드블록은 링크가 깨지거나 클릭 편의가 떨어질 수 있음)
- [ ] 질문 포맷 재공지(필요 시, 채팅 공지 최대 2회 이내): `Q: 직무 / 상황 / 원하는 결과 (1줄)`
- [ ] 위에서 정리한 타임스탬프/리캡을 그대로 복붙(챕터 블록 중간에 설명 문장/구분선 삽입 금지)
  - (중요) 타임스탬프(00:00… 라인들)는 **빈 줄/설명 문장 없이 연속 라인으로** 붙여넣기(챕터 인식 안정)
  - (형식) 챕터 라인은 **불릿(-/•)·들여쓰기 없이** 줄 맨 앞부터 `00:00` 형태로 유지
  - (형식) `업데이트: KST ...` 라인은 타임스탬프 블록 **위에 배치하고, 사이에 빈 줄 1개** 유지
  - (주의) 타임스탬프 블록(00:00… 라인들)에는 `KST ...` 줄을 섞지 않기(챕터 인식 안정)
- [ ] (복붙 직전) 템플릿의 `https://LINK_HERE` / `https://LINK_HERE_2` / `KST HH:MM` / `YYYY-MM-DD` / `— ... —` 같은 플레이스홀더/예시가 **남아있지 않은지** 1초 확인
- [ ] (복붙 직전) 챕터 라인 시작에 **앞 공백/불릿(-/•)** 이 끼지 않았는지 1초 확인(인식 실패 예방)
- [ ] (복붙 직전) 챕터 라인이 **`00:00` 포함 최소 3줄(권장 6줄 이상)**인지 최종 1회 확인(자동 인식 안정)
- [ ] (복붙 직후) 붙여넣기/수정 후 **저장 버튼 비활성화(저장 완료 상태)**인지 1초 확인(저장 누락 방지)
- [ ] (권장) 고정댓글에 올린 타임스탬프는 이후 **설명란에도 동일하게 복사**(순서: **고정댓글 → 설명란**, 검색/공유/유입에 유리)
- [ ] (리플레이 팁) 고정댓글에 “오늘…” 같은 문구가 남아있으면 “이 영상…”으로 바꾸기
- [ ] (실수 방지) 수정/저장 후 **고정댓글이 ‘진짜로’ 핀(고정) 상태인지** 10초 확인(수정하다가 고정이 풀리는 사고 방지)
- [ ] (실수 방지) 고정 후 **새로고침 1회** 해서 *진짜로* 고정됐는지 확인(계정/권한 꼬임 방지)
- [ ] (권장) 저장 후 1–3분 뒤 **챕터 1개만 클릭 테스트**(반영 지연/인식/클릭 동작 10초)

- [ ] (운영 로그) 고정댓글/설명란 수정이 끝나면: `KST HH:MM 고정댓글/설명란 업데이트 완료` 1줄만 남기기(나중에 추적용)
- [ ] (권장) **업데이트 완료 직후 화면 스크린샷 1장 저장**(“진짜로 반영됐는지” 증빙/기억용)
