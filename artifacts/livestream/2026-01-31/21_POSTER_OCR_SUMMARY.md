# 포스터 OCR 요약 (OCR 후 수기 보정)

원본 포스터: **AI 영상 제작 워크플로우 ‘일반 클래스’ (Crebit)**

검증 메모: OCR 한계가 있으므로 **개강 요일·시간/가격/장소명은 원본 포스터 기준으로 재확인**을 권장합니다. 특히 요일-날짜 일치 여부도 함께 확인해 주세요. 설명란의 **커리큘럼/문의 링크가 모두 최신 URL인지** 게시 직전에 점검해 주세요. 리허설 사본이 아닌 **최종 게시본** 기준으로 반드시 대조하세요.
- 운영 팁: 혜택가/일정 문구는 변동 가능성이 있으므로, 라이브 당일 공지 직전에 **최종 게시본 기준으로 1회 재대조**하고, 본문/고정댓글/설명란 표기를 한 번에 맞춰 주세요.
- 게시 직전 체크(권장, 30초):
  - [ ] 개강일/요일/시간 (요일-날짜 일치 + 시간대 표기(KST) 일관성 확인)
  - [ ] 요일·날짜 충돌 시 최종 게시본 기준으로 본문/고정댓글/설명란 표기를 **하나의 표현으로 통일**
  - [ ] 가격(혜택가 숫자 + VAT 포함/별도 + 한글/숫자 표기 일치)
  - [ ] 혜택가 표기 병기 규칙 일치(예: `24만 원(240,000원)` 형태로 함께 표기)
  - [ ] 장소(지명 표기 통일 + 지도 링크 열림 1회 확인, 최종 게시본 기준으로 대조)
  - [ ] 문의 링크(카카오톡 채널, 최종 게시본 기준 URL) 클릭 동작 1회 확인(가능하면 모바일에서도 1회 포함)
  - [ ] 커리큘럼 링크(최종 게시본 기준 URL) 클릭 동작 1회 확인
  - [ ] 최종 게시본과 대조한 캡처 1장 보관(수정 이력 추적용)
  - [ ] 포스터 버전 정보(파일명/수정 시각) 한 줄 기록
