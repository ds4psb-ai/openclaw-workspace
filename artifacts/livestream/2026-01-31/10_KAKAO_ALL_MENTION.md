# 13:55 카톡방 전체 멘션 (붙여넣기)

> 목적: **후킹 강함 + 판매글 티 최소화**

## 버전 A (가장 직관/강한 후킹 / 최신 공지 반영)
```
@전체 오늘 **14:00–18:00(KST)** 유튜브 라이브 합니다.
오늘은 **코드 0줄 + 자연어 채팅만**으로
1) 앱/홈페이지 **성능·디자인 업그레이드**
2) 지난 2강의 ‘씬별 프롬프트 일관성 유지 앱’을 **데이터 기반 프롬프트 추론**으로 확장 → **스토리보드(시간코드/샷 목표/일관성 체크)**까지
3) **Polar 카드결제**까지 붙여서 ‘운영 가능한 상태’로 만들기
이 3가지를 라이브로 그대로 보여드릴게요. (중간에 체크리스트/템플릿도 공유)
```

## 버전 B (문제-해결/호기심)
```
@전체 “AI로 뭘 만들긴 하는데 왜 운영/수익화로는 안 이어지지?”
오늘 **14:00–18:00(KST)** 라이브에서 **코드 없이 채팅만으로**
성능·디자인 개선 → 데이터 기반 프롬프트 추론 고도화 → Polar 결제 연결까지 한 번에 보여드립니다.
```

## 버전 C (공부방 톤/부담 낮음)
```
@전체 오늘 라이브는 툴 소개가 아니라, ‘개인화+범용화 AI 에이전트 서비스’를 **운영 가능한 형태**로 완성하는 실전입니다.
(코드 X, 채팅만) **14:00–18:00(KST)**: 성능/디자인 개선 → 데이터 기반 프롬프트 추론 고도화 → Polar 결제 연결.
```

## 운영 팁
- 시간 표기는 **KST 기준**으로 쓰기(예: `14:00–18:00(KST)`).
- 링크는 본문에 길게 붙이지 말고, **고정댓글/설명란**에만(광고 티 감소).
- 멘션 후 3~5분 뒤, 댓글로 “오늘 3파트(업그레이드/일관성/결제)”만 짧게 한 번 더.
- ‘상업’은 엔딩에만: “필요한 분만” 톤 유지.
