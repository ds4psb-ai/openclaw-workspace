## 데모 컨셉(한 줄)
“텔레그램에 한 줄만 던지면 → NotebookLM이 ‘브랜드 브레인’으로 정리하고 → Antigravity가 페이지를 업데이트하고 → (가능하면) 결제·운영 루프까지 이어진다.” *(라이브 중 실반영은 승인 후 최대 1회만 진행, 중복 실행 금지)*

## 시퀀스(10분 타임라인)

### 00:00–01:00 훅 (말로만)
- 멘트: “이건 챗봇이 아니라 **내 PC를 실제로 움직이는 비서**예요. 메신저에서 한 줄 던지면, 승인된 작업만 문서/블로그/홈페이지로 반영됩니다.”
- 운영 메모(권장): 훅 시작 시점에 `__:__ 오프닝 훅` 1줄만 메모해두기(종료 후 챕터 정리 속도↑).

### 01:00–04:00 (장면 1) NotebookLM ‘브랜드 브레인’ 3분 데모
- 스토리: 바이럴 방/채널의 기존 글/스크립트/홍보 문구를 ‘소스’로 넣으면, NotebookLM은 **소스 기반으로만** 답해서 톤이 안 깨짐.
- (업그레이드 포인트) 여기서 바로 **스토리보드 표(timecode/shot_goal)**까지 뽑아내면 ‘기획→제작’이 한 번에 이어져서 **감탄 포인트(‘와’ 모먼트)**가 생긴다.
- 임팩트 한 줄: “프롬프트를 사람이 관리하는 게 아니라 **NotebookLM이 브랜드 브레인**이 된다.”
- 시연 포인트(화면)
  - NotebookLM에 소스 체크박스로 포함/제외 보여주기(공식 기능)
  - Chat에 질문 1개:
    - “오늘 라이브 요약을 ‘중년 남성 사장님’ 타깃으로 6문장으로 써줘. 마지막은 상업성 티 안 나게.”

### 04:00–07:00 (장면 2) OpenClaw (구 Moltbot): 텔레그램 한 줄 → ‘게시/배포 초안’ 생성(승인 후 반영)
- 스토리: “배포해줘” 한 줄이 업무 지시서로 변환되어 Git/노션/블로그/홈페이지 업데이트 작업 큐가 자동으로 쌓이는 장면.
- 임팩트 한 줄: “글 쓰는 것보다 **‘올려줘’라고 말하는 시간이 더 짧다**.”
- 시연 포인트(화면)
  - 텔레그램에서 봇에게 명령(예시, **먼저 dry-run 결과 확인 → 승인 후 실반영 1회만 진행**):
    - “NotebookLM 최신 요약을 가져와서: 1) 홈페이지 공지 섹션 업데이트 문구 작성 2) 고정댓글/설명란 문구 업데이트 3) Git 커밋 메시지까지 만들어줘.”
    - (안전장치) 실반영 전에 “지금 바로 반영할까요?” 확인 질문 1회 후 실행(라이브 중 오반영/오적용 방지, 중복 실행 금지)
  - 결과물: Git diff/commit 준비 화면 또는 노션/문서에 생성된 결과 보여주기
  - 원샷 가드레일(운영): **같은 명령 재실행 금지**, 승인 문구 확인 후 1회만 반영, 실패 시 즉시 Plan B로 전환

### 07:00–08:00 (장면 3) 무드보드: 60초 스타일 합의 (‘거장 DNA’ 시각화)
- 스토리: 키워드만으로 **이미지/색/구도**가 한 번에 정리되면 ‘미학’이 갑자기 쉬워짐.
- 임팩트 한 줄: “감으로 고르는 게 아니라, **보드로 합의**한다.”
- 시연 포인트: 무드보드에서 보드 1개 만들고 ‘조금 더 어둡게/더 미니멀하게’ 같은 자연어 수정 1번.

### 08:00–09:00 (장면 4) Antigravity(안티그래비티): 공지 섹션/랜딩 ‘즉시 반영’
- 스토리: 라이브 중에 바뀐 문구/섹션이 **홈페이지에 즉시 반영**되는 장면이 신뢰를 만든다.
- 임팩트 한 줄: “이제 업데이트는 ‘개발’이 아니라 **대화**다.”
- 시연 포인트
  - 공지 섹션(라이브 일정/핵심 3파트/툴) 업데이트
  - (가능하면) Polar 버튼/안내 섹션이 노출되는 것까지

### 09:00–10:00 마무리 훅(오디오 팟캐스트로 확산)
- 스토리: 라이브가 끝나면 NotebookLM Audio Overview로 “오늘 방송 2분 요약(Brief)”을 뽑아 바이럴 방에 공유한다(가능하면 **종료 후 10분 내**).
- 임팩트 한 줄: “라이브가 끝나도 **AI가 후반 작업을 다 해줘서** 바이럴이 계속 돈다.”
- 시연 포인트
  - Audio Overview 포맷(Brief/Deep Dive 등) 선택 화면을 짧게 보여주기
  - 마무리 멘트 고정: “방송 끝나고 2분 요약 오디오를 방에 바로 공유할게요.”
