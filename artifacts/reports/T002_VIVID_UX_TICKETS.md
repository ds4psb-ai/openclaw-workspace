# T002 – Vivid 메가앱 UX 구현 티켓

**목표:** P0 백로그 → 화면 컴포넌트 단위 구현 티켓  
**Activation 정의:** DNA Lab에서 첫 영상 업로드 → 분석 완료 → 결과 확인  
**담당:** @ag-vivid @bomi

---

## 📋 티켓 목록

### 🟢 P0-1: 온보딩/진입

| 티켓 ID | 제목 | 화면/컴포넌트 | 설명 | 우선순위 |
|---------|------|---------------|------|----------|
| VIV-001 | Intent-driven Entry | `Landing.tsx` or `Home.tsx` | 첫 화면에 3가지 목적 버튼 추가: "영상 분석(DNA) / 스토리 만들기 / 바로 제작". 클릭 시 해당 메가앱으로 바로 진입 + 샘플 데이터 제공 | 🔴 P0 |
| VIV-002 | Value-before-signup | `DNALab.tsx` or `Preview.tsx` | 로그인 전에도 샘플 영상 1개 분석 결과 미리보기 제공. 비로그인 사용자도 "이런 결과가 나온다"를 볼 수 있게 | 🔴 P0 |

**구현 노트:**
- VIV-001: 기존 랜딩이 있으면 버튼 3개 + 라우팅 추가, 없으면 새 컴포넌트 생성
- VIV-002: 샘플 분석 결과 JSON/mock 데이터 필요, 로그인 체크 로직 분기

### 🟡 P0-2: 업로드/분석 플로우

| 티켓 ID | 제목 | 화면/컴포넌트 | 설명 | 우선순위 |
|---------|------|---------------|------|----------|
| VIV-003 | 업로드 정보 표시 | `Upload.tsx` or `UploadArea.tsx` | 업로드 단계에서 **지원 포맷/권장 길이/예상 시간** 즉시 표기. 파일 선택 전/후 모두 표시 | 🔴 P0 |
| VIV-004 | 분석 진행률 표시 | `AnalysisProgress.tsx` (신규) | 분석 시작 시 **progress bar + 남은 단계** 표시. 단계: 큐 → 분석 → 요약 → 프리뷰 | 🔴 P0 |
| VIV-005 | 에러 복구 UI | `AnalysisError.tsx` (신규) | 실패 시 **1클릭 재시도** 버튼 + 에러코드/원인 가이드 (용량/포맷/네트워크 분기) | 🔴 P0 |

**구현 노트:**
- VIV-003: 업로드 영역에 helper text 추가 (포맷: mp4/mov, 권장: 30초~5분, 예상: ~2분)
- VIV-004: 백엔드에서 진행 단계 polling/websocket 필요. 없으면 프론트에서 타이머 기반 fake progress
- VIV-005: 에러 타입별 메시지 매핑 테이블 필요

## 🔄 구현 순서 (권장)

```
1. VIV-003 (업로드 정보) ← 가장 빠르게 적용 가능
2. VIV-004 (진행률 표시) ← 사용자 경험 즉시 개선
3. VIV-005 (에러 복구) ← 이탈 방지
4. VIV-006 + VIV-007 (결과 화면) ← Activation 완료 단계
5. VIV-001 + VIV-002 (온보딩) ← 진입 개선
6. VIV-008 + VIV-009 (크레딧) ← 과금 플로우
7. VIV-010 (계측) ← 효과 측정
```
