## 2. Clustering System

### Hybrid Clustering (E2)
```
Score = VDG_WEIGHT(0.6) * vdg_similarity + EMBEDDING_WEIGHT(0.4) * embedding_similarity
Threshold: 0.75 (75% 이상 유사해야 같은 패턴)
```

### Cluster Name Generation (VDG 4축)
```
"[카테고리]•[훅타입] [딜리버리] ([오디오특성])"
예: "뷰티•POV 빠른컷 (트렌딩음악)"
```

### Ancestor + Depth System
```
ancestor_score >= ANCESTOR_THRESHOLD
→ 기존 클러스터의 "변형"으로 간주
→ depth = parent.depth + 1
```
