## 8. Key Design Patterns

### Data Provider Pattern
- 서버: 구조화된 데이터만 반환
- Claude Desktop: 자체 모델로 분석
- 결과: 서버 LLM 비용 $0!

### Elicitation Pattern
- 20개 초과 or 비용 발생 → 사용자 확인 요청
- FastMCP 2.14+ 지원

### Kelly Criterion
- 투자 전략 개념 적용
- 콘텐츠 Go/No-Go + 최적 투자 비율
