## VIV-001: Intent-driven Entry

### 목표
첫 화면에서 사용자가 "뭘 하러 왔는지" 바로 선택하게

### UI 스펙
```
┌─────────────────────────────────────┐
│     🎬 Vivid에 오신 걸 환영해요!     │
│                                     │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐│
│  │  🔬    │ │  📝    │ │  🎥    ││
│  │ DNA Lab │ │ 스토리  │ │ 바로제작 ││
│  │ 영상분석 │ │ 만들기  │ │        ││
│  └─────────┘ └─────────┘ └─────────┘│
│                                     │
│  (로그인 없이도 DNA Lab 샘플 체험!)  │
└─────────────────────────────────────┘
```

### 동작
- 버튼 클릭 → 해당 메가앱으로 라우팅
- DNA Lab 클릭 시 → 샘플 데이터와 함께 진입 (VIV-002와 연계)

### 구현 포인트
- 버튼 3개 + 간단한 설명
- 반응형 (모바일: 세로 배치)
- 애니메이션 optional

## VIV-002: Value-before-signup

### 목표
로그인 전에도 "이런 결과가 나온다"를 보여줘서 전환율 ↑

### UI 스펙
```
┌─────────────────────────────────────┐
│  🔬 DNA Lab 체험하기                 │
│                                     │
│  ┌─────────────────────────────────┐│
│  │ [샘플 영상 썸네일]               ││
│  │ "이 영상의 DNA를 분석해볼까요?"  ││
│  │                                 ││
│  │ [분석 시작하기] ← 클릭하면      ││
│  │                   결과 미리보기  ││
│  └─────────────────────────────────┘│
│                                     │
│  ※ 내 영상 분석은 로그인 후 가능    │
└─────────────────────────────────────┘
```

### 동작
- 샘플 영상 1개 하드코딩 (또는 API에서)
- 클릭 → 미리 준비된 분석 결과 표시
- 결과 하단에 "내 영상도 분석하기" CTA → 로그인 유도

### 구현 포인트
- 샘플 분석 결과 mock data 필요
- 로그인 상태 체크 → 분기 처리

## VIV-003: 업로드 정보 표시

### 목표
업로드 전에 "이 파일 올려도 되나?" 불안 해소

### UI 스펙
```
┌─────────────────────────────────────┐
│  📤 영상 업로드                      │
│                                     │
│  ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐│
│  │                               │ │
│  │   여기에 파일을 드래그하거나    │ │
│  │   [파일 선택] 버튼을 클릭      │ │
│  │                               │ │
│  └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘│
│                                     │
│  ℹ️ 지원 포맷: MP4, MOV, WebM       │
│  📏 권장 길이: 30초 ~ 5분            │
```

### 구현 포인트
- helper text 추가 (기존 업로드 컴포넌트에)
- 파일 validation 로직 추가
- 예상 시간 = 파일 크기 기반 계산

## VIV-004: 분석 진행률 표시

### 목표
"지금 뭐 하는 거지?" → "아 이 단계구나" 명확하게

### UI 스펙
```
┌─────────────────────────────────────┐
│  🔄 분석 중...                       │
│                                     │
│  ═══════════════════════░░░░░ 65%   │
│                                     │
│  ✅ 큐 등록                          │
│  ✅ 영상 분석                        │
│  🔄 요약 생성 ← 현재 단계            │
│  ⬜ 프리뷰 생성                      │
│                                     │
│  예상 남은 시간: 약 1분              │
└─────────────────────────────────────┘
```

### 동작
- 단계별 상태: pending → processing → done
- 진행률 바 + 퍼센트
- 예상 남은 시간 (optional)

### 구현 포인트
- 백엔드 API 필요: `GET /api/analysis/{id}/status`
- polling 또는 websocket
- 없으면 프론트에서 fake progress (타이머 기반)

## VIV-005: 에러 복구 UI

### 목표
에러 나도 "뭐가 잘못됐고, 어떻게 하면 되는지" 바로 알려줌

### UI 스펙
```
┌─────────────────────────────────────┐
│  ❌ 분석 실패                        │
│                                     │
│  ┌─────────────────────────────────┐│
│  │ 🎥 파일 포맷을 확인해주세요      ││
│  │                                 ││
│  │ 지원 포맷: MP4, MOV, WebM       ││
│  │ 업로드한 파일: AVI              ││
│  └─────────────────────────────────┘│
│                                     │
│  [다시 시도하기] [다른 파일 업로드]  │
└─────────────────────────────────────┘
```

### 에러 타입별 메시지

| 에러 코드 | 원인 | 메시지 |
|-----------|------|--------|
| FORMAT_ERROR | 지원 안 하는 포맷 | "지원하는 포맷: MP4, MOV, WebM" |
| SIZE_ERROR | 용량 초과 | "최대 500MB까지 가능해요" |
| DURATION_ERROR | 너무 길거나 짧음 | "30초~5분 영상을 권장해요" |
| NETWORK_ERROR | 네트워크 문제 | "인터넷 연결을 확인해주세요" |
| SERVER_ERROR | 서버 문제 | "잠시 후 다시 시도해주세요" |

### 구현 포인트
- 에러 코드 → 메시지 매핑 테이블
- 1클릭 재시도 버튼
- 에러 로그 수집 (optional)

## VIV-006: 결과 화면 Next Action

### 목표
분석 끝났는데 "이제 뭐 하지?" → 명확한 2가지 선택지

### UI 스펙
```
┌─────────────────────────────────────┐
│  ✅ 분석 완료!                       │
│                                     │
│  [DNA 요약 카드 - VIV-007]          │
│                                     │
│  ┌───────────────┐ ┌───────────────┐│
│  │ 🔄 이 DNA로   │ │ 📝 스토리로   ││
│  │ 변주 만들기   │ │ 넘기기        ││
│  └───────────────┘ └───────────────┘│
│                                     │
│  [더보기 ▼] ← 기타 옵션             │
└─────────────────────────────────────┘
```

### 동작
- 메인 CTA 2개만 prominent
- 기타 옵션은 "더보기"로 숨김
- 클릭 → 해당 메가앱으로 데이터 전달

### 구현 포인트
- 기존 버튼 3개 이상 → 2개 + 더보기
- DNA 데이터 다음 앱으로 전달

## VIV-010: 퍼널 이벤트 추가

### 목표
Activation 퍼널 측정으로 개선 포인트 파악

### 이벤트 스키마

```javascript
// step1: 진입
analytics.track('activation_step1_entry', {
  source: 'landing' | 'direct' | 'referral',
  user_type: 'new' | 'returning'
});

// step2: 업로드 완료
analytics.track('activation_step2_upload', {
  file_size: number,
  file_format: string,
  duration_seconds: number
});

// step3: 분석 시작
analytics.track('activation_step3_analysis_start', {
  analysis_id: string
});

// step4: 분석 완료
analytics.track('activation_step4_analysis_complete', {
  analysis_id: string,
  duration_ms: number,
  success: boolean
});

// step5: 다음 액션 클릭
analytics.track('activation_step5_next_action', {
  action: 'remix' | 'story' | 'other',
  analysis_id: string
});
```

### 구현 포인트
- 기존 analytics 서비스 확인 (GA4/Mixpanel/자체)
- 각 티켓 구현 시 해당 이벤트 호출 추가
