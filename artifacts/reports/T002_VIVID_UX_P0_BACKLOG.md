# T002 – Vivid 메가앱 UX P0 백로그 (보미 🐰)

가정: 신규 유저의 Activation = **DNA Lab에서 첫 영상 업로드 → 분석 완료 → 결과(프리뷰/요약) 확인**

## P0 목표 (2주 내)
- Activation 완료율 ↑
- 첫 성공까지 시간 ↓
- 오류/대기 중 이탈 ↓

---

## P0-1 온보딩/진입 (가장 먼저)
1) **Intent-driven entry** (첫 화면에서 3가지 목적 버튼)
- “영상 분석(DNA) / 스토리 만들기 / 바로 제작”
- 선택하면 해당 메가앱으로 바로 진입 + 샘플 데이터 제공

2) **Value-before-signup**
- 로그인 전에도 샘플 영상 1개 분석 결과 미리보기 제공

---

## P0-2 업로드/분석 플로우
3) 업로드 단계에서 **지원 포맷/권장 길이/예상 시간** 즉시 표기
4) 분석 시작 시 **progress + 남은 단계(큐→분석→요약→프리뷰)** 표시
5) 실패 시 **1클릭 재시도** + 에러코드/원인(용량/포맷/네트워크) 가이드

---

## P0-3 결과 화면
6) 결과 화면의 ‘다음 액션’ 2개로 제한
- “이 DNA로 변주 만들기” / “스토리로 넘기기”
7) 결과 요약 카드(한 화면)
- 캐릭터/톤/색감/샷 구성/음악 등 핵심 DNA를 5~7개 불릿으로

---

## P0-4 크레딧/과금
8) 실행 전 크레딧 소모 **명확히**
9) 크레딧 부족 시 **맥락형 페이월(중단 최소화)**

---

## 계측(최소)
- step1: 진입
- step2: 업로드 완료
- step3: 분석 시작
- step4: 분석 완료
- step5: 결과 화면에서 다음 액션 클릭
