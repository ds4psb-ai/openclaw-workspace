---

## 📝 P0 사용자 스토리 (우선순위순)

### 1. 진행률 표시 (P0-2-4)
**사용자 말:**
> "분석 시작했는데 화면이 멈춘 것 같아요. 얼마나 걸려요? 계속 기다려야 해요?"

**해결:**
- 실시간 진행률 바 + 단계 표시 (큐 → 분석 → 요약 → 완료)
- 예상 남은 시간 표시

**측정:**
- 분석 중 이탈률 (목표: -50%)

---

### 2. 크레딧 미리보기 (P0-4-8)
**사용자 말:**
> "이거 분석하면 크레딧 얼마나 써요? 모르니까 무서워서 못 누르겠어요."

**해결:**
- 실행 버튼 옆에 "8 크레딧 소모" 명시
- 내 잔여 크레딧 표시

**측정:**
- 분석 시작 클릭률 (목표: +30%)

---

### 3. 결과 요약 카드 (P0-3-7)
**사용자 말:**
> "DNA가 나왔는데 이게 뭔지 모르겠어요. 숫자랑 용어가 너무 많아요."

**해결:**
- 한 화면에 핵심 5개만 (캐릭터/톤/색감/구도/음악)
- 각 항목 한 줄 설명 + 아이콘
- "이 DNA의 특징: 봉준호 스타일의 긴장감 있는 구도"

**측정:**
- 결과 화면 체류 시간 (목표: +2분)

---

### 4. 다음 액션 제안 (P0-3-6)
**사용자 말:**
> "DNA 나왔는데... 그래서 뭘 해요? 다음 버튼이 10개나 있어요."

**해결:**
- 버튼 2개로 제한: "이 DNA로 변주" / "스토리로 넘기기"
- 나머지는 "더보기"로 숨김

**측정:**
- 결과 → 다음 단계 전환율 (목표: +40%)

---

### 5. 스타일 프리셋 (추가 제안)
**사용자 말:**
> "봉준호 스타일로 하고 싶은데 어디서 설정해요?"

**해결:**
- 분석 시작 전 "스타일 선택" 드롭다운
- 프리셋: 봉준호 / 왕가위 / 웨스 앤더슨 / 자동

**측정:**
- 프리셋 사용률

---

### 6. 목적별 진입 (P0-1-1)
**사용자 말:**
> "처음 들어왔는데 뭐부터 해야 할지 모르겠어요. 버튼이 너무 많아요."

**해결:**
- 첫 화면에 3개 선택지만:
  - "🧬 영상 분석하기"
  - "📝 스토리 만들기"  
  - "🎬 바로 제작하기"

**측정:**
- 온보딩 완료율 (목표: +50%)

---

### 7. 에러 복구 (P0-2-5)
**사용자 말:**
> "분석 실패했는데 왜 실패했는지 모르겠어요. 다시 하려면 처음부터?"

**해결:**
- 실패 사유 명확히 (파일 크기/포맷/네트워크)
- "1클릭 재시도" 버튼
- 문제 해결 가이드 링크

**측정:**
- 에러 후 재시도율 (목표: +60%)

---

### 8. 샘플 체험 (P0-1-2)
**사용자 말:**
> "가입하기 전에 어떤 건지 먼저 보고 싶어요."

**해결:**
- 로그인 없이 샘플 영상 분석 결과 미리보기
- "이런 결과를 얻을 수 있어요" 데모

**측정:**
- 비로그인 → 가입 전환율

---

### 9. 업로드 가이드 (P0-2-3)
**사용자 말:**
> "어떤 영상 올려도 돼요? 10분짜리도 돼요?"

**해결:**
- 업로드 버튼 옆에:
  - 지원 포맷: MP4, MOV, WebM
  - 권장 길이: 15초~3분
  - 최대 크기: 500MB
- 예상 분석 시간 표시

**측정:**
- 업로드 실패율 (목표: -70%)
