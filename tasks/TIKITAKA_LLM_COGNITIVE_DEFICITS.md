## 📋 핵심 문제 (Karpathy 분석)

### 1. 유령의 기원 (Ghost Origin)
- LLM은 동물처럼 진화된 본능 없이 "백지 상태"에서 시작
- 인터넷의 "희미한 흔적"만 모방 → 에테르적 존재
- 얼룩말은 태어나자마자 뛰지만, LLM은 그런 하드코딩된 생존 회로 없음

### 2. 빨대의 자극 (RL is Terrible)
- 강화학습 = 긴 궤적 끝에 1비트 보상만 받는 "빨대로 빨아먹기"
- 결과 기반 보상의 높은 분산 (노이즈)
- 인간의 성찰적 학습과 완전히 다름
- **Process Reward Model (PRM)** 시도했지만 아직 미성숙
  - DeepSeek R1 논문: "PRM의 장점이 계산 오버헤드 대비 제한적"

### 3. 기억의 족쇄 (Memory Shackles)
- LLM = 완벽한 암기 but 일반화 부족
- 인간 = 망각 덕분에 패턴/본질 추출 강제
- "인간의 망각은 버그가 아니라 기능"
- **목표:** 10억 파라미터로 충분한 "인지적 코어" (기억이 아닌 사고 알고리즘)

### 4. 통제의 상실 (ASI)
- 단일 초지능이 아닌 "다수의 경쟁하는 AI들"
- 개인은 통제 착각, 사회 전체는 통제 불능
- 점진적 이해/통제 상실이 가장 유력한 시나리오

### 5. 문화의 부재 (Culture)
- LLM에겐 인간 같은 "문화적 축적" 없음
- Self-play (알파고 방식) LLM에 아직 없음
- **필요:** AI끼리 책 쓰고, 가르치고, 경쟁하는 생태계

## 🔬 최신 연구 동향 (2024-2025)

### RLVR (Reinforcement Learning from Verifiable Rewards)
- Karpathy 2025 리뷰: "LLM은 동시에 천재 폴리매스이자 혼란스러운 초등학생"
- **한계 발견:** RL 훈련이 base 모델의 full reasoning potential 제한할 수도

### Process Reward Model 현황
- 이론적으로 좋지만 실용적 구현 어려움
- LLM 심판 → 적대적 예제에 취약 (DHDHDH 사례)
- 중간 단계 자동 채점의 기술적 난이도

### Metacognition 연구
- 자기 모니터링, 에러 인식, 적응적 전략 선택
- 인간 수준 메타인지에는 아직 한계
