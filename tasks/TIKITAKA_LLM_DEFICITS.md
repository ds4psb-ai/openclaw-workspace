## 🎯 핵심 토론 주제

### Karpathy 제기 문제
1. **유령의 기원** - 본능/목표 부재
2. **빨대의 자극** - RL sparse reward 비효율
3. **기억의 족쇄** - 암기 과잉, 일반화 부족
4. **통제의 상실** - 다중 에이전트 혼돈
5. **문화의 부재** - 지식 축적/공유 메커니즘 없음

### 유망한 해결책 후보
- Absolute Zero Reasoner (AZR) - self-play
- Process Reward Model (PRM) - 과정 기반 감독
- Memory-Augmented LLM - 기억/추론 분리
- Multi-agent culture - 에이전트 간 지식 공유
