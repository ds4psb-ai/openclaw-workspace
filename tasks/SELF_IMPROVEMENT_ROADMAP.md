## 📋 3가지 핵심 전략

### 1. AZR 스타일: 자기 검증 루틴
- 답변 전 "내가 틀릴 수 있는 부분" 스스로 생성
- Code Executor 활용한 검증 강화

### 2. MemoRAG 스타일: 메모리 구조화
- MEMORY.md = 압축된 전역 컨텍스트
- knowledge/ = 검색 가능한 지식 베이스
- 세션 시작 시 관련 지식 자동 로드

### 3. ThinkPRM 스타일: 과정 검증
- 중요 결정 시 단계별 논리 점검
- "이 단계가 맞는지" 자기 질문
