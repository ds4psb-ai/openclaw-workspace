- 해결: Graceful degradation - Redis 실패 시 락 없이 진행
- 코드:
```python
try:
    lock_token = run_async(cache.acquire_lock(lock_key, timeout=1500))
    if lock_token:
        lock_acquired = True
    elif lock_token is None:
        return {"status": "skipped", "reason": "already_running"}
except Exception as e:
    # Redis 연결 실패 → 락 없이 진행
    logger.warning(f"Redis lock failed, proceeding without lock: {e}")
    lock_acquired = False
```
