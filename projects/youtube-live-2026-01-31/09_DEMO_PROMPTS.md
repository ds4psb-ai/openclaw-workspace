# 09. 데모용 프롬프트 모음 (복붙용)

## 🎯 Part 2: 스토리보드 기능

### 2-1. 기본 스토리보드 추가
```
이 앱에 스토리보드 자동 생성 기능을 추가해줘.

요구사항:
1. 영상 분석 결과를 바탕으로 각 씬의 스토리보드 생성
2. 타임라인 형태로 시각화 (가로 스크롤)
3. 각 씬 카드에 표시할 것:
   - 씬 번호
   - 썸네일 이미지
   - 시작/종료 시간
   - AI 프롬프트 추천
4. Sora나 Veo에서 바로 쓸 수 있는 프롬프트 형식으로 출력
```

### 2-2. 드래그앤드롭 추가
```
스토리보드에 드래그앤드롭으로 씬 순서 변경 기능 추가해줘.
변경하면 자동으로 타임코드도 재계산되게.
```

### 2-3. 내보내기 기능
```
스토리보드를 PDF로 내보내기 기능 추가해줘.
PDF에는:
- 전체 스토리보드 요약
- 각 씬 카드 (이미지 + 프롬프트)
- 총 러닝타임
포함되게 해줘.
```

## 🧠 Part 3: 데이터 기반 추론

### 3-1. 패턴 학습 기능
```
데이터 기반 프롬프트 추론 기능 추가해줘:

1. 사용자가 올린 영상과 유사한 스타일 패턴 분석
2. 성공적인 프롬프트 패턴 데이터베이스 구축
3. 현재 영상에 맞는 프롬프트 자동 추천
4. 추천 이유도 함께 표시 ("이 씬은 OO 스타일과 유사해서...")
```

### 3-2. 스타일 매칭
```
"스타일 매칭" 기능 추가해줘:
- 드롭다운에서 스타일 선택 (시네마틱, 브이로그, 광고, 다큐)
- 선택한 스타일에 맞는 프롬프트 톤 조정
- 예시: 시네마틱 → "cinematic lighting, shallow depth of field..."
```

## 🎨 Part 4: 디자인 업그레이드

### 4-1. 전체 디자인 변경
```
디자인을 더 예쁘게 바꿔줘:

1. 다크모드 기본
2. 그라데이션 배경 (진한 파랑 → 보라)
3. 카드형 UI (둥근 모서리, 그림자)
4. 버튼에 호버 애니메이션
5. 부드러운 페이지 전환

참고: 노션이나 Linear 같은 깔끔한 느낌으로
```

### 4-2. 모바일 반응형
```
모바일에서도 잘 보이게 반응형으로 만들어줘:
- 768px 이하에서는 1열 레이아웃
- 햄버거 메뉴
- 터치 친화적인 버튼 크기 (최소 44px)
```

### 4-3. 로딩 상태
```
AI 분석 중일 때 로딩 UI 추가해줘:
- 스켈레톤 UI (깜빡이는 회색 박스)
- 진행률 표시 (%)
- "AI가 열심히 분석 중..." 메시지
```

## 💰 Part 5: Polar 결제 연동

### 5-1. 결제 버튼 추가
```
상단 헤더에 "Pro 업그레이드" 버튼 추가해줘:
- 보라색 그라데이션 버튼
- 클릭하면 이 URL로 이동: [Polar checkout 링크]
- 버튼 옆에 "✨ 무제한 분석" 텍스트
```

### 5-2. 가격 표시
```
가격 안내 섹션 추가해줘:

[무료]
- 월 5회 분석
- 기본 스토리보드

[Pro - $9.99/월]
- 무제한 분석
- 고급 스토리보드
- PDF 내보내기
- 우선 지원

"Pro 시작하기" 버튼은 [Polar 링크]로 연결
```

### 5-3. Pro 기능 잠금
```
무료 사용자가 Pro 기능 쓰려고 하면:
- "Pro 기능입니다" 모달 표시
- "업그레이드" 버튼으로 Polar 연결
- 부드러운 애니메이션으로 표시
```

## ⚠️ 에러 대응 프롬프트 (Bolt v2 자동 디버깅 스타일)

```
에러가 났어. 에러 메시지 분석하고 자동으로 수정해줘.
```

### 에러 발생 시 - 상세
```
방금 에러가 났어:
[에러 메시지 붙여넣기]

원인 분석하고 수정해줘.
```

### 에러 반복 시 (Bolt v2 스타일)
```
같은 에러가 계속 나.
다른 접근 방식으로 해결해줘.
이전 방식: [설명]
새로운 방식으로 시도해봐.
```

### 완전히 막혔을 때
```
지금 막혔어. 현재 상태:
- 하려는 것: [목표]
- 문제: [문제]
- 시도한 것: [시도]

다른 방법 제안해줘.
```

### 디자인 미세 조정
```
[특정 부분]의 디자인을 조금 바꿔줘:
- 색상을 더 진하게
- 여백을 좀 더 넓게
- 폰트 크기 키워줘
```

### 기능 롤백
```
방금 추가한 기능 원래대로 돌려줘.
그 전 버전이 더 나았어.
```

### 속도 개선
```
이 부분 로딩이 느려. 최적화해줘:
- 불필요한 렌더링 줄이기
- 코드 정리
```
