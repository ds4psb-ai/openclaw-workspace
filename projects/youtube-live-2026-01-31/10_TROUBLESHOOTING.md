# 10. 트러블슈팅 가이드

## 🚨 기술 문제

### 안티그래비티 응답 없음
**증상:** 프롬프트 입력 후 아무 반응 없음

**대응:**
1. 잠깐 기다리기 (30초)
2. 새로고침
3. 다른 브라우저로 시도

**멘트:**
> "AI가 열심히 생각 중인 것 같아요. 잠깐만요..."
> "새로고침 한 번 해볼게요. 이런 일도 가끔 있죠!"

---

### 안티그래비티 에러 발생
**증상:** 빨간 에러 메시지

**대응:**
1. 에러 메시지 읽기
2. 프롬프트 수정해서 재시도
3. 더 간단한 요청으로 쪼개기

**멘트:**
> "에러가 났네요. 이럴 때는 요청을 더 간단하게 쪼개면 돼요."
> "AI도 가끔 헷갈리나 봐요. 다시 해볼게요!"

---

### 클로드 코드 세션 끊김
**증상:** 연결 끊김 알림

**대응:**
1. 재연결 시도
2. 새 세션 시작
3. 이전 컨텍스트 요약해서 다시 입력

**멘트:**
> "세션이 끊겼네요. 잠깐 재연결할게요."

---

### Polar 연동 실패
**증상:** 결제 페이지 안 열림 / 에러

**대응:**
1. URL 다시 확인
2. Polar 대시보드 확인
3. 스크린샷으로 대체 설명

**멘트:**
> "Polar 쪽에서 잠깐 문제가 있나 봐요. 화면으로 보여드릴게요."

---

## 📺 방송 문제

### OBS 송출 끊김
**대응:**
1. OBS 확인 (녹화는 계속되는지)
2. 재연결 시도
3. 모바일 핫스팟 전환

**멘트:**
> "잠깐 기술 문제가 있어요. 바로 돌아올게요!"

---

### 마이크 문제
**증상:** 소리 안 들림 / 잡음

**대응:**
1. 마이크 음소거 확인
2. OBS 오디오 설정 확인
3. 다른 마이크로 전환

**멘트:**
> "소리 들리시나요? 채팅에 알려주세요!"

---

### 화면 공유 안 됨
**대응:**
1. OBS 소스 확인
2. 창 다시 선택
3. 화면 전체 공유로 전환

**멘트:**
> "화면 공유 잠깐 다시 할게요~"

---

## 💬 시청자 관련

### 채팅 도배 / 악플
**대응:**
1. 무시하고 진행
2. 심하면 타임아웃
3. 분위기 전환

**멘트:**
> "자, 다음 진행할게요~"

---

### 어려운 질문
**대응:**
1. 솔직하게 모른다고
2. 나중에 찾아보겠다고
3. 채팅/커뮤니티에 남겨달라고

**멘트:**
> "좋은 질문인데 지금 바로 답하기 어렵네요. 
> 채팅에 남겨주시면 라이브 후에 확인할게요!"

---

### 시청자 수 적음
**대응:**
1. 신경 쓰지 말고 진행
2. 다시보기 시청자도 많음
3. 퀄리티에 집중

**멘트:**
> "지금 보시는 분들 실시간 시청자시니까 더 집중해서 진행할게요!"

## 💳 Polar 결제 상세 트러블슈팅

### Polar 대시보드 접속 안 됨
**대응:**
1. 다른 브라우저로 시도
2. 시크릿 모드로 접속
3. 스크린샷으로 설명 (플랜B)

**멘트:**
> "Polar 쪽이 잠깐 느리네요. 미리 찍어둔 화면으로 설명할게요."

### Checkout 링크 에러
**대응:**
1. URL 재확인
2. polar.sh에서 직접 복사
3. 미리 준비한 백업 링크

### Webhook 수신 안 됨
**대응:**
1. endpoint URL 확인
2. 서버 로그 확인
3. 사전 녹화 영상으로 대체

**멘트:**
> "webhook이 아직 안 왔어요. 실제로는 이렇게 옵니다 (영상 재생)"

### Polar API 에러 코드
| 코드 | 의미 | 대응 |
|------|------|------|
| 400 | 잘못된 요청 | 파라미터 확인 |
| 401 | 인증 실패 | API 키 확인 |
| 404 | 상품 없음 | 상품 ID 확인 |
| 500 | 서버 에러 | 잠시 후 재시도 |
