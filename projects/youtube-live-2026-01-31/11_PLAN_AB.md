## Part 1: 스토리보드 기능

### 플랜 A (기본)
- 안티그래비티에서 실시간 프롬프트 입력
- 스토리보드 UI 실시간 생성
- 기능 추가도 라이브로

### 플랜 B (실패 시)
- 미리 만들어둔 스토리보드 앱 불러오기
- "시간 절약을 위해 미리 만든 버전 보여드릴게요"
- 핵심 기능만 설명

### 전환 멘트
> "안티그래비티가 잠깐 쉬고 싶대요 😅
> 미리 준비한 버전으로 보여드릴게요.
> 원리는 똑같으니까 집중해서 봐주세요!"

---

## Part 2: 디자인 업그레이드

### 플랜 A (기본)
- 실시간 디자인 요청
- 다크모드, 애니메이션 추가
- 반응형 테스트

### 플랜 B (실패 시)
- 미리 만든 예쁜 버전 보여주기
- Before/After 비교 슬라이드
- "실제로는 이렇게 됩니다"

### 전환 멘트
> "디자인 변경이 좀 느리네요.
> 미리 완성한 버전으로 비교해볼게요!"

---

## Part 3: Polar 결제 연동 ⭐ (가장 중요!)

### 플랜 A (기본)
1. Polar 대시보드에서 상품 생성 (라이브)
2. 앱에 결제 버튼 추가 (라이브)
3. Webhook 연동 (라이브)
4. 테스트 결제 성공

### 플랜 B (실패 시)
1. 미리 설정한 Polar 상품 사용
2. 미리 만든 결제 버튼 코드 복붙
3. Webhook은 스크린샷으로 설명
4. 사전 녹화된 테스트 결제 영상

### 플랜 C (최악의 경우)
- Polar 대시보드만 보여주면서 설명
- "실제로는 이렇게 연동됩니다" 슬라이드
- 라이브 후 영상 편집해서 추가

### 전환 멘트
> "Polar 쪽에서 잠깐 문제가 있어요.
> 미리 준비한 테스트 영상으로 보여드릴게요.
> 
> (영상 재생)
> 
> 보셨죠? 실제로 이렇게 됩니다!"
