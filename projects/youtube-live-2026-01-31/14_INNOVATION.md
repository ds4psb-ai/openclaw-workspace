```

                  │

## 🎙️ NotebookLM 팟캐스트 전략

### 라이브 후 자동 생성

```
1. 라이브 종료
2. 스크립트 → NotebookLM 업로드
3. Audio Overview 생성 (약 5분)
4. "10분 요약 팟캐스트" 완성!
5. 시청자에게 공유
```

### 멘트
```
"라이브 끝나면 10분짜리 팟캐스트로 만들어드릴게요.

NotebookLM이라는 구글 AI가
오늘 내용을 두 사람이 대화하는 형식으로 정리해줘요.

출퇴근길에 들으시면 복습 끝!
댓글에 링크 남길게요."
```

```

이게 왜 중요하냐면...

일관된 스타일의 프롬프트가 필요해요.

이 앱은 그걸 자동으로 만들어줘요.
