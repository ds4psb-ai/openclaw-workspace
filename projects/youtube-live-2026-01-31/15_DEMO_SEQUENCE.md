# 15. 10분 WOW 데모 시퀀스 - 실제 시연용

**목표:** 중년 남성들이 "와…" 하는 장면 3개
**시간:** 약 10분 (라이브 중간 또는 마지막)

---

## 🎯 핵심 컨셉

> "카톡/텔레그램에서 한 줄 던졌더니 비즈니스가 굴러가는 장면"

### 타깃 페르소나
- 50대 사장님/1인 사업자
- 부업 관심 있는 직장인
- "코딩은 모르지만 AI는 궁금한" 사람들

---

## 📍 데모 1: NotebookLM "브랜드 브레인" (3분)

### 스토리
> "여러분 채널 운영하면서 제일 힘든 게 뭐예요?
> 영상마다 톤이 달라지는 거 아니에요?
> 
> 이제 그거 AI가 해결해줍니다."

### 실제 시연
```
1. NotebookLM 열기
2. "휴머나이저 채널 스타일 가이드 + 바이럴 영상 스크립트 3개" 보여주기
3. 프롬프트: "이 스타일로 오늘 라이브 홍보 쇼츠 스크립트 3개 만들어줘"
4. 결과: 채널 톤에 맞는 스크립트 3개!
```

### 화면에 띄울 것
```
╔═══════════════════════════════════════════════════╗
║  📚 NotebookLM = "채널 브레인"                     ║
╠═══════════════════════════════════════════════════╣
║                                                   ║
║  바이럴 영상 모음 → 패턴 추출 → 일관된 톤 유지     ║
║                                                   ║
║  "프롬프트 일관성을 사람이 아닌 AI가 관리"        ║
║                                                   ║
╚═══════════════════════════════════════════════════╝
```

### 한 줄 임팩트
> "프롬프트 일관성을 사람이 컨트롤하는 게 아니라,
> 노트북이 '브랜드 브레인' 역할을 해줍니다."

---

## 📍 데모 2: 안티그래비티 "앱 생성" (3분)

### 스토리
> "NotebookLM에서 나온 이 스크립트,
> 이걸 앱으로 만들면 어떨까요?
> 
> '영상 넣으면 우리 채널 톤으로 자막/타이틀 자동 생성'
> 이런 앱을요."

### 실제 시연
```
1. 안티그래비티 열기
2. 프롬프트: "영상 업로드하면 채널 스타일에 맞는 
   자막/타이틀/설명을 자동 생성하는 앱 만들어줘"
3. 결과: 앱 UI 자동 생성!
4. (옵션) Polar 결제 버튼까지 추가
```

### 화면에 띄울 것
```
╔═══════════════════════════════════════════════════╗
║  🚀 안티그래비티 = "아이디어 → 앱"                 ║
╠═══════════════════════════════════════════════════╣
║                                                   ║
║  NotebookLM 브레인 + 안티그래비티 앱 생성          ║
║  = 내 채널만의 AI 도구!                           ║
║                                                   ║
╚═══════════════════════════════════════════════════╝
```

### 한 줄 임팩트
> "연구+기획+스토리보드까지 한 번에,
> 그걸 바로 앱으로 뽑아버리는 느낌."

---

## 📍 데모 3: Moltbot "자동 운영" (4분) - 하이라이트!

### 스토리
> "자, 이제 진짜 '와…' 하실 거예요.
> 
> 이 앱을 만들었으면, 운영도 자동화해야죠.
> 텔레그램에서 한 줄 던지면 어떻게 되는지 보세요."

### 실제 시연
```
1. 텔레그램 열기 (Moltbot 채팅)
2. 메시지: "오늘 라이브 요약을 블로그에 올려줘"
3. Moltbot 반응:
   - NotebookLM에서 요약 가져오기
   - 마크다운으로 변환
   - git commit & push
4. 결과: 실제 블로그에 글 올라감!
```

### 화면에 띄울 것 (2개 화면 분할)
```
┌─────────────────────┬─────────────────────┐
│  📱 텔레그램        │  💻 블로그/깃허브   │
│                     │                     │
│  "블로그에 올려줘"  │  [새 글 올라감!]    │
│                     │                     │
│  ✅ 완료!           │  📝 라이브 요약     │
└─────────────────────┴─────────────────────┘
```

### 한 줄 임팩트
> "이건 ChatGPT가 아닙니다.
> **내 컴퓨터를 직접 만지는 AI 비서**예요.
> 이메일도 보내고, 블로그도 올리고, 
> 파일 저장하고 업로드까지 다 대신 합니다."
