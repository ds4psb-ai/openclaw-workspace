## Polar 소개 (16:30-16:40)

### Polar란?
- 크리에이터/개발자를 위한 결제 플랫폼
- PG심사 없이 바로 시작
- 무통장입금 필요 없음
- 해외 결제도 OK

### 왜 Polar인가?
> "보통 결제 붙이려면 PG심사, 사업자등록, 복잡한 API 연동...
> Polar는 그냥 링크 하나로 끝입니다."

### 화면에 보여줄 것
- Polar 홈페이지 (https://polar.sh)
- 대시보드 미리보기
- 가격 정책 (무료 시작 가능)

## 연동 과정 (16:40-17:10)

### Step 1: Polar 계정 (16:40-16:45)
1. polar.sh 접속
2. GitHub로 로그인 (또는 이메일)
3. 대시보드 확인

**멘트:**
> "가입은 1분이면 됩니다. GitHub 계정 있으면 바로 연동."

### Step 2: 상품 만들기 (16:45-16:55)
1. Products → New Product
2. 이름: "AI 스토리보드 Pro"
3. 가격: $9.99/월 (예시)
4. 설명 추가

**멘트:**
> "상품 만드는 것도 이렇게 간단해요.
> 이름, 가격, 설명 - 끝!"

### Step 3: 앱에 연동 (16:55-17:10)

**프롬프트 예시:**
```
이 앱에 Polar 결제 버튼 추가해줘:
1. 상단에 "Pro 업그레이드" 버튼
2. 클릭하면 Polar 결제 페이지로 이동
3. 결제 완료 후 Pro 기능 활성화
4. Polar checkout 링크: [여기에 링크]
```

**멘트:**
> "자연어로 '결제 버튼 추가해줘' 하면 끝!
> API 연동? 필요 없어요. 링크만 넣으면 됩니다."
