# 03. 데모 진행 스크립트 (14:15-16:30)

## 🎯 데모 목표
- 지난주 앱에 스토리보드 기능 추가
- 데이터 기반 프롬프트 추론
- UI/UX 디자인 업그레이드

---

## Part 1: 앱 불러오기 (14:15-14:25)

### 액션
1. 안티그래비티 열기
2. 지난주 프로젝트 불러오기
3. 현재 상태 리뷰

### 멘트
> "자, 지난주에 만든 앱 불러올게요.
> 여기 보시면 씬 분석 기능까지 있죠?
> 오늘은 여기에 스토리보드를 추가합니다."

---

## Part 2: 스토리보드 기능 추가 (14:25-15:15)

### 2-1. 기능 설계 (14:25-14:40)

**프롬프트 예시:**
```
이 앱에 스토리보드 자동 생성 기능을 추가해줘.

요구사항:
1. 영상 분석 결과를 바탕으로 각 씬의 스토리보드 생성
2. 타임라인 형태로 시각화
3. 각 씬에 AI 프롬프트 추천
4. Sora나 Veo에서 바로 쓸 수 있는 형식으로
```

**멘트:**
> "보세요, 자연어로 기능 요청하면 바로 만들어줍니다.
> 코드 한 줄도 안 썼죠?"

### 2-2. 구현 확인 (14:40-14:55)

**체크포인트:**
- [ ] 스토리보드 UI 생성됐는지
- [ ] 타임라인 뷰 있는지
- [ ] 프롬프트 추천 기능 있는지

**멘트:**
> "와, 벌써 스토리보드 뷰가 생겼어요.
> 이걸 코드로 짜면 몇 시간인데..."

### 2-3. 개선 요청 (14:55-15:15)

**프롬프트 예시:**
```
스토리보드에 이런 기능 추가해줘:
1. 드래그앤드롭으로 씬 순서 변경
2. 각 씬에 메모 추가 기능
3. 전체 스토리보드 PDF 내보내기
```

**멘트:**
> "더 필요한 기능? 그냥 말하면 됩니다.
> '드래그앤드롭 추가해줘' - 끝!"

## Part 3: 데이터 기반 추론 (15:15-15:45)

### 3-1. 개념 설명 (15:15-15:25)

**멘트:**
> "지금까지는 단순 분석이었는데요,
> 이제 데이터를 학습해서 더 똑똑하게 만들 거예요.
> 
> 예를 들어, 비슷한 영상 100개 분석해서
> '이런 스타일엔 이런 프롬프트가 잘 먹힌다' 추론하는 거죠."

### 3-2. 기능 추가 (15:25-15:45)

**프롬프트 예시:**
```
데이터 기반 프롬프트 추론 기능 추가해줘:
1. 유사 영상 패턴 분석
2. 성공한 프롬프트 패턴 학습
3. 사용자 영상에 맞는 프롬프트 자동 추천
4. 추천 이유도 함께 표시
```
