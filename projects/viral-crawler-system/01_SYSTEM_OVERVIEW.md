# 01. 시스템 전체 개요

## 🎯 목표

**입력:** 인터넷상의 모든 숏폼/틱톡 영상  
**출력:** 바이럴 가능성 높은 영상 자동 큐레이션

---

## 📊 발전 단계

### Phase 1: 대량 크롤링 + 수동 승격
```
[크롤링] → [대량 영상] → [테드 수동 승격] → [승격 DB]
```
- OpenClaw가 24시간 크롤링
- 테드가 직접 승격/탈락 판단
- 승격된 영상 DB 축적

### Phase 2: 학습 + 경향성 메모리화
```
[승격 DB] → [패턴 분석] → [경향성 메모리] → [예측 모델]
```
- 테드의 승격 기준 패턴 학습
- 경향성을 문서/벡터로 메모리화
- 예측 점수 모델 구축

### Phase 3: A/B 테스트 제안
```
[새 영상] → [모델 예측] → [A/B 제안] → [테드 피드백] → [모델 개선]
```
- 모델이 승격 후보 제안
- 테드가 A/B 중 선택
- 피드백으로 모델 개선

### Phase 4: 완전 자동화
```
[새 영상] → [자동 판단] → [자동 승격] → [Komission 연동]
```
- 신뢰도 높은 경우 자동 승격
- 사람 개입 최소화
- Komission 시스템과 통합

---

## 🔧 기술 스택 (기존 시스템 기반)

> ⚠️ **AG 리뷰 반영 (2026-01-31):** Komission에 이미 크롤러 존재!

### 크롤링 (기존 구현)
- **TikTok:** SocialKit API (api.socialkit.dev) + Residential Proxy
- **YouTube:** Data API v3 (youtube.py)
- **Instagram:** ⚠️ 개인 계정 API 완전 차단됨 (2024.12~)

### 데이터 저장
- Neo4j (관계형 분석) - 이미 사용 중
- PostgreSQL/SQLite (메타데이터)
- Vector DB (경향성 임베딩)

### 학습/분석
- 텍스트: 제목, 설명, 해시태그 분석
- 시각: 썸네일, 영상 프레임 분석
- 메트릭: 조회수, 좋아요, 참여율

### 자동화
- OpenClaw cron jobs (24시간)
- Webhook 기반 알림
- Git 기반 상태 동기화

---

## 📈 성공 지표

1. **크롤링 양**: 일일 크롤링 영상 수
2. **승격률**: 크롤링 → 승격 비율
3. **예측 정확도**: 모델 추천 vs 테드 승격 일치율
4. **자동화율**: 사람 개입 없이 처리된 비율
