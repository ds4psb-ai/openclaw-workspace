```

├── 경쟁 크리에이터/채널 추적
```

## 🔧 AG 개발자에게 요청사항

### P0 (즉시)
1. **Telegram 알림 연동**
   - `send_telegram_alert(message, chat_id)`
   - S-tier 발견 시 즉시 호출

2. **Celery Beat 스케줄**
   ```python
   "crawler-youtube": crontab(hour="*/2")    # 2시간
   "crawler-tiktok": crontab(hour="*/3")     # 3시간
   "daily-report": crontab(hour=13, minute=0) # 22:00 KST
   "morning-summary": crontab(hour=23, minute=0) # 08:00 KST
   ```

3. **아웃라이어 점수 계산**
   - 조회수 / 채널평균조회수 = multiplier
   - S-tier: 500x+, A-tier: 100x+, B-tier: 50x+

### P1 (1주 내)
4. **크리에이터 워치리스트 API**
   - `POST /api/v1/watchlist/add`
   - `GET /api/v1/watchlist/check-new`

5. **키워드 모니터링 API**
   - `POST /api/v1/keywords/track`
   - `GET /api/v1/keywords/trending`

### P2 (1개월 내)
6. **승격 학습 파이프라인**
   - 승격된 영상 특징 추출
