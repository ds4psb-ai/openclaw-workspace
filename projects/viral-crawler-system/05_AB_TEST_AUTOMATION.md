# 05. A/B 테스트 & 자동화

## 🎯 단계별 자동화

### Level 0: 완전 수동 (현재)
- 테드가 모든 영상 직접 검토
- 시스템은 데이터 수집만

### Level 1: 필터링 자동화
- 시스템이 기본 필터링
- 테드는 필터 통과한 것만 검토
- **목표: 검토량 50% 감소**

### Level 2: A/B 테스트 제안
- 시스템이 승격 후보 2개씩 제시
- 테드가 A/B 중 선택 (또는 둘 다/둘 다 아님)
- **목표: 결정 시간 단축, 학습 가속**

### Level 3: 신뢰도 기반 자동 승격
- 높은 신뢰도: 자동 승격
- 중간 신뢰도: 테드 확인
- 낮은 신뢰도: 자동 탈락
- **목표: 70% 자동화**

### Level 4: 완전 자동화
- 모든 판단 자동화
- 테드는 예외 케이스만 검토
- 정기적 품질 샘플링
- **목표: 95% 자동화**

## 🧪 A/B 테스트 설계

### 테스트 형식

```
┌─────────────────────────────────────┐
│  오늘의 A/B 테스트 #1               │
├─────────────────────────────────────┤
│  A: [영상 썸네일 A] @creator_a      │
│     조회수: 1.2M / 참여율: 11%      │
│     예측 점수: 0.82                 │
├─────────────────────────────────────┤
│  B: [영상 썸네일 B] @creator_b      │
│     조회수: 800K / 참여율: 15%      │
│     예측 점수: 0.79                 │
├─────────────────────────────────────┤
│  선택: [ A ] [ B ] [ 둘다 ] [ 없음 ]│
└─────────────────────────────────────┘
```

### 테스트 전략

1. **유사도 기반**: 비슷한 점수의 영상 비교
2. **다양성 기반**: 다른 카테고리 영상 비교
3. **경계선 테스트**: 승격/탈락 경계의 영상
4. **랜덤 샘플**: 편향 방지용

## 📊 자동화 신뢰도

### 신뢰도 계산

```python
confidence = model_score * consistency_factor * recency_weight

# model_score: 0-1 (모델 예측 점수)
# consistency_factor: 과거 유사 영상 승격률
# recency_weight: 최근 트렌드 반영
```

### 임계값 설정

| 신뢰도 | 처리 |
|--------|------|
| > 0.9 | 자동 승격 |
| 0.7 - 0.9 | A/B 테스트 |
| 0.4 - 0.7 | 테드 검토 |
| < 0.4 | 자동 탈락 |

## 📈 자동화 KPI

### 일일
- 자동 처리 비율
- 테드 검토 소요 시간
- A/B 테스트 응답률

### 주간
- 자동 승격 정확도 (샘플 검증)
- 자동 탈락 중 놓친 좋은 영상
- 신뢰도 분포 변화

### 월간
- 전체 자동화율 추이
- 모델 성능 변화
- 테드 작업량 변화

## ⚡ OpenClaw 자동화 역할

### A/B 테스트 운영
```
# 매일 09:00 KST
1. 전일 크롤링 중 중간 신뢰도 영상 추출
2. A/B 페어 생성 (5-10세트)
3. 테드에게 Telegram으로 전송
4. 응답 수집 (당일 내)
5. 결과 기록 및 학습 반영
```

### 자동 승격 실행
```
# 매 6시간
1. 높은 신뢰도 영상 추출
2. 최종 체크 (중복, 삭제 등)
3. Komission DB 자동 등록
4. 로그 기록
```

### 모니터링
```
# 매일
1. 자동화율 계산
2. 이상 탐지 (급격한 변화)
3. 주간 리포트 생성
```
