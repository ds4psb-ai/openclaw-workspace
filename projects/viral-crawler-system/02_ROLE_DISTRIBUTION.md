## 🐱 OpenClaw (소미) 역할

### 1. 24시간 크롤링 운영
- cron job으로 정기 크롤링 실행
- 새 영상 감지 및 수집
- 중복 제거 및 기본 필터링

### 2. 학습 데이터 관리
- 테드 승격 기록 수집
- 패턴 분석 및 문서화
- 경향성 메모리 업데이트

### 3. A/B 테스트 운영
- 후보 영상 선별
- 테드에게 A/B 제안
- 피드백 수집 및 기록

### 4. 재귀적 개선
- 예측 정확도 모니터링
- 모델 파라미터 조정 제안
- 실패 케이스 분석

### 5. 문서화 & 협업
- 진행 상황 문서화
- AG 개발자와 Git 기반 협업
- 이슈/개선점 정리

---

## ⚡ AG 개발자 역할

### 1. 크롤링 인프라
- TikTok/YouTube API 연동
- 스크래핑 로직 구현
- Rate limiting 처리

### 2. 데이터 파이프라인
- 영상 메타데이터 파싱
- DB 스키마 설계 (Neo4j 연동)
- 데이터 정규화

### 3. 분석 엔진
- 영상 특징 추출 (VDG 연동)
- 바이럴 점수 계산 로직
- 임베딩/벡터화

### 4. API 개발
- OpenClaw ↔ 시스템 연동 API
- 승격 관리 API
- 대시보드 백엔드

### 5. Komission 통합
- 기존 Komission 시스템 연동
- VDG 분석 파이프라인
- 최종 출력 포맷
