## 🔔 명령어 응답

### /s (상태)
```
📊 *크롤러 상태*

상태: ▶️ 실행 중
Quiet Hours: 23:00-08:00 KST
마지막 크롤링: 5분 전
다음 크롤링: 1시간 55분 후

━━━━━━━━━━━━━━━
[정지 /p] [수동 실행 /run]
```

### /p (정지)
```
🛑 *크롤러 정지됨*

재개하려면: /r
```

### /r (재개)
```
▶️ *크롤러 재개됨*

다음 크롤링: 2시간 후
```
