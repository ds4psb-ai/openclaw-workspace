# 🔧 AG 개발자를 위한 소미(OpenClaw) 통합 명세서

**작성:** 소미 🐱 (OpenClaw)
**대상:** AG (Antigravity) 개발자
**목적:** 소미의 능력과 한계를 이해하고, 최적의 통합 방식 결정

---

## 📋 소미(OpenClaw)란?

### 기본 정보
| 항목 | 설명 |
|------|------|
| **정체** | Claude 기반 AI 에이전트 (OpenClaw 플랫폼) |
| **가동 시간** | **24시간 365일** (VPS에서 상시 구동) |
| **통신 채널** | Telegram (현재), Slack/Discord (설정 시 가능) |
| **코드 실행** | ✅ Python/Shell 스크립트 실행 가능 |
| **파일 관리** | ✅ 읽기/쓰기/Git 커밋 가능 |
| **API 호출** | ✅ HTTP 요청 가능 (curl, httpx 등) |
| **스케줄링** | ✅ cron job 설정/관리 가능 |
| **코드 수정** | ❌ Komission 코드베이스 직접 수정 불가 |

### 소미가 할 수 있는 것
```
✅ API 엔드포인트 호출 (GET/POST)
✅ 응답 파싱 및 분석
✅ 조건부 로직 (if 점수 > 500x → 알림)
✅ Telegram 메시지 전송
✅ 파일 생성/수정 (JSON, MD 등)
✅ Git commit/push
✅ cron job 스케줄 관리
✅ 웹 검색/리서치
✅ 패턴 분석 및 문서화
```

### 소미가 할 수 없는 것
```
❌ Komission 백엔드 코드 직접 수정
❌ DB에 직접 쿼리 (API 통해서만 가능)
❌ 서버 배포/인프라 관리
❌ 복잡한 ML 모델 학습 (파일 기반 규칙만)
```

## 📡 필요한 API 명세

### AG가 제공해야 할 API

#### 1. 크롤링 트리거 (기존)
```http
POST /api/v1/crawlers/run
Authorization: Bearer {token}
Content-Type: application/json

{
  "platforms": ["youtube", "tiktok"],
  "limit": 50,
  "region": "KR"
}

Response:
{
  "status": "started",
  "job_id": "crawl_20260131_163000"
}
```

#### 2. 아웃라이어 목록 조회 (기존/확인 필요)
```http
GET /api/v1/outliers?status=pending&min_score=50&limit=20
Authorization: Bearer {token}

Response:
{
  "items": [
    {
      "id": 123,
      "video_id": "abc123",
      "platform": "tiktok",
      "url": "https://...",
      "title": "영상 제목",
      "creator": "@username",
      "metrics": {
        "views": 2300000,
        "likes": 150000,
        "comments": 5000,
        "engagement_rate": 0.185
      },
      "score": 850,  // 채널 평균 대비 배수
      "tier": "S",
      "crawled_at": "2026-01-31T16:00:00Z"
    }
  ],
  "total": 45
}
```

#### 3. 승격 처리 (신규)
```http
POST /api/v1/outliers/{id}/promote
Authorization: Bearer {token}
Content-Type: application/json

{
  "reason": "높은_참여율",
  "tags": ["트렌드_적합", "UGC_친화적"],
  "promoted_by": "ted",  // "ted" | "somi_auto" | "somi_suggest"
  "confidence": 0.95
}

Response:
{
  "status": "promoted",
  "id": 123,
  "promoted_at": "2026-01-31T16:35:00Z"
}
```

#### 4. 탈락 처리 (신규)
```http
POST /api/v1/outliers/{id}/reject
Authorization: Bearer {token}
Content-Type: application/json

{
  "reason": "광고성_콘텐츠",
  "rejected_by": "ted"
}
```

#### 5. Webhook (크롤링 완료 시) (신규)
