# 04. 학습 & 경향성 메모리화

## 🎯 목표

테드의 5년 큐레이션 경험을 시스템이 학습하여:
1. 승격 기준을 패턴화
2. 경향성을 메모리(문서/벡터)로 저장
3. 새 영상에 대해 예측 가능하게

---

## 📊 학습 데이터

### 입력 (X)
- 영상 메타데이터 (제목, 설명, 해시태그)
- 크리에이터 정보
- 메트릭 (조회수, 참여율 등)
- 수집 시점 트렌드 컨텍스트

### 출력 (Y)
- 테드 승격 여부 (1/0)
- (선택) 승격 이유 메모

---

## 🧠 경향성 메모리화 방법

### 1. 규칙 기반 (명시적)
```markdown
# CURATION_RULES.md

## 승격 기준
1. 참여율 > 10% 우선
2. 해시태그에 [타겟 키워드] 포함
3. 크리에이터 팔로워 1만 이상
4. 영상 길이 15-60초 선호

## 탈락 기준
1. 광고성 콘텐츠
2. 저품질 썸네일
3. 리포스트/도용 의심
```

### 2. 통계 기반
```json
{
  "avg_promoted_views": 500000,
  "avg_promoted_engagement": 0.12,
  "top_hashtags": ["#trend1", "#trend2"],
  "preferred_duration": [15, 45],
  "creator_follower_range": [10000, 1000000]
}
```

### 3. 임베딩 기반 (고급)
- 승격된 영상들의 텍스트 임베딩
- 유사도 기반 추천
- 클러스터링으로 카테고리 발견

## 🔄 학습 루프

```
[새 크롤링 영상]
       ↓
[기본 필터링] → 탈락
       ↓
[경향성 점수 계산]
       ↓
[상위 N개 → 테드 제시]
       ↓
[테드 승격/탈락 결정]
       ↓
[결과 기록]
       ↓
[경향성 업데이트] ←────┐
       ↓                │
[예측 정확도 평가] ────┘
```

## 📈 정확도 개선

### 피드백 수집
- 테드 승격 시 간단한 이유 태그
- 탈락 시 주요 원인 선택

### 오차 분석
- False Positive: 예측 승격 → 실제 탈락
- False Negative: 예측 탈락 → 실제 승격
- 주기적 오차 패턴 분석

### 모델 업데이트
- 주간 단위 규칙 재검토
- 월간 단위 통계 리셋/조정
- 분기별 전체 재학습

## ⚡ OpenClaw 역할

### 일일 작업
- 승격 결과 수집 및 기록
- 통계 업데이트
- 규칙 위반 케이스 감지

### 주간 작업
- 경향성 변화 리포트
- 규칙 개선 제안
- 새로운 패턴 발견 보고

### 재귀적 개선
- 예측 정확도 < 목표 시 알림
- 개선 방안 자동 제안
- A/B 테스트 설계
