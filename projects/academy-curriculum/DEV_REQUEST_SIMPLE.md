## 📊 3개 앱별 "최고 성능" 기준

### 1. DNA Lab (분석)
| 해야 할 것 | 기준 |
|-----------|------|
| URL → VPE 분석 | 30초 내 결과 |
| VPE → 프롬프트 | Veo/Kling에서 실제 좋은 결과 |

**질문:** 현재 프롬프트 품질 어떤가요? 실제 렌더링 테스트 해봤나요?

### 2. Story Engine (구성)  
| 해야 할 것 | 기준 |
|-----------|------|
| 아이디어 → 시나리오 | 구조화된 출력 |
| 시나리오 → 스토리보드 | 10컷 자동 생성 |
| 스토리보드 → 샷 리스트 | Production에서 바로 사용 가능 |

**질문:** 샷 리스트가 Production 프롬프트로 바로 연결되나요?

### 3. Production (제작)
| 해야 할 것 | 기준 |
|-----------|------|
| Veo 3.1 연동 | 4K, Ingredients-to-Video, 세로영상 |
| Kling 2.6 연동 | 네이티브 오디오, 립싱크 |
| 비용 최적화 | 목적별 최적 Provider 추천 |

**질문:** Veo/Kling API 최신 기능 다 쓰고 있나요?

---

## 🔗 3개 앱 연동

```
DNA Lab ──→ Story Engine ──→ Production
(분석)        (구성)          (제작)
```

**핵심:** 앱 간 데이터가 끊김 없이 흘러야 함
- DNA Lab 스타일 → Story Engine 가이드로
- Story Engine 샷 → Production 프롬프트로
