# 🎯 메가앱 3개 핵심 스펙

**목표:** 메가앱이 최고 성능으로 작동하게 하는 것  
**부차적:** 커리큘럼, 강사모드 등은 앱이 완성된 후

---

## 📊 3대 메가앱 핵심 기능

### 1. 🔬 DNA Lab (분석)

**핵심 목적:** 레퍼런스 영상에서 스타일 DNA 추출

| 기능 | 입력 | 출력 | 우선순위 |
|------|------|------|----------|
| VPE 분석 | 영상 URL | Visual/Verbal/Emotional 프로파일 | ⭐⭐⭐ |
| 프롬프트 연금술 | VPE 결과 | 영상 생성용 프롬프트 | ⭐⭐⭐ |
| 스타일 비교 | 영상 2개 | 차이점/공통점 분석 | ⭐⭐ |

**최고 성능 기준:**
- [ ] URL 입력 → 30초 내 VPE 결과
- [ ] 프롬프트가 Veo/Kling에서 실제로 좋은 결과 생성
- [ ] 거장 스타일 재현 가능

---

### 2. 📖 Story Engine (구성)

**핵심 목적:** 아이디어 → 촬영 가능한 스토리보드

| 기능 | 입력 | 출력 | 우선순위 |
|------|------|------|----------|
| 시나리오 생성 | 컨셉 텍스트 | 구조화된 시나리오 | ⭐⭐⭐ |
| 스토리보드 | 시나리오 | 컷별 이미지 설명 | ⭐⭐⭐ |
| 샷 리스트 | 스토리보드 | 촬영 지시서 (프롬프트 포함) | ⭐⭐⭐ |

**최고 성능 기준:**
- [ ] 컨셉 한 줄 → 10컷 스토리보드 자동 생성
- [ ] 각 컷이 바로 Production에서 렌더링 가능
- [ ] 일관된 스타일 유지

---

### 3. 🎬 Production (제작)

**핵심 목적:** 프롬프트 → 최종 영상 렌더링

| 기능 | 입력 | 출력 | 우선순위 |
|------|------|------|----------|
| Provider 선택 | 요구사항 | Veo/Kling 추천 | ⭐⭐⭐ |
| 렌더링 | 프롬프트 + 설정 | AI 영상 | ⭐⭐⭐ |
| 비용 추정 | 설정 | 예상 비용 | ⭐⭐ |

**최고 성능 기준:**
- [ ] Veo 3.1: 4K, 캐릭터 일관성, 세로영상
- [ ] Kling 2.6: 네이티브 오디오+립싱크
- [ ] 비용 대비 최적 품질 가이드

---

## 🔗 3개 앱 연동 플로우

```
[DNA Lab] ──프롬프트──→ [Story Engine] ──샷리스트──→ [Production]
   │                        │                          │
   └── 스타일 DNA ──────────┴── 일관성 유지 ───────────┘
```

**핵심 연동 포인트:**
1. DNA Lab의 VPE 결과 → Story Engine 스타일 가이드로 전달
2. Story Engine의 샷 리스트 → Production 프롬프트로 직접 사용
3. Production 결과 → DNA Lab에서 품질 분석 (피드백 루프)

## 🎯 성공 기준 (체크리스트)

메가앱이 "최고 성능"이라고 할 수 있으려면:

- [ ] **DNA Lab:** 아무 영상 URL → 재현 가능한 프롬프트 추출
- [ ] **Story Engine:** 아이디어 한 줄 → 렌더링 가능한 샷 리스트

- [ ] **연동:** 3개 앱이 끊김 없이 데이터 전달
