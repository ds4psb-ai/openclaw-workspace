# 8회 커리큘럼(화/목 19-21) — ‘거장 DNA + 일관성 + 바이럴 + 실전 제작’

원칙: **매 회차 산출물 1개(파일) + 데모 1개 + 체크리스트 1개**

## 1회차(화) — 거장 DNA 추출 + 브랜드 브레인 세팅
- 목표: “내가 만들고 싶은 세계관/미학”을 **규칙으로 고정**
- 도구: NotebookLM(무료)
- 산출물: `Master DNA Sheet`(샷 언어/색/조명/금칙/리듬 1장)
- 데모: 레퍼런스 3개 넣고 **DNA 질문 5개** 중 1,2번으로 표 생성
- 체크: 저작권/레퍼런스 안전 체크

## 2회차(목) — Mixboard로 ‘시각 언어’ 보드 고정(2~3안)
- 목표: 감이 아니라 **보드로 합의**
- 도구: Mixboard(무료 축)
- 산출물: `Moodboard v1~v3` (보드 3장 캡처)
- 데모: “더 어둡게/더 미니멀/더 시네마틱” 자연어 수정 3회
- 체크: 컬러 팔레트/프레이밍/소품 일관성 체크

## 3회차(화) — shot_goal/timecode 스토리보드 설계(쇼츠 45초)
- 목표: 프롬프트를 문장이 아니라 **표(데이터)**로 관리
- 도구: NotebookLM + 템플릿
- 산출물: `Storyboard Table 45s` (6~10줄)
- 데모: shot_goal 기반 0–5s/5–12s… 스토리보드 자동 생성
- 체크: 훅(3초)/전환/엔딩 CTA 품질 체크

## 4회차(목) — Scene vs Shot 분리 + 파이프라인 설계
- 목표: “일관성(씬)”과 “펀치(샷)” 분리
- 도구: Antigravity(무료) + 문서 템플릿
- 산출물: `Pipeline Spec v1` (Scene=Veo, Shot=Kling)
- 데모: 스토리보드 표 → Scene 묶음/Shot 리스트로 자동 분해
- 체크: 어떤 샷을 Veo/Kling에 보내는지 규칙(간단 룰 5개)

## 5회차(화) — Veo 파이프라인(일관성/시네마틱) 데모 샷 생성
- 목표: 거장 스타일 ‘시네마틱 일관성’ 증명
- 도구: Veo 3.1(유료/크레딧) + 레퍼런스 이미지(ingredients)
- 산출물: `Veo Scene Pack` (씬 2개: 9:16, 5~8초)
- 데모: ingredients 1~4장으로 캐릭터/배경 고정
- 체크: 일관성 체크리스트(얼굴/의상/조명/배경/질감)

## 6회차(목) — Kling 파이프라인(펀치/오디오) 데모 샷 생성
- 목표: 숏폼 ‘세게 치는’ 샷 + 오디오/립싱크
- 도구: Kling 2.6(유료/크레딧)
- 산출물: `Kling Punch Pack` (샷 3개: FPV/댄스/밈 중 택1)
- 데모: 오디오 컨텍스트(대사/비트) 포함 렌더
- 체크: 리텐션(첫 2초) + 사운드/자막 싱크 체크

## 7회차(화) — 편집 패키지(자막/타이틀/썸네일) 자동 생성
- 목표: 업로드 직전 ‘패키지’를 만든다
- 도구: NotebookLM + 템플릿
- 산출물: `Upload Kit`(제목 20개/썸네일 카피 10개/설명란 3종/자막 가이드)
- 데모: 채널 톤 고정(브랜드 브레인 기반)
- 체크: 상업성 티 최소 CTA 문장(필요한 분만)

## 8회차(목) — 운영 루프(발행/회고/다음주 자동 개선)
- 목표: “꾸준히 나오는 시스템” 완성
- 도구: OpenClaw(메신저=리모컨) + NotebookLM Audio Overview
- 산출물: `Weekly Ops`(체크리스트+회고 템플릿+2분 오디오 요약)
- 데모: “요약→고정글→오디오(Brief)” 한 사이클
- 체크: 키/토큰 노출 방지, 승인(qa) 루프

## 수강 종료 시 학생이 들고가는 ‘3종 세트’
1) 브랜드 브레인(NotebookLM)
2) 스토리보드 표 + 샷 라이브러리
3) Scene/Veo + Shot/Kling 파이프라인 스펙
