## 📱 회차별 상세 (메가앱 기능 매핑)

### 1회: 전체 워크플로우 체험 ⭐
**메가앱:** All 3 (순차 체험)
**시간:** 2시간

| 시간 | 활동 | 메가앱 기능 |
|------|------|------------|
| 0-20분 | Smart Onboarding | IntentSearchBar → 목표 입력 |
| 20-50분 | DNA Lab 체험 | VPE 분석 → 프롬프트 추출 |
| 50-80분 | Story Engine 체험 | 시나리오 → 스토리보드 |
| 80-110분 | Production 체험 | Provider 선택 → 렌더링 |
| 110-120분 | 결과 공유 | 수강생 영상 상영회 |

**프리셋 입력값:**
```json
{
  "intent": "15초 제품 광고 영상",
  "reference": "Apple 광고 스타일",
  "provider": "kling_2.6_turbo"
}
```

## 🎓 강사 모드 요구사항

### 필수 기능
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **프리셋 입력값** | 수강생이 바로 시작할 수 있는 템플릿 | ⭐⭐⭐ |
| **단계별 가이드** | "지금 이 버튼을 누르세요" 하이라이트 | ⭐⭐⭐ |
| **진행률 추적** | 수강생별 현재 단계 확인 | ⭐⭐ |
| **강사 컨트롤** | 전체 화면 동기화 (선택) | ⭐ |

### 구현 방식 제안

**Option A: 메가앱 내장 (추천)**
```
URL: prompty.co.kr?mode=instructor&session=academy-1
- 프리셋 자동 로드
- 가이드 오버레이 활성화
- 진행률 사이드바
```

**Option B: 별도 대시보드**
```
URL: prompty.co.kr/instructor
- 수강생 목록 + 현재 단계
- 원격 화면 공유
- 통계 (완료율, 시간 등)
```

### MVP (2/3 강의용)
- ✅ 프리셋 URL 파라미터
- ✅ 단계별 설명 모달
- ❌ 진행률 추적 (Phase 2)
- ❌ 강사 컨트롤 (Phase 2)
