# 성수동 아카데미 ‘10배 가치’ 설계(2026)

목표: 수강생이 “툴 배웠다”가 아니라 **‘내 채널/내 상품이 굴러간다’**로 귀결되게.

## 10배 가치의 정의(측정 가능)
- 수강 종료(8회) 시점에 최소 3개가 ‘실물’로 남아야 함
  1) **브랜드 브레인(NotebookLM 노트북 1개)**: 스타일/금칙/샷언어/제목패턴/CTA 패턴
  2) **shot_goal 기반 스토리보드 템플릿 1개** + 샷 30개 라이브러리
  3) **Scene=Veo / Shot=Kling 파이프라인 템플릿 1세트**(데모 샷 생성까지)

## 수강생 경험을 ‘압도’로 만드는 6가지 장치
1) **첫날 20분 안에 ‘결과물’**
   - 무드보드 1개 + 스토리보드 6줄 + 데모 샷 1개(저해상도/짧게)
2) **매 회차 산출물 1개(문서/표/템플릿) 강제**
3) **코드/어려운 용어 금지**: ‘샷 목표/금칙/톤/구도/리듬’ 같은 언어로 통일
4) **개인화 루프**: 학생별 ‘브랜드 브레인’에 계속 축적(다음 회차가 쉬워짐)
5) **검수 체크리스트**: 일관성/미학/바이럴 훅/권리·저작(안전) 체크
6) **후반 자동화 맛보기**: “메신저 한 줄→정리→게시” 데모(선택)

## 커리큘럼을 ‘제품’처럼 설계하는 원칙
- 매 회차: (Input) → (Process) → (QA) → (Output) → (Archive)
- Output은 반드시 파일로 남기고, 다음 회차의 Input으로 재사용

## 포스터 구조(4 STEP)를 8회로 쪼개는 방법(추천)
- STEP1(기획) 2회: 거장 DNA 추출 + 무드보드 고정
- STEP2(시나리오) 2회: 쇼츠 훅/전개/엔딩 패턴 + shot_goal 스토리보드
- STEP3(제작) 2회: Scene(Veo) / Shot(Kling) 파이프라인 + 데모 샷 생성
- STEP4(편집) 2회: 컷 리듬/사운드/자막 템플릿 + 업로드 패키지

## 라이브에서 한 줄로 말할 ‘약속’
- “8회 끝나면, 여러분은 영상 만드는 법이 아니라 **‘영상이 꾸준히 나오는 시스템’**을 들고 갑니다.”
