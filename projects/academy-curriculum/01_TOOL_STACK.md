### 강점

> → 거장 DNA 스타일 유지에 최적!

## 🎬 Kling 2.6 - 오디오 통합

### 핵심 기능
| 기능 | 상세 |
|------|------|
| 해상도 | 1080p ~ 4K |
| 오디오 | **네이티브 오디오 + 립싱크** |
| 특별 기능 | 랩/노래 동기화, FPV 드론 샷 |
| 모드 | Turbo (고속), Standard, Pro |

### 가격
- 구독/크레딧 기반
- 체감 단가 Veo보다 낮음 → 대량 생산에 유리

### 노드 워크플로우 구조 (보미용)
```
노드1: Prompt & Style
  → NotebookLM/Mixboard에서 뽑은 키워드/감성

노드2: Shot Config
  → duration, camera motion (FPV, dolly, orbit)

노드3: Audio Context
  → 대사/나레이션/비트 감성 텍스트

노드4: Render
  → Draft 모드 → Final 모드 브랜치
```

## 📊 Veo 3.1 vs Kling 2.6 비교표

| 항목 | Veo 3.1 | Kling 2.6 |
|------|---------|-----------|
| 해상도 | 4K, 60fps | 1080p~4K |
| 세로 영상 | ✅ 네이티브 9:16 | ✅ 지원 |
| 캐릭터 일관성 | ✅ 이미지 4장 레퍼런스 | 🔶 변동 있음 |
| 오디오 | ✅ 대사+효과음+앰비 | ✅ 립싱크+랩/노래 |
| 가격 | 초당 과금 (비쌈) | 구독 (저렴) |
| 강점 | 품질, Google 생태계 | 대량 생산, 오디오 |

### 역할 분담 추천
- **Veo 3.1**: 고퀄리티 시그니처 영상, 레퍼런스 일관성 필요할 때
- **Kling 2.6**: 대량 쇼츠 생산, 오디오/립싱크 필요할 때
