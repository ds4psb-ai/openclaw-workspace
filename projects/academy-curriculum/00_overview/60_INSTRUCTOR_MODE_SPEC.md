# ‘강사 모드 / 강의 템플릿’ 필요성 및 MVP 스펙

## 왜 필요한가
강의장에서는 “기능이 있다”보다 **학생이 지금 무엇을 눌러야 하는지**가 중요.

## MVP(2/3 D-Day 기준) — 최소 기능
1) **Session Preset(회차 프리셋)**
- 회차별: 목표/입력/샘플 데이터/출력 형식이 미리 채워진 템플릿
- 버튼 1개: “1회차 템플릿 시작하기”

2) **Step Guide(단계별 가이드)**
- 화면 상단에 3~6단계 체크리스트
- 현재 단계는 강조(하이라이트/배지)

3) **Progress(진행률 추적)**
- 학생별: `sessionId` + `step` 완료 여부(Boolean)만 저장해도 충분
- 강사 화면: 학생 리스트 + (진행률 0~100%)

## 구현 형태(추천)
- 메가앱 내장(추천): 학생이 다른 링크로 이동하지 않아도 됨
- 별도 강사 대시보드(차선): 시간 부족하면 ‘읽기 전용’으로 분리

## Export/SYNC
- D-Day 전엔 Export만: CSV/Google Sheet 업로드 1회
- D+ 이후 자동화: Notion/Google Sheet 실시간 동기화
