# 수강생 산출물 체크리스트(8회)

- [ ] Master DNA Sheet 1장(샷언어/색/조명/금칙/리듬)
- [ ] Moodboard 3장(v1~v3)
- [ ] Storyboard Table 45s (6~10줄)
- [ ] Pipeline Spec v1 (Scene=Veo / Shot=Kling)
- [ ] Veo Scene Pack 2개(세로 9:16)
- [ ] Kling Punch Pack 3개(오디오 포함)
- [ ] Upload Kit(제목/썸네일/설명/자막)
- [ ] Weekly Ops(회고+다음 주 개선+2분 오디오 요약)

## Shorts 규격(근거 3줄 · Google 공식)
- **세로 영상(Vertical)**이 Shorts에 가장 적합하다고 안내(가로만 있으면 세로로 변환 기능을 권장).
- Shorts 피드에서는 **최대 180초(3분 중 앞부분)**까지만 재생된다고 명시(핵심 메시지는 180초 안에).
- 모바일 환경을 전제로 **사운드 ON**(음악/보이스) 크리에이티브를 권장.

출처: Google Ads Help – YouTube Shorts ads: Asset specs and best practices
https://support.google.com/google-ads/answer/16041697

완료 정의: 8개 중 6개 이상 + 데모샷(최소 1개) 실제 생성하면 ‘수강료 10배’ 체감 구간 진입.
