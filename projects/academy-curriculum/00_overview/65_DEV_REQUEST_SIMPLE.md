# DEV_REQUEST_SIMPLE (AG-Vivid용 / D-3)

목표(1줄)
- **10분 안에 15초 고품질 영상 완성** E2E 플로우를 강의장에서 끊김 없이 달성.

필수 구현(P0)
1) **강의 프리셋(버튼 1개로 시작)**
- 1회차/2회차/3회차/4회차 프리셋 최소 4개
- 프리셋은 “입력 최소/기본값 최대” (학생이 옵션에서 멈추지 않게)

2) **Step Guide(3~6단계 안내 + 하이라이트)**
- 지금 뭘 해야 하는지 ‘한 문장’으로 표시

3) **Progress(학생별 step boolean) + Export(CSV)**
- 강사 화면: 학생 리스트 + 진행률
- Export 버튼 1개면 충분

필수 테스트(P0)
- 실제 prompty.co.kr에서 **DNA→Story→Production E2E 10분 루트** 5회 반복 성공
- Veo/Kling 실제 호출(실토큰) 성공률/에러 로그 확보

필요하면 나중에(P1)
- 구글시트/노션 자동 동기화
- 음성/명령 기반 화면 열기
