# 8회 커리큘럼 → prompty 메가앱 매핑(간단/성능 우선)

목표: 강의장에서 ‘커리큘럼 설명’이 아니라 **메가앱 3개가 최고 성능으로 발휘**되게 수업을 설계한다.

먼저 읽기: `00_overview/45_MEGAAPP_FOCUS_PRINCIPLES.md`

## 매핑 원칙(한 줄)
- 8회는 “콘텐츠 주제”보다 **앱이 잘하는 일(최소 입력 → 최대 출력)** 기준으로 배치한다.

## 회차 매핑(8회)

### 1회차 — Full Flow 온보딩(한 바퀴)
- App: Shell(All)
- Output: 학생별 Workspace + 샘플 프로젝트(복제)

### 2회차 — DNA Lab: ‘규칙 고정’
- App: DNA Lab
- Output: Master DNA Sheet(룰/금칙)

### 3회차 — Story Engine: ‘shot_goal로 설계’
- App: Story Engine
- Output: Storyboard Table 45s(timecode/shot_goal)

### 4회차 — Production: ‘플랜/비용/엔진 선택’
- App: Production
- Output: Pipeline Spec(Scene=Veo / Shot=Kling, 데모/파이널 분리)

### 5회차 — Production(Veo): Scene 일관성 데모
- Output: Veo Scene Pack(9:16, 짧은 데모샷)

### 6회차 — Production(Kling): Shot 펀치+오디오 데모
- Output: Kling Punch Pack(짧은 펀치샷)

### 7회차 — Packaging: 업로드 키트(제목/설명/자막)
- App: Story Engine + Production
- Output: Upload Kit

### 8회차 — Ops: 회고/다음주 실험/진행률 Export
- App: Shell + (간단 Ops)
- Output: Weekly Ops + Progress Export

## 결론
- 커리큘럼은 ‘추가 기능’이 아니라 **3앱의 성능(속도/일관성/재현성)을 극대화하는 UI 프리셋/가이드**로 구현한다.
