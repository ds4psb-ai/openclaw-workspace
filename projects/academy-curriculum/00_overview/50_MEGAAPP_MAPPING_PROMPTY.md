# 8회 커리큘럼 → prompty.co.kr 메가앱 매핑(제안)

목표: “커리큘럼을 페이지로 설명”이 아니라, **강의 당일 실제 툴 화면으로 진행**.

## 전제
- 메가앱 구성(가정): `DNA Lab` / `Story Engine` / `Production` (+ 공통 Shell)
- 수업 원칙: 회차마다 **Preset 입력값 + 단계별 안내 + 산출물 저장**이 있어야 함.

---

## 회차 매핑(8회)

### 1회차 — Smart Onboarding(전체 워크플로우 한 바퀴)
- App: **UnifiedWorkflowShell (All)**
- 핵심 기능: Smart Onboarding → Sample 프로젝트 로드 → 3앱( DNA→Story→Production) 한 번에 체험
- 산출물: 학생별 `Workspace` 생성 + 기본 템플릿 복제

### 2회차 — ‘광고처럼 임팩트’(DNA Lab)
- App: **DNA Lab**
- 핵심 기능: VPE 분석 + Master DNA Sheet 생성 + 금칙/미학 규칙 고정
- 산출물: `Master DNA Sheet` (키워드/룰/금칙)

### 3회차 — ‘이야기가 있는 영상’(Story Engine)
- App: **Story Engine**
- 핵심 기능: shot_goal/timecode 스토리보드 테이블 + 훅(3초) 패턴 생성
- 산출물: `Storyboard Table 45s`

### 4회차 — ‘나만의 작품’ Capstone 구조(Production)
- App: **Production**
- 핵심 기능: Provider Selector + Cost Estimator + Render Plan(무료 데모샷/유료 파이널)
- 산출물: `Pipeline Spec v1` (Scene=Veo / Shot=Kling)

### 5회차 — Scene-level 일관성(Production: Veo)
- App: **Production (Veo path)**
- 핵심 기능: Ingredients(레퍼런스) + 세로 9:16 + Scene Pack 생성(데모샷)
- 산출물: `Veo Scene Pack`

### 6회차 — Shot-level 펀치(Production: Kling)
- App: **Production (Kling path)**
- 핵심 기능: 고모션 + 오디오 컨텍스트 + Punch Shot 생성(데모샷)
- 산출물: `Kling Punch Pack`

### 7회차 — 업로드 패키지(Story Engine → Production 마감)
- App: **Story Engine + Production**
- 핵심 기능: 제목/썸네일/설명/자막 ‘Upload Kit’ 생성 + 링크/CTA 최소화 규칙
- 산출물: `Upload Kit`

### 8회차 — 운영 루프(발행/회고/자동 개선)
- App: **UnifiedWorkflowShell + Ops(간단)**
- 핵심 기능: 오늘 성과 요약(Brief) + 다음 주 실험 1개 + 진행률 Export
- 산출물: `Weekly Ops`

---

## 제안 결론
- 1~4회차는 “무료 입구(기획/분석/스토리보드/플랜)”를 메가앱 UI로 고정.
- 5~6회차는 Production에서 엔진을 ‘플러그인’처럼 선택(데모샷 위주).
- 7~8회차는 결과물 패키징/운영까지 연결해 **수강생 체감 10배**를 만든다.
