# 자동화 아이디어(실현 가능성/우선순위)

목표: 2/3 D-Day까지 “가장 임팩트 큰 것만” 붙인다.

## P0 (D-3~D-Day에 가능한 것)
1) **Markdown → 메가앱 UI 반영**
- 방식: 커리큘럼 md를 단일 JSON으로 변환 → 앱에서 렌더
- 장점: 커리큘럼 변경이 즉시 반영, 버전 관리 쉬움

2) **진행률 Export(수동 동기화)**
- 강사 화면에서 CSV 다운로드 → 구글시트 업로드
- 장점: 구현 난이도 낮고 강의 운영에 바로 도움

## P1 (D+ 이후)
3) **진행률 자동 동기화(구글시트/노션)**
- 조건: 학생 식별(이름/코드) + step 이벤트 수집

4) **라이브 커맨드(‘OO 학생 DNA Lab 열어줘’)**
- 브라우저 제어/딥링크로 가능하나, 강의장 네트워크/디바이스 변수 큼
