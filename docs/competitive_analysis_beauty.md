## 시장 Gap & 기회

### 발견된 Gap

1. **"왜 바이럴인지" 설명하는 도구 없음**
   - Virlo: "무엇이" 뜨는지만
   - Shortimize: 숫자만
   - **VDG = 유일한 "왜" 분석**

2. **K-뷰티 특화 인텔리전스 부재**
   - 글로벌 툴은 영미권 중심
   - K-뷰티 패턴 이해 부족
   - **한국 기반 = 경쟁 우위**

3. **Human-in-the-loop 워크플로우 미비**
   - 대부분 완전 자동화 or 완전 수동
   - **Shorti Scout = 자동 발견 + 인간 판단**

### 진입 전략

**Phase 1: K-뷰티 전문가 포지셔닝**
- 아모레퍼시픽, LG생활건강 같은 K-뷰티 그룹 먼저
- "K-뷰티 바이럴 전문가"로 신뢰 구축

**Phase 2: 글로벌 브랜드 확장**
- 로레알 등 글로벌 그룹의 "K-뷰티 인사이트 파트너"
- Borntostandout 같은 K-브랜드 투자 기업 공략

**Phase 3: 플랫폼화**
- VDG API 오픈
- 에이전시 화이트라벨

## 📰 최신 경쟁사 뉴스 (2025-12)

- **2025-12-06:** "#1 TikTok Trend Discovery Tool for 2025-2026" 선정 (OpenPR)
