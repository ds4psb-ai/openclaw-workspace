# Skill Quality Checklist (범용)

출시 전 아래 항목을 모두 통과해야 함.

## 1) Trigger 품질
- [ ] `description`에 **언제 호출**되는지 명시
- [ ] `description`에 **언제 호출하지 않는지** 명시
- [ ] `any work`, `모든 작업` 같은 과도한 표현 없음

## 2) 구조 (Progressive Disclosure)
- [ ] `SKILL.md`는 핵심 정책/워크플로우만 포함
- [ ] 상세 문서/스키마/예시는 `references/`로 분리
- [ ] 반복 실행 커맨드는 `scripts/`로 분리

## 3) 실행 가능성
- [ ] 문서에 적힌 경로가 실제 존재
- [ ] 스크립트가 현재 환경에서 실행 가능
- [ ] 실패 시 복구/대체 절차가 있음

## 4) 검증/예외
- [ ] PASS/FAIL 기준 명시
- [ ] 오탐 방지를 위한 예외 조건 2개 이상 명시
- [ ] 최소 1개 verify 루틴 제공 (스크립트 권장)

## 5) 유지보수성
- [ ] owner(담당) / last-validated 기록
- [ ] 중복 규칙 최소화 (공통 규칙은 표준 문서로 이동)
- [ ] 레퍼런스 링크 깨짐 없음
