## 🔄 협업 패턴 (Best Practices)

### 패턴 1: 리서치 → 구현
```
1. 소미: 리서치 + 스펙 작성 (분석 강점)
2. 보미: 구현 (코드 생성 강점)
3. 소미: 리뷰 + 문서화 (QA 강점)
```

### 패턴 2: 브레인스토밍 → 정제
```
1. 보미: 아이디어 100개 발산 (창의성)
2. 소미: 분석 + 10개 선별 (분석력)
3. 테드: 최종 3개 선택
```

### 패턴 3: 콘텐츠 제작
```
1. 보미: 구조/아웃라인 생성 (구조화)
2. 소미: 한국어 다듬기 (뉘앙스)
3. 보미: 시각자료 (멀티모달)
```

### 패턴 4: 자동화 개발
```
1. 소미: API 리서치 + 문서화
2. 보미: 스크립트 작성
3. 소미: cron 설정 + 모니터링
```
