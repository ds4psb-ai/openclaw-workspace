## A. 훅 유형 (Hook Type)

콘텐츠 시작 3초 내 시청자를 사로잡는 방식

| 태그 | 정의 | 뷰티 브랜드 가치 |
|------|------|-----------------|
| `#shock-hook` | 충격적 장면/결과로 시작 | 높은 초반 retention, 브랜드 적합도 주의 |
| `#question-hook` | "이거 왜 이래?" 등 질문으로 시작 | 궁금증 유발, 교육 콘텐츠와 궁합 |
| `#before-after` | 변신 전후 대비 | 제품 효과 증명, 스킨케어/메이크업 핵심 |
| `#problem-solution` | 문제 제시 → 해결책 | 제품 니즈 자연 연결 |
| `#storytelling-hook` | 개인 스토리로 시작 | 감정적 연결, 진정성 |
| `#trend-recreation` | 인기 트렌드 재현 | #beautytok 편승, 발견 가능성 ↑ |
| `#pov-hook` | "POV: ~할 때" 형식 | Z세대 공감, 상황 연출 |
| `#asmr-hook` | 소리/텍스처로 시작 | 감각적 어필, 제품 질감 강조 |
| `#unboxing-hook` | 개봉 장면으로 시작 | 기대감 조성, 신제품 론칭 |

## B. 콘텐츠 포맷 (Content Format)

전체 영상 구조 및 형식

| 태그 | 정의 | 뷰티 브랜드 가치 |
|------|------|-----------------|
| `#tutorial` | 단계별 사용법 설명 | 교육적, 제품 사용 장벽 낮춤 |

| `#routine` | 아침/저녁 루틴 | 다중 제품 노출 기회 |

| `#first-impression` | 첫 사용 반응 | 진정성, 실시간 반응 |

## 태깅 가이드라인

### 필수 태그 (모든 영상)
1. 훅 유형 1개
2. 콘텐츠 포맷 1개
3. 제품 카테고리 1개+
4. 참여도 신호 1개

### 선택 태그
- 크리에이터 프로필 (정보 있을 때)
- 트렌드/시즌 (해당될 때)
- 브랜드 적합도 (클라이언트 매칭용)

### 예시
```
영상: 스킨케어 before-after 튜토리얼, 50K 팔로워, 12% 참여율

태그:
- #before-after (훅)
- #tutorial (포맷)
- #skincare #serum (카테고리)
- #micro (크리에이터)
- #high-engagement (참여도)
- #premium-fit (브랜드 적합도)
```
