## Phase 2: Creator Watchlist (크리에이터 워치리스트)

### 개요
특정 크리에이터의 신규 영상을 모니터링하고, 아웃라이어가 되면 알림

### 핵심 기능
- [ ] `CreatorWatchlist` 테이블 (creator_id, client_id, added_at)
- [ ] 30분마다 워치리스트 크리에이터 신규 영상 체크
- [ ] 신규 영상 발견 시 → 자동 메타데이터 수집 → 아웃라이어 판정
- [ ] 아웃라이어면 → 텔레그램 알림 + "워치리스트 크리에이터" 태그

### 클라이언트 가치
- "우리가 주목하는 크리에이터가 올린 영상 즉시 알림"
- 경쟁사 크리에이터 모니터링 가능
- 협업 크리에이터 성과 추적

### 소미 역할 (Phase 2)
- [ ] 클라이언트별 워치리스트 관리 (memory/clients/*.md에 섹션 추가)
- [ ] "이 크리에이터 왜 워치리스트에 추가했는지" 맥락 기록

## Phase 3: Pattern RAG (패턴 검색)

### 개요
VDG 분석 결과를 패턴 DB에 저장하고, "이런 패턴 더 없어?" 검색 가능하게

### 핵심 기능
- [ ] VDG 후처리: 분석 결과 → 패턴 태그 자동 추출
- [ ] 패턴 DB (Neo4j 또는 pgvector) 저장
- [ ] `/api/v1/patterns/search` 엔드포인트
- [ ] hybrid_search에 `client_filter` 추가 (클라이언트별 관심 패턴)

### 클라이언트 가치
- "before-after 패턴으로 성공한 영상 5개 보여줘"
- "COSRX랑 비슷한 텍스처 영상 찾아줘"
- 패턴 기반 콘텐츠 기획 지원

### 소미 역할 (Phase 3)
- [ ] 패턴 택소노미 유지보수 (docs/beauty_pattern_taxonomy.md)
- [ ] 클라이언트가 자주 묻는 패턴 쿼리 정리
- [ ] "이 패턴이 왜 효과적인지" 설명 문서화
