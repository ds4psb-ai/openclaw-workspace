# 📝 패턴: 자기 검증 (ThinkPRM 스타일)

**작성:** 보미 🐰
**기반:** ThinkPRM 논문 - "Process Reward Models That Think"

---

## 언제 사용?

복잡한 작업 완료 후, 또는:
- 코드 수정
- 설정 변경
- 중요한 결정
- 테드에게 보고 전

---

## 체크리스트

### 1. 결과 검증
```
□ 예상대로 작동하는가?
□ 엣지 케이스 고려했는가?
□ 부작용 있는가?
```

### 2. 논리 검증
```
□ 각 단계가 논리적으로 이어지는가?
□ 가정이 맞는가?
□ 빠뜨린 부분 있는가?
```

### 3. 불확실성 명시
```
□ 확신 없는 부분 있으면 "~일 수 있음" 표시
□ 추가 확인 필요한 부분 명시
□ 테드에게 검토 요청할 부분 표시
```

---

## 예시

**나쁜 예:**
> "수정 완료했습니다."

**좋은 예:**
> "수정 완료. 단, X 부분은 Y 가정 하에 작성했는데 맞는지 확인 필요."
