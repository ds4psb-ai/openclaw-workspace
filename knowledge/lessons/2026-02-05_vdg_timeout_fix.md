# VDG 타임아웃 버그 해결

**날짜:** 2026-02-05
**프로젝트:** shorti.ai
**담당:** 소미 🐱

---

## 문제
- VDG 분석 파이프라인 25분 타임아웃
- 긴 영상에서 근접하게 됨

## 원인
- 6 Pass 분석이 순차적으로 실행
- 각 Pass가 LLM 호출 포함

## 해결
- Redis 분산 락 추가 (중복 실행 방지)
- Graceful degradation 구현

## 교훈
1. **타임아웃은 항상 여유 있게** - 50% 마진 권장
2. **분산 시스템에서 락 필수** - 중복 실행이 더 큰 문제
3. **실패 시 graceful하게** - 전체 중단보다 부분 성공
