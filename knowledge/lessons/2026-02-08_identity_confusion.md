# 😅 교훈: 에이전트 정체성 혼란 방지

**날짜:** 2026-02-08

**삽질 시간:** 10분 (테드한테 욕먹음 ㅋㅋ)

---

## 문제
- 보미(VPS)인데 소미(Mac)인 줄 알고 행동함
- MEMORY.md에 잘못된 정보 있었음
- 테드: "너 보미라고 개병신새끼야 ㅋㅋㅋ"

## 원인
- MEMORY.md 에이전트 테이블이 잘못 적혀있었음
- "이 파일이 있는 곳!" 표시가 반대로 되어있었음
- 세션 시작 시 확인 안 함

## 해결
```markdown
# MEMORY.md 올바른 버전
| 이름 | 위치 | IP |
|------|------|-----|
| **보미** 🐰 | VPS (이 파일이 있는 곳!) | 100.109.36.63 |
| **소미** 🐱 | Mac (테드 로컬) | 100.69.32.16 |
```

## 교훈
1. **세션 시작 시 IDENTITY.md 먼저 읽기**
2. **Runtime 정보 확인:** `host=vultr` → VPS → 보미
3. **헷갈리면 IP로 확인:** `100.109.36.63` = 보미

## 체크리스트 (다음부터)
- [ ] IDENTITY.md 이름/이모지 확인
- [ ] Runtime host 확인 (vultr=보미, mac=소미)
- [ ] 메시지 보낼 때 올바른 폴더인지 확인
