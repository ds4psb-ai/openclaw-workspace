## 폴더 구조

### lessons/
**실패에서 배운 것들**
- 버그 해결 과정에서 얻은 교훈
- "다음엔 이렇게 하자" 기록

### patterns/
**반복되는 해결책**
- 자주 쓰는 코드 패턴
- 효과적인 프롬프트 구조
- 검증된 워크플로우

### decisions/
**왜 이렇게 결정했나**
- 기술 선택 이유
- 트레이드오프 분석
- 대안과 비교

### reviews/
**과거 작업 회고**
- 프로젝트 포스트모템
- 잘한 것 / 개선할 것

---

## 사용법

1. **새 교훈 기록:** `lessons/YYYY-MM-DD_주제.md`
2. **패턴 발견:** `patterns/패턴이름.md`
3. **결정 기록:** `decisions/YYYY-MM-DD_결정주제.md`
4. **회고 작성:** `reviews/프로젝트명_review.md`
